## 0. ビジョン(北極星)

> **無数のエージェントから成る「生命のようなコミュニティ」が、自律的に世界を変えていく様を観察し、その結果を社会へ実装する。**

AI住民が文化を自律進化させる「生命のように変化する人工社会」。発想源は佐藤航陽『世界2.0』。応用先は未来予測・安全保障・都市開発・社会制度など(ハッカソンの対象領域すべて)に及びうる。

## 1. プロジェクトの核(一文)

> **技術的貢献 = 「大規模でも、創発と世界改変が死なない人工社会の作り方」。**
> **研究(世界改変者/ラベルの創発、k* 相転移)は、それが本当に機能したことの証拠 = 旗艦デモ。**

### 規模と新規性の関係(2026-07-03 更新: research-scope と統一)
- **規模そのものは差別化ではない**(OASIS=100万体、AgentSociety=1万体が既達)。規模は**必要インフラ**であり、ハッカソン審査の「**GPU必然性**」「**GPUで成果が伸びるか**」への答え(リッチ認知を保った数千体 × k掃引 × seed の多数フルラン)。
- **新規性 = ①世界改変者の創発という問い ②k* の測定 ③崩壊させない機構(LOD/memory/非broadcast)④検証可能性(測定の厳密さ: null/sham 対照・FSS・observer-frame)**。勝負所は現象の目新しさでなく**測定の厳密さ**([risk-register](./risk-register.md))。

### 本丸の技術的緊張
| | 豊かさ(生命的・世界改変可能) | 大規模 |
|---|---|---|
| 要求 | 毎回LLMで深く考える=高コスト | 1体あたり安く |
| 帰結 | 規模が出せない | 豊かさが死ぬ |

**この矛盾の解法そのものが新規性。** 解 = **LOD / 階層フリート**(大衆は安価なルーチン、意味のある瞬間だけ高コストな熟考)。→ 設計の最優先は **スケーラビリティ**。

## 3. 研究の問い(= 旗艦デモ)

### 中核仮説
> 世界を変えようとする個体は、生まれつき存在するのか、環境から創発するのか。

改変者を**直接実装しない**。経験と社会環境で変化する内部状態から、改変者が自然発生するかを観察する。

### 反証可能な再定式化(分散分解)
- 最終的な world-changing 行動量を、**初期パラメータ群で回帰**する。
- ★ **被説明変数(D1 決定 2026-07-03)**: 「改変者か否か」の希少二値でなく、**4層(空間/資源/象徴/network)への連続的な書き換え量**を主指標に(検出力・judge循環の両面で優位)。二値判定(別ファミリ LLM-judge、人手κ≥0.7)は補助。
- R² が高い → 初期条件支配レジーム(「生まれつき」寄り)。R² が低く経路依存が強い → 創発レジーム。
- 経験↔内部状態のカップリング強度 `k` を掃引し、init-determined → path-dominated への **相転移点 `k*`** を探す。
- ★ **k の操作化と対照(D7 決定 2026-07-03)**: k の主軸=ソロ内省の**信念書き戻し自由度**(free/degraded/sham/off)。**対照3種を必須実装**: sham reflection(計算量同一・結合ゼロ)/ compute·token 一定掃引 / null 系列(呼び出し量だけ増)。3信号(R²低下・seed発散・EWS)が対照で出ないことを示して初めて k* を主張できる([risk-register](./risk-register.md) R1)。
- 最終的発見は「生まれつきか創発か」ではなく「**`k*` を境に相転移する**」という測定可能な形。k* の主推定は finite-size scaling(N 3水準)。

### 統一現象(世界改変者 = ラベルの創発)
共有された不満が**名前(ラベル)を得た瞬間**、個人の不満が集合的になる(フレーミング理論)。コミット少数派が tipping point を超え慣習を覆す(Ashery 2025)。→ 「世界改変者の創発」と「ラベルの創発」は**1つのエンジン**。

## 5. マイルストーン梯子(下から登る)

選択肢ではなく**依存関係のある順序**。

```
M3  初期条件での回帰 R²(k 掃引)= k* 相転移      ← 論文の核心図。兆候=必達 / 確定=ストレッチ(§4)
      ▲ 信じるには測定器(LLM-judge)の検証が要る
M2  改変者の事後特定(観測者frame の計測)        ← R² の入力を作る。M3 の前提
      ▲ 測る対象が無いと検証できない
M1  ラベルの伝播 + semantic drift + 高コスト行動  ← 現象そのもの。最初の成功
```

### 最初の成功 = M1 の定義
> 共有された不満が"名前(ラベル)"を得て、ブロードキャストではなく**知覚チャネル経由で不均一に伝播**し、意味が**分岐(drift)**し、少数の個体がそのラベルから**高コスト行動へ踏み出す** — これを観測者frameで事後計測できる。

| # | 指標 | 合格イメージ |
|---|---|---|
| a | **創発** | ラベルが研究者の seed ではなく、驚き/予測誤差トリガーから内生的に1つ以上発生 |
| b | **伝播** | 全員記録ではなく知覚チャネル経由で非自明な割合へ拡散(採用曲線がS字) |
| c | **drift** | ラベルの語形 or 意味が部分集団間で計測可能に分岐(編集距離/埋め込み距離 > 閾値) |
| d | **橋渡し** | ファネル(§9)を通り、数体がラベル保持 → 高コスト行動へ踏み出す |

すべて**観測者frameで事後測定**。エージェントには構成概念(効力感・不満等)を一度も教えない。

## 6. 規模ラダー(規模は設定パラメータ)

M1 の drift・S字・tipping は**本質的に集団サイズ依存**。N≈20 では全員が即収束し分岐しない。

| 段 | 規模 | 目的 | LLM |
|---|---|---|---|
| **A 骨格/正しさ** | N=10〜50 | 配線・ログ・LOD・再現性・無クラッシュ | Mock / 小モデル |
| **B 創発/調律** | N≈100〜500 | drift が本当に出るか、伝播/トリガー率の調律、測定器(M2)検証 | 本物LLM |
| **C 本番** | フル規模 × k掃引 × seed | k* 相転移データ | フリート |

「本番は回すだけ」が成り立つのは**エンジン**まで。drift の調律は B 段(現象が現れる規模)で一度回さないと決まらない。

## 7. 不変原則:2つの frame を混ぜない

> **エージェントは "世界" にラベルを貼る**(創発する文化を、外から伝播として観測)。
> **研究者は "エージェント" にラベルを貼る**(心理学的構成概念を、行動から事後測定)。

- 内的状態(効力感・不満・当事者意識)は**エージェントに自己生成させない**。LLM事前学習の指紋/自己成就を避けるため、**観測者が外から post-hoc で**行動・発話ログを LLM-judge / 分類器で採点する。
- ラベルは**全員即記録(グローバルブロードキャスト)禁止**。知覚チャネル経由で**不均一に・歪みながら**伝播する。普遍化するかは**観測対象**であって前提ではない。

## 8. 基盤 = 人間社会の4永続レイヤー

```
空間レイヤー  : 場所 / 新規POI(街の構造)
資源レイヤー  : 保有・移転・プール(集団的高コスト行動の燃料)
社会network   : 誰が誰を知るか(伝播経路)
象徴レイヤー  : ラベル / 集団(§3 の中核エンジン)
```

「社会に変化を起こす」= これらレイヤー(特に象徴・構造)を**永続的に書き換える**こと。

## 9. アクション空間(OPEN #7 → 段階決定)

### LOD ↔ 行動 のマッピング
- **ルーチン層(非LLM)** = 閉じた列挙可能な動詞集合(移動・仕事・休息・予定追従)を決定論的に実行。
- **熟考層(LLM)** = 開いた行動(自由に構成)。ただし「なんでも」は**世界が実現できて初めて変化**になる。

### 実装方針:生成プリミティブの自由合成
「なんでも」を**動詞プリミティブの自由な合成**として実装する:
- 各プリミティブは**必ず永続的な共有世界状態を書き換える**(効果が保証される)
- LLM はそれらを**自由に組み合わせる**(開放性が保証される)
- 研究者は結果を台本化しない(到達可能にするだけ、強制しない)

### 採用範囲(DECIDED): まず Bundle C、モジュール式で最大プランへ拡張可
- **Bundle C(初回)**: 発話/ラベル + 移動/POI生成 + 資源プール/名付き集団形成。→ ファネル全段(高コスト行動)が可能 = M1 指標(d) 到達可能。
- 動詞は**ハードコードせずレジストリ(データ/プラグイン)**として持ち、将来「最大プラン(永続構造物の構築等・全レイヤー開放)」へ拡張可能にする。
- **拡張は実行前に必ずユーザーへ確認**(恒久ルール)。

### ファネルモデル(世界改変の逐次フィルタ)
```
思考が生じる → 世界に作用する意図が固まる → 高コスト行動を実行する
(上流ゲート)     (信念フィルタ)              (実行フィルタ)
```
改変者は各因子が**揃って高い角 = joint upper tail** にしか存在しない(連言が希少)。

## 10. LOD / イベント駆動認知

- 通常は状態機械・統計モデル・行動ルール(非LLM、安価)。
- LLM 起動は**イベント時のみ**: 会話・強い感情変化・驚き・違和感・チャンス発見・自発的思考開始。
- **LLM 起動トリガー = ラベリング起動トリガー**(統一。別 system を足さない)。
- フリート: 高認知エージェントに大モデル、ルーチンに小モデル(168GB クラスタで実現)。
- 心理学的正当化: 認知的努力は「常時」でなく「stake が高いとき」に配分される(metacontrol)。LOD は計算ハックでなく人間認知の近似。

- OPEN #1/#2/#4/#7 は全て registry/strategy + スイッチ。中身は確定しない。
- 「論文を組み込む」も**プラガブルなレジストリ**として(結論ではなくメカニズムとして seam 化)。

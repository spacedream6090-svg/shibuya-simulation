# 『世界2.0』(佐藤航陽)— 世界の創り方フレーム(参照)

> ユーザーがコミュニティ構築の指針として強く影響を受けているフレーム。本プロジェクトの**基盤(affordance)設計と観測項目(observable)の発想源**として使う。
> ⚠️ **使い方の限定**: これは「設計者が世界を作るレシピ」。本プロジェクトは「設計者の指紋を最小化し創発を観る」のが中核なので、**振る舞いを hardcode しない**。詳細は [research-scope.md](./research-scope.md) の「世界2.0 をどう使うか」を参照。

## 原フレーム(ユーザー提供)

```
世界とは？
├─ 視空間
│  ├─ 人間（アバター）
│  │  ├─ 顔
│  │  └─ それ以外のパーツ
│  └─ 景色（フィールド）
│     ├─ ランドマーク（空間の要点）
│     └─ それ以外の景色
└─ 生態系
   ├─ 基本3要素：自律的 / 有機的 / 分散的
   ├─ 価値の3分類：実用的価値 / 感情的価値 / 社会的価値
   ├─ 登場人物：生産者 / 消費者
   ├─ 立ち上げ手順（4段階）
   │  ├─ 自ら生産者となり消費者を集める
   │  ├─ 両方を兼ねる存在を呼びこむ
   │  ├─ 生産者が魅力的な道具を配る
   │  └─ 他の生態系に「タダ乗り」する
   ├─ 実装する基本機能（4）
   │  ├─ 生産者と消費者のマッチング
   │  ├─ 信用を可視化する
   │  ├─ ルールとペナルティの策定
   │  └─ 自助努力を促す仕組み
   ├─ 強化する仕組み（5）
   │  ├─ 価値の重ね合わせ / コミュニケーションの促進 / ヒエラルキーの確立
   │  ├─ 流動性の確保 / 不確実性の担保
   └─ 参加者を熱中させる仕掛け（5）
      ├─ ランダム・フィードバック / 届きそうな目標の設定 / 難易度のエスカレーション
      └─ 社会的相互作用の可視化 / 進歩している実感の提供
```

## 本プロジェクトへの対応づけ(affordance / observable として)

| 世界2.0 要素 | 役割 | 対応する分野 | seam |
|---|---|---|---|
| 基本3要素(自律的/有機的/分散的) | 設計原理 | 複雑系・自己組織化 / ALife | engine, vision |
| 価値の3分類(実用/感情/社会) | observable | 経済学(価値論) / 社会学 | observer/measure |
| 生産者/消費者 | affordance(役割は固定せず創発) | プラットフォーム経済学 | actions, observer |
| 立ち上げ手順4段 | ⚠️ 研究者は実行しない(injection) | 社会運動・拡散 | (観測のみ) |
| 基本機能4(マッチング/信用可視化/ルール/自助) | affordance | メカニズムデザイン / 制度経済学 / 信頼・評判 | actions, world |
| 強化5(価値重ね/疎通/階層/流動性/不確実性) | affordance+observable | 組織社会学 / 市場経済学 | actions, observer |
| 熱中させる仕掛け5 | ⚠️ affordance/observable 限定 | 行動経済学・ゲーミフィケーション | (慎重に) |

> ⚠️ 「立ち上げ手順」「熱中させる仕掛け」は設計者の介入色が濃い。これらを**研究者が実行/hardcode すると指紋**になる。affordance として"可能"にとどめ、創発するかは**観測**する。

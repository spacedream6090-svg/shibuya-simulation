# 分野6 概観 — 集合行為・制度経済学・フレーミング(M1指標d + Bundle C の資源・制度)
- 分野: actions, factors/update, labeling, observer | 重要度: P0
- 出典: Olson 1965(集合行為の論理/フリーライド)/ Ostrom 1990(コモンズの統治/8原則)/ Benford & Snow 2000(フレーミング, Annual Rev Sociol 26:611-639)

## 中核機構
- **フリーライド(Olson)**: 合理的個人は集団財に貢献しない(貢献せずとも便益を得る)。**集団が大きいほど free-riding は強まる**。→ M1(d) 集団的高コスト行動の**最大の障壁**。★スケールの逆説: 大集団=自動で協調ではない(Olson は逆を主張)。Moltbook と整合。
- **制度による解決(Ostrom)**: Hardin の「コモンズの悲劇」に反し、共同体は CPR を自己統治できる。**8設計原則**(境界 / congruence / 集合的選択 / 監視 / 段階的サンクション / 紛争解決 / 組織権の承認 / 入れ子構造)。→ **「世界改変 = 永続的制度の創発」**。世界2.0「ルールとペナルティ」の affordance。
- **フレーミング(Snow & Benford)**: collective action frame = 運動を正当化する行動志向の信念。3機能: **診断(問題の命名)→ 予後(解決策)→ 動機づけ(行動喚起)**。

## ★ §4 統一チェーンの完成(M1 エンジン全体が文献接地)
```
不満(分野3 grievance)
 → "名前"を得る = 診断フレーム(分野4 labeling / Snow&Benford 診断)
 → complex contagion で伝播(分野5)
 → コミット少数派が tipping(分野4 Ashery/Centola ~25%)
 → 動機づけフレームで高コスト行動へ、フリーライドを制度創発で克服(分野6 Olson/Ostrom)
 = 世界改変者コホートが集団変化を駆動
```

## 効く seam / no-fingerprint
- `actions`(Bundle C): 制度形成(ルール/サンクション/監視/資源プール)を **affordance** として可能に。**協調も制度も hardcode しない** — フリーライドは個人合理性から創発し、制度は作られれば創発。
- `observer/measure`: free-riding 率 / Ostrom 8原則の出現 / フレーム型(診断・予後・動機)を事後測定。
- `labeling`: ラベルは collective action frame になりうる(診断→予後→動機)。labeling と動員を接続。

## P1 経済系をここに畳む
- 市場・メカニズムデザイン(生産者/消費者・マッチング・流動性)= 制度の一種。信頼・評判 = Ostrom の監視・サンクションの前提。→ 個別 deep-dive でなく本チェーンの affordance として扱う。

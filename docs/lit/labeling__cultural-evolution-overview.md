# 分野4 概観 — 文化進化・社会言語学(ラベル創発 / semantic drift)
- 分野: labeling(OPEN#4)/ propagation / observer | 重要度: P0
- 出典: Ashery, Aiello & Baronchelli 2025(Science Advances, LLM naming game)/ Centola et al. 2018(Science, tipping ~25%)/ Baronchelli(minimal naming game)/ Centola & Baronchelli 2015(PNAS)

## 中核機構
- **Naming Game**: ペア局所相互作用で form-meaning 慣習(=ラベル)が共有化する。ラベル創発の形式モデル。
- **Ashery 2025(LLM集団)**: ①局所相互作用で慣習が自発創発(**非ブロードキャスト**)②個体に偏りが無くても**集団バイアスが創発**(個体レベルで不可視)③tipping point ④**コミット少数派が多数派の慣習を覆す**。
- **Centola 2018(ヒト実験)**: コミット少数派が **~25%** の臨界質量で多数派を反転できる。

## 我々への含意(M1 の中核)
- **drift/分岐(M1指標c)= Ashery の「集団バイアスの創発」**。個体バイアス無しでも創発 → **injection でなく創発**(no-fingerprint に完全合致)。設計せず観測する。
- **非ブロードキャスト伝播が正しい**: 局所ペア相互作用で慣習が創発し、かつ drift も生む。全員記録=broadcast は Moltbook 型崩壊。
- **tipping/コミット少数派 = 世界改変者コホートが集団変化を駆動(§4 統一)**。~25% を参照閾値に観測。
- M1(d)→M2/M3 の橋: コミット少数派の tipping を測る = 改変者コホートの集団効果の測定。

## 効く seam / no-fingerprint
- `labeling/constrained`(OPEN#4): naming-game 型(候補プール + ペア採用 + drift 計測)。Ashery/Baronchelli が接地。
- `labeling/propagation`: 局所ペア(非ブロードキャスト)。集団バイアス/drift は**創発 → 観測**(hardcode しない)。
- `observer/measure`: 慣習採用曲線 / 集団バイアス / tipping 閾値(~25% 参照)。
- **期待較正(handoff §4)**: LLM は新語形をほぼ作らない。**既存語の再結合・転用(スラング化=意味的革新)**が出る。これは欠点でなく drift spec に乗る。

# 分野3 概観 — state 更新則(OPEN#2)
- 分野: factors/update(OPEN#2)| 重要度: P0
- 出典: van Zomeren, Postmes & Spears 2008(SIMCA, Psych Bulletin 134(4):504-535, 182効果のメタ分析)/ Morrison & Phelps 1999(Taking Charge, AMJ 42:403-419)/ Bandura 4源泉(分野2)

## 各 state と因果入力(magnitude でなく causal structure のみ)
| state | 因果入力(どの出来事/相互作用で動くか) | 出典 |
|---|---|---|
| 自己効力感 | 達成 / 代理 / 説得 / 生理・情動(4源泉)。領域特異的 | Bandura |
| 不満・不公正感(grievance) | 不公正と知覚した出来事・結果(**affective が強い**)。抗議の失敗で ↑ | SIMCA |
| 集団効力感(group efficacy) | 「集団は変えられる」信念。抗議の成功/失敗で更新 | SIMCA |
| 当事者意識(felt responsibility) | 役割・環境の開放性・同一視で形成。**傍観者と主体を分ける** | Morrison&Phelps |
| 社会的/政治化アイデンティティ | 相互作用・共有された不満から創発。**grievance↔efficacy を橋渡し**。政治化で最強 | SIMCA |
| 統制の所在 | 「世界は行動に応答するか」を経験で更新 | Rotter(分野2) |

## ★ k(結合強度)の文献的接地 — 最重要
SIMCA は**フィードバックループ**を前提: 行動の成功/失敗 → grievance・効力感・アイデンティティ を更新し返す(Bandura も達成経験 → 効力感)。
→ **我々の k(経験↔内部状態の結合強度)= これらフィードバックループの"ゲイン"**。
- 低 k: 経験で state がほぼ動かない → **init-determined(生まれつき寄り)**
- 高 k: 経験が state を強く駆動 → **path-dominated(創発寄り)**
- **k* 相転移 = このゲインが系を反転させる点**。→ k を魔法数でなく SIMCA/Bandura 由来の結合ゲインとして掃引する根拠。

## world-changing 行動(= 測定対象、入力にしない)
- taking charge(Morrison&Phelps)= 裁量的な変革着手行動 = world-changer の一種 → **事後測定**。
- ファネル: felt responsibility + efficacy + 環境開放性 → taking charge(実行フィルタ)。

## 効く seam / no-fingerprint
- `factors/update`: 上表の**因果構造のみ**を実装(方向と入力のみ、magnitude/決め打ち禁止)。k がゲインを掃引。
- `observer/measure`: grievance/効力感/当事者意識/改変行動を**事後測定**(構成概念を教えない)。
- SIMCA のフィードバックは「ダイナミクスが軸を相関させるか」を文献内で既にモデル化 = 観たい創発の理論的裏付け。

# 日本語感情辞書の選定 + 渋谷IPF周辺分布(RQ3+RQ4、2026-07-05 検収)

> フル調査: [../research/lexicon-ipf-shibuya.md](../research/lexicon-ipf-shibuya.md)(Opus 4.8 実行・Fable 5 検収)。

## 感情辞書(RQ3)→ 採用済み
- **採用: 東北大 乾・岡崎研 日本語評価極性辞書**(用言編+名詞編)。クレジット明記で再配布可 → `data/sentiment_lexicon.json` に同梱(pos 5,345 / neg 7,983。名詞は p/n のみ、曖昧 e は破棄)。
- 実装 `lang/sentiment.py`: 純stdlib・決定論。最長一致(形態素解析なし、い形容詞は語幹展開)+否定反転(〜ない/ません 等6形)+強調×1.5+絵文字。9テスト。
- 不採用: WRIME(CC BY-NC-ND=同梱不可・コーパスであり辞書でない)、oseti/pymlask(MeCab 依存)。既知の限界: 活用網羅・皮肉・多義語(「高すぎる」等)。

## 渋谷IPF(RQ4)→ 一部反映済み
- **実数(令和2年国勢調査)**: 渋谷区 夜間人口 **243,883**(男117,907/女125,976)、世帯149,856、**昼間人口551,344(昼夜比≈226%)** → 来街者比率 **0.56** と性比を `data/shibuya_population.json` に反映済み。産業は第3次90.9%。
- **未確認(取得元は特定済み)**: 年齢5歳階級×性別の区実数 / 職業大分類の区実数(statsDataId **0003176482**)/ 昼夜間人口の正確値(sid **0004003060**、常住人口243,883 vs 230,609 の資料間齟齬あり)/ 丁目別。
- 最短手順: 渋谷区公式ページの Excel 直DL(appId不要)。API は e-Stat 利用登録で appId 発行。
- → 年齢帯・職業 share は**暫定**のまま(ファイルに明記)。差し替えは shibuya_population.json のみ。

# 大規模人工社会シミュレーション — 設計ハンドオフ (v0.1)

> **この文書の目的**：Claude Code への実装ハンドオフ。これまでの設計議論を、**決まったこと (DECIDED)** と **まだ決めてないこと (OPEN)** に分けて整理したもの。
>
> **重要な読み方**：このプロジェクトの一貫したテーマは「**設計者の指紋を最小化する**」こと。OPEN 項目を実装の都合で勝手に確定させないこと。確定が必要な箇所は、決定を後から差し込める"継ぎ目 (seam)"として実装してほしい。
>
> **北極星**：AI住民が自律的にコミュニティ・文化を進化させる「生命のように変化する人工社会」。今回はその基盤技術。発想源は佐藤航陽『世界2.0』。

---

## 1. 研究の問い

### 中核仮説
> **世界を変えようとする個体は、生まれつき存在するのか、それとも環境から創発するのか。**

世界改変者や起業家を**直接実装しない**。経験と社会環境で変化する内部状態から、改変者が自然発生するかを観察する。

### 再定式化（DECIDED — ここが方法論の肝）
「生まれつき vs 創発」を二択で問うと**反証不能**になる（初期分布も更新則も研究者が設計するため、何が起きても設計の帰結になる）。そこで問いを**分散分解 (variance decomposition)** に置き換える：

- 最終的な world-changing 行動量を、**初期パラメータ群で回帰**する。
- R² が高い → 初期条件支配レジーム（「生まれつき」寄り）。
- R² が低く経路依存が強い → 創発レジーム。

さらに、**経験↔内部状態のカップリング強度 `k` を掃引**し、系が init-determined から path-dominated へ移る**相転移点 `k*`** を探す。最終的な発見は「生まれつきか創発か」ではなく「**`k*` を境に系が相転移する**」という測定可能な形になる。

---

## 2. 主体性と世界改変の操作化（DECIDED）

- **主体性 (agency) = 思考頻度**（自発的に思考を始める頻度）。これは認知の**"量"**。
- **世界改変 = 認知の"向き"**。主体性の**サブタイプ**。よく考える個体が、不安で反芻するだけ／計画して動かない、こともある。思考頻度はそこを区別しない。
- したがって「思考頻度＝主体性」は維持。ただし「思考頻度＝世界改変」**ではない**。

### ファネルモデル
世界改変は並列の足し算ではなく、各段を別の因子がゲートする逐次フィルタ：

```
思考が生じる        → 世界に作用する意図が固まる → 高コスト行動を実行する
(上流ゲート)           (信念フィルタ)                (実行フィルタ)
```

- 世界改変者は、これら因子が**揃って高い角 = joint upper tail** にしか存在しない。
- だから改変者は希少。どれか1つが希少だからではなく、**conjunction（連言）が希少**だから。これは「改変者はレアで創発的であるべき」という直感に合致する。

## 3. 因子設計（DECIDED — 文献ベース）

### 設計原則
1. **メカニズムに焼き込まない**。`world_change_drive = f(...)` のようなハードコードは禁止（設計者の指紋が残る）。
2. 因子は**初期条件に置く or 経験から創発させる**だけにして、「誰が改変者になったか」を**事後測定**する。
3. 論文の結論を直接実装しない。「成功→効力感+10」のような決め打ちを避け、**確率的・因果的な傾向のみ**導入する。

### trait / state の切り分け（最重要）
元の3要素（思考頻度・自己効力感・リスク許容度）は trait と state を混ぜていた。文献に基づき分離する：

| 因子 | 役割 | 分類 | 文献 |
|---|---|---|---|
| 思考頻度 (Need for Cognition) | 上流ゲート：熟慮が起動するか | **trait（初期）** | Cacioppo & Petty 1982 |
| リスク許容度 | 実行フィルタ：コストを払うか | **trait（初期）** | 起業オリエンテーション文献 |
| 内的統制 (locus of control) | 「世界は行動に応答する」信念 | trait寄り（経験で動く） | Rotter |
| 好奇心 / 未来志向 | 探索・先行行動の傾向 | trait（初期） | Parker & Collins 2010 |
| 自己効力感 (self-efficacy) | 「自分は実行できる」 | **state（経験で構築）** | Bandura 1977/1997 |
| 不満 / 不公正感 (grievance) | 動機源：そもそも変えたいか | **state（出来事から）** | van Zomeren 2008 (SIMCA) |
| 当事者意識 (felt responsibility) | 傍観者と主体を分ける | **state** | Morrison & Phelps 1999 |
| 社会的アイデンティティ | 個人→運動の橋 | **state（相互作用から）** | van Zomeren 2008 (SIMCA) |

### この切り分けがなぜ効くか
- state 変数（不満・効力感・当事者意識・同一視）を**初期に焼き込まず経験から立ち上げれば**、「環境が改変者を作った」が設計の artifact ではなく**本物の発見**になる。
- 改変者になる個体 = 履歴がたまたま state 変数を joint tail に押し上げた個体。**その軌跡を追える**。

### 補足知見（実装に効く）
- **思考頻度は量であって向きではない**ことは実証済み：NFC が高いと思考"量"は増えるが、より良い決定が出るとは限らず、元の偏りをむしろ増幅しうる。
- **LOD の心理学的正当化**：認知的努力は「常時」ではなく「stake が高いとき」に配分される（metacontrol）。LOD は計算ハックではなく人間認知の近似。
- **自己効力感 ≠ 内的統制**：前者は「この行動を実行できるか（領域特異的）」、後者は「世界は行動に応答するか（一般的）」。世界改変者には**内的統制の方が load-bearing**。両方を別変数として持つ。
- **SIMCA はフィードバックループ込み**：行動の成功・失敗が効力感と不満に影響し返す。観たかった「ダイナミクスが軸を相関させるか」が文献内で既にモデル化されている。
- **`Bystander Lab` という名前との符合**：bystander effect の反対が felt responsibility。

## 4. ラベリングと創発（DECIDED — 方向原則）

### 中核原則
> **エージェントは "世界" にラベルを貼る**（創発する文化を、外から伝播として観測）。
> **研究者は "エージェント" にラベルを貼る**（心理学的構成概念を、行動から測定）。

外的・集団的現象はエージェントの frame、内的心理状態は観測者の frame。**この2方向を混ぜない。**

### 内的状態はエージェントに生成させない（観測者frame）
- LLM は「自己効力感」が何かを既に知っている。エージェントに自己生成させると、研究者の指紋が**LLM事前学習の指紋**に置き換わるだけ（不可視で制御不能なぶん悪化）。
- 自己報告は、観たい創発現象そのものに汚染される（「成功した→高い効力感を報告」という訓練済みの物語を演じる）。
- **実装**：エージェントは効力感という構成概念を**与えalso引き出しもせず**、ただ生きる（行動・内省・会話）。**研究者が外から post-hoc で**、行動ログ・発話ログを LLM-judge / 分類器で採点する。エージェントにその構成概念の存在を一度も教えない。完全可観測性（「世界全体をセンサー化」）を活用。

### ラベル創発＋伝播（エージェントframe）
- 直感は実証的に裏付けあり：Ashery et al., *Science Advances* 2025（naming game で、分散集団から普遍的慣習が自発創発。記憶＋自己強化＋ペア相互作用。コミット少数派が臨界規模で慣習を覆す）。
- **「全エージェントが即記録」は禁止**。それはグローバルブロードキャストになり、本プロジェクトの中核現象「**信念・噂の分岐 + semantic drift**」を破壊する。
- **正しい実装**：ラベルはネットワーク（直接会話・立ち聞き・ブロードキャストの知覚チャネル）を通じて**不均一に、歪みながら**伝播する。普遍化するかは**観測対象**であって前提ではない。伝播過程で生まれる集団バイアスこそが分岐現象。
- **トリガーの統一**：ラベリングの起動 = **LLM 起動トリガー（驚き / 違和感 / 予測誤差）**。既存記憶に収まらない事象 → LLM 起動 → 可能な行動の一つが「名前をつける」。別 system を足さない。
- **期待値の較正**：LLM エージェントは新しい語形・私的言語をほぼ作らない。**既存語の再結合・転用（スラング/ジャーゴン化＝意味的革新）**が出る。これは欠点ではなく、semantic drift spec にそのまま乗る。「異星人の言語」は期待しない。

### 統一ペイオフ（2スレッドが1つになる）
ラベリング system は別実験ではなく、**世界改変者の問いの個人→集団の橋（エンジン）**：
- 共有された不満が**名前を得た瞬間**、個人の不満が集合的になる ＝ 社会運動のフレーミング理論（Snow & Benford）。
- Ashery の「コミット少数派が tipping point を超えて慣習を覆す」＝ **世界改変者コホートが集団変化を駆動する**。
- → 「世界改変者の創発」と「ラベルの創発」が**1つの現象**になる。

## 5. 制約（DECIDED）

- **GPU：A5000×7 / 168GB VRAM、利用可能期間は10日間（hard wall-clock 制約）**。これは因子数・掃引軸数・seed 数を直接縛る。`k*` 相転移の測定には同一条件の複数 run が要るため、**因子の絞り込みは美学ではなく計算予算上の強制**。
- **LOD**：全エージェントを常時 LLM で動かさない。通常は状態機械・統計モデル・行動ルール。LLM は会話・強い感情変化・驚き・違和感・チャンス発見・自発的思考開始などのイベント時のみ起動。
- **llm.fleet**：高認知エージェントに大モデル、ルーチンに小モデルを割り当てる階層構成（168GB クラスタで実現可能）。
- 独立プロジェクト。**shibuya-sim のコードは引き継がない**（問いが違うため設計を素直に保つ）。

## 6. 未決定事項（OPEN — Claude Code は勝手に確定しないこと）

これらは設計判断であり、ユーザーとの議論で決める。実装では**継ぎ目を用意するだけ**にする。

1. **因子の down-select**：初回 run に載せる最小因子セット。
   暫定案（要合意）：初期trait = {NFC, リスク許容度, 内的統制}、emergent state = {自己効力感, 不満, 当事者意識}。社会的アイデンティティ・集団効力感は第2弾（集団レイヤー）に回す。
2. **state 更新則**：不満・効力感・当事者意識が「どの出来事で」動くか。決め打ち（+10）を避け、因果構造だけ文献接地する。← **次に詰める最有力候補（これが決まらないと実験が定義できない）**。
3. **初期分布**：trait の分布形と分散。GSE 尺度・NFC 尺度の母集団分布から逆算。
4. **ラベリングの粒度**：初回を **制約版（naming-game 的・候補プール＋伝播＋drift計測、tractable）** にするか **オープンエンド版（驚きトリガーで自由生成、新規性高いが mush リスク）** にするか。
5. **storage アーキテクチャ**：何をログするか（per-agent 主観 digest、4チャネル知覚ログ、ラベル伝播＋drift トレース）で決まる。兆し（SQLite + pgvector + Obsidian）が射程内。**観測指標が固まってから逆算**。
6. **スケール**：概要は5万〜10万体だが、shibuya-sim の150〜200体から3桁のジャンプ。初回の現実的な規模を要再検討。
7. **アクション空間（＝最大の実務リスク）**：エージェントは世界に対して具体的に何ができるか。歩いて喋るだけだと、起こりうる最大の改変は「コミュニティ形成＋噂の伝播」まで。経済圏形成・都市構造変化を観たいなら、空間占有・POI生成・資源の蓄積と移転・永続構造物の構築などのアフォーダンスが要る。**「injection なしの純粋創発」はアクション空間が貧しいと「何も起きない」に振れる**。観測対象を到達可能にする設計が必要。

## 7. 実装の入口（提案）

OPEN 項目に対して不変な骨格から scaffold する。決定が差し込まれる箇所を seam にしておく：

1. **Agent core**：最小デモグラフィック（性別など）からの persona、長期記憶ストア、知覚チャネル（物理＋SNS）。
2. **LOD / イベント駆動ループ**：驚き・予測誤差の検出 → LLM 起動。**ラベリングトリガーをこの起動と同一**にする。
3. **観測者frame ロギング層（最重要・不変）**：完全可観測性で全ログを残し、構成概念を**後から外部測定**できるようにする。これがないと中核の測定ができない。
4. **Factor モジュール（pluggable）**：trait/state の集合を差し替え可能に。**因子リストをハードコードしない**（OPEN #1 の seam）。
5. **Labeling モジュール（pluggable）**：制約版 ⇄ オープンエンド版をスイッチで切替（OPEN #4 の seam）。**「全員記録」は実装しない**。伝播は知覚チャネル経由・drift あり。
6. **記憶圧縮**：日中は詳細ログ、睡眠時に要約・抽象化・意味付けして長期記憶へ圧縮（例：「広告を見た／友人と議論した」→「環境問題への関心が高まった」）。

## 付録：主要文献
- Bateman & Crant (1993) — proactive personality（"状況に縛られず環境に変化をもたらす個体"）。直接実装はしない／antecedents を使う。
- Cacioppo & Petty (1982) — Need for Cognition（思考頻度の trait 化）。
- Rotter — locus of control（内的統制 ≠ 自己効力感）。
- Bandura (1977/1997) — self-efficacy と4源泉（達成経験・代理経験・社会的説得・生理的状態）。更新則の入力にほぼ対応。
- Morrison & Phelps (1999) — taking charge の先行因（felt responsibility / self-efficacy / 環境の開放性）。
- van Zomeren, Postmes & Spears (2008) — SIMCA（不公正感・集団効力感・社会的アイデンティティ＋フィードバックループ）。
- Snow & Benford — framing theory（grievance の命名＝動員）。
- Ashery et al., *Science Advances* (2025) — LLM 集団での慣習の自発創発・集団バイアス・tipping point・コミット少数派。

## 0. 一言でいうと

「聞こえた全員を処理する」現行を、人間と同じ**4段の注意パイプライン**に置き換える:
**①前注意(全入力・軽量算術)→②優先度マップ(top-k競合)→③有限ワークスペース通過分だけ深処理
(記憶・関係・プロンプト)→④注意予算による関係の自然制限**。
層A=①-③をエンジン算術で(呼ゼロ・決定論)。層B=③のワークスペースを**LLM自身が構造化出力で
編集する注意ブロック**に昇格(追加呼ゼロ・SNC方式の相乗り)。

## 1. 文献総括(設計を支える5本柱)

1. **「非注意の発話は記憶に残らない」は実験的事実**(Cherry 1953・Wood & Cowan 1995)。現行実装
   (聞こえた全員を記憶・台帳化)の方が人間から乖離=ATTは近似でなく**人間の実装そのもの**。
2. **容量の設計定数が定量で存在**: 深処理k=4±1(Cowan 2001)・会話上限4人(Dunbar 1995実測)・
   カクテルパーティ貫通率p≈0.33(自己名・個体差0.20-0.65=Conway 2001)。
3. **優先度の統一式**(Wolfe GS6 2021): priority=w_bu·顕著性+w_td·目標関連+w_h·履歴+w_v·価値。
   除算正規化(Reynolds-Heeger 2009)で「混雑時は1人あたり処理が薄まる」=**Milgram都市過負荷(1970)の
   内生化**(計算モデル未確立=新規性候補)。
4. **容量制限は統計則再現の必要条件**(独立6実証: Weng 2012重尾・Gleeson 2014のα<2臨界・
   Gonçalves 2011のDunbar飽和・ほか)=「入れないと現実のSNS統計が出ない」方向の証拠。
5. **新規性**: 「有限スロットの社会的注意を構造化出力で自己宣言・永続化」の直接先行なし(最近傍=
   MEM1の全量再宣言・PIANOのボトルネック・MetaGPT購読)。OASISの「候補=エンジン/選択=LLM」二段が
   100万体で実証済み=層Bの分業設計の裏付け。

## 2. 層A: ボトムアップ顕著性選抜(エンジン算術・呼ゼロ)

**挿入点**: scheduler.pyのspeak-hear配布ブロック(S15と同一点)。S15(距離top-K)を**上位互換で置換**
(S15はattention.mode: distanceとして残す=縮退線)。

**式**(発話ごと・聴取候補ごとにO(1)):
```
salience_i = 距離減衰(既存) × (1 + α_nov·新奇語 + α_emo·|情動価| + α_addr·宛先性)
priority_i = w_bu·salience_i + w_td·relevance_i + w_h·history_i + w_v·value_i
  relevance = 話者・話題タグと自分のdrive/日課タグの一致(既存タグの照合のみ)
  history   = 直近D日にこの話者を注意した回数(飽和つき・プライミング)
  value     = closeness/tier(関係台帳)+ contacts/follows在籍 + 世帯・同僚・partner
選抜 = priority上位 k=4(会話参加中は会話相手を優先充当)∧ priority ≥ θ_ignition(点火閾値)
貫通 = 自己名・自己言及・自己関心タグの文字列一致 → p_break(個体・ハッシュ決定論)で閾値バイパス
```
**効果**: 注意通過分のみ remember/relations更新/C3/覚醒。非通過は**群衆1チャンク**(「周りが騒がしかった」
の集約1件・L1はhear集約行に置換可=体積も削減)。
**conf**: world.attention.{enabled, mode(distance|salience), k, θ_ignition, p_break_base, 重み4+α3}。
既定enabled:false=バイト一致。ON時はaffects_k=True(S15と同じ宣言)。

## 3. 層B: LLM自律宣言の注意ブロック(追加呼ゼロ)

**スロット構造**(agent.attention・checkpoint搬送):
```
K=7スロット(conf・Cowan4±1とLost in the Middle回避から5-9帯)
各スロット: {kind: person|place|topic|goal, target: id or 語, why: ≤20字, salience: float, since: step}
```
**更新の二重経路**:
- **発火時**(deliberate/reflect/planの既存呼に相乗り): プロンプトに現ブロック+**候補リスト**
  (エンジン提示=層Aのpriority上位・未処理の社会イベント・OASIS二段方式)を注入し、構造化出力に
  `attend: [{kind, target, why}]`(MEM1式・全量再宣言)を追加。SNCのrelate/followと同じ後置フィールド
  =**追加呼ゼロ**・mockはフィールド不出=欠落で現状維持。
- **非発火時**(全員・毎日): Ebbinghausな減衰(MemoryBank方式・decay定数conf)+イベント駆動boost
  (自分宛て発話・スロット対象の可視イベント=算術のみ)。
**プロンプト注入**: 固定位置(システム節直後)に「いま気にしていること」節(Lost in the Middle対策)。
Attention Schema理論(PNAS 2021)=自分の注意状態を読める形で持つと注意制御が向上、の実装。
**層Aとの結合**: 宣言済み対象は層Aのw_tdに持続ボーナス=トップダウン注意の実体。
**「すべてのもの」への拡張**: kindにperson以外(place/topic/goal)を最初から持つ=語・場所・目標を
同じブロックで追える(関係台帳は人だけ・注意ブロックは全種=役割分担)。

## 4. 関係台帳との統合(REL→CogSNet正準形へ)

認知科学レーンの発見: **CogSNet**(Michalski et al. 2021, Complexity)=関係重みを記憶痕跡として
「イベントで強化w←μ+w(1-μ)・無イベントで減衰(λ)・**w<θで辺を刈込**」の3パラメータモデルが
実データ(NetSense)で人間の関係認識の再現を有意に改善済み。
→ REL設計(ram-rootcause-and-fix-plan.md §REL)の忘却基準を**CogSNetのθ刈込として実装**すると
文献的に最強(既存decay_per_day線形はλ指数の特殊形として整理)。層A採用時はrelations流入自体が
O(k)化するのでRELは第二線の保険に降格。較正指標: アクティブ紐帯~150への自己組織化・
social signature形状(Saramäki 2014)・層比≈3(Zhou 2005/Tamarit 2018)。

## 5. 導入のメリット(ユーザー質問への直答)

1. **爆発の根治**: 記憶・関係・観測の書込がO(聴衆数百〜数万)→O(k=4)。RAM試算: relations steady state
   100GB級→10-25GB(S15単独比でも観測列が桁で軽くなる)。step時間の密度依存劣化も同根で解消。
2. **現実整合の向上**(近似ではなく): 容量制限なしでは実SNSの統計則(重尾・Dunbar飽和・α<2)が
   出ないという独立6実証。「注意を入れる=現実の渋谷に近づける」が文献で言える。
3. **新規性**: 有限スロット社会的注意の自己宣言=直接先行なし。Milgram過負荷の内生的創発も未計算化領域。
4. **観測資産**(提出物・論文のユニークデータ): 注意グラフ(誰が誰の注意を得たか)・受信注意Gini
   (実SNS≈0.94との比較)・Milgram勾配(密度vs知覚率)・注意の時間則(話題滞在時間分布)。
5. **k*研究の核心への接続**: 「社会を変える人」の前提=注意を集めること。注意の不平等の形成過程を
   最初から観測できる=審査基準「連鎖・創発の観測」の解像度が上がる。
6. **層Bはエージェントの自律性の実装**: 「LLM自身が何に注目するか選ぶ」=ユーザーの原案そのもの。
   行動の一貫性(なぜその行動をしたか=注意ブロックが説明)がday_traceで読めるようになる。

## 6.5 個体差設計(2026-08-19ユーザー指示「4人固定にせず個体ごとに変化・LLMが決める・閾値+topKの併用」)

- **k_i の個体化**: k_i ∈ 2-7(基底4)をペルソナからblake2b決定論導出。文献根拠=Cowanの「4±1」の±1・
  Conway 2001(WM個体差)・Alvarez & Franconeri(負荷と容量のトレードオフ)。
- **閾値+topKの併用**(ユーザー第3案=採用): θ_ignition未満は k_i に満たなくても拾わない=
  kは上限でありノルマではない。静かな住宅街では1-2人・スクランブルでは上限まで、が自動で出る。
- **貫通率の個体化**: p_break_i ∈ 0.20-0.65(基底0.33)をWM系特性から決定論導出(Conway実測レンジ)。
- **LLMが決める**(ユーザー第2案)=層Bそのもの: attend宣言→w_td持続ボーナス→関係形成へ。
  さらに注意→closeness↑→次の注意確率↑の**個体内rich-get-richerループ**が働き、新奇性項とIoRが
  それを拮抗=「誰と関係を持つか」の個体差は k_i・p_i・θ・宣言の4源泉から創発する。
- **較正指標**: Saramäki social signature(個人固有の配分形状が時間を跨いで保存)が出るか。

## 6.6 実装決定(2026-08-19・ユーザー「実装自体はやるべき」承認)

- **層A+層B両方を実装**。層A=finals ON予定(値は8/20判定で最終化)・**層B=conf既定OFFで実装し、
  プローブ(宣言率・スロット内容の質・8B/14B)を経てから本選ONを判断**(SNC/第140教訓との両立)。
- hear L1: attention ON時は注意通過分のみhearイベント記録・非通過はrememberもL1も無し(Cherry準拠)・
  群衆チャンクは記憶1件のみ(新L1 kindは作らない=schema/causality不触)。
- SNC note_encounterも注意通過分のみ(知覚しない相手とは遭遇も数えない=一貫)。
  conversation.py C2/C3(共在ベース)は別経路のため不触(既にC3P capで有界)。
- 注意スロットはdehydrate/rehydrate搬送に追加(第113認知棚卸しの搬送漏れ教訓)。

# エージェント自由度の拡張計画(第16バッチ 2026-07-10・計画のみ・実装なし)

体制: Fable計画 → Opusリサーチ(docs/research/agent-freedom-audit.md)→ Fable統合計画(本書)。
ユーザー依頼: 「今のシムでエージェントにどれぐらい自由度があるか調べ、現実と比べて足りない分野の実装計画を .md に」。

## 監査の結論(要旨)
1. これまでの「自由度」は**内的自由度**(agency=思考頻度、k=信念書き戻し)に集中しており、
   **行動的自由度**(選べる行動の広さ)の正面監査は今回が初。
2. LLM が行動を選べるのは「drive 発火時」と「話しかけられた時」のみ。選べるのは発話系
   (speak/post/dm/coin_label/wander)+改変5ツール(host_event/post_flyer/found_group/
   propose/open_venture)+朝の plan(非拘束)+夜の reflect。**`move_to`(行き先の能動選択)
   すら存在しない**。
3. **生活の自己決定はほぼ全てルール強制**(拒否権なし): 就寝・出退勤・通勤手段・食事・消費・
   家賃・解雇/転職(日次確率)・家族形成(確率)・受診・逸脱。「仕事に行きたくないから休む」
   「引っ越す」「辞める」をエージェントは選べない。
4. 教訓(world-change-motivation.md): **affordance を2,654回提示しても行使0回**の実測がある。
   行動空間を広げるだけでは行使されない — 動機(不満・欲求・興味)との接続が対で必要。
   ただし動機の注入はしない(no-fingerprint)— 接続は「発火理由と選択肢の意味的対応」で作る。

## 設計原則(全項目に適用)
- **R1**: 新アクションは既存の同じ1呼の応答 JSON の選択肢を増やすだけ=**呼数不変**。
- **決定論**: 新たな確率が要る箇所は新 stream のみ(例: "career_choice")。既存 draw 不変。
- **既定 OFF**: `freedom:` config ブロックに集約し、既定=現行と完全同一(ゴールデン保護)。
- **中立提示**: 選択肢はメニューに置くだけ。促進・誘導の文言は書かない(coin_label と同じ流儀)。
- **観測**: 全新アクションの提示回数/行使回数を L1 で記録し「自由度の行使率」を測れるようにする。

## 実装計画(優先度順)

### P1 — 研究関連度「高」: 生活の自己決定の中核(次の実装バッチ候補)
| # | 新アクション | 内容 | 制約(現実準拠) | 触るモジュール | リスク |
|---|---|---|---|---|---|
| 1 | `quit_job` | 自発的退職(無職に。貯蓄で生活) | 覚醒時のみ。退職金なし | economy/career+deliberate | 失業率が較正バンドを外れうる→daily 7日実LLMランで行使率を実測して調整 |
| 2 | `apply_job` | 求職(空きのある org へ応募) | 無職 or 在職(転職)。採否=新stream "career_choice"(能力・評判で確率変調) | 同上 | 同上 |
| 3 | `move_to` | 自由時間の行き先を能動指定(POI名/カテゴリ) | 自由時間のみ(勤務・就寝窓は不可=現実の拘束) | routine(発火アクション追加) | 低(routine の EPR 抽選を LLM 指定で置換するだけ) |
| 4 | `skip_work` | 欠勤(その日は自由時間) | 賃金なし・評判低下(既存 reputation へ接続)・連続欠勤→解雇確率上昇 | routine+career | 労働時間の較正が緩む→行使率を監視 |
| 5 | `stay_up` | 夜更かし(就寝を1-2時間遅らせる) | 翌日の疲労増(既存 health.fatigue へ接続) | routine(bedtime 窓) | 睡眠較正(7.33h)への影響を監視 |
- 検証: _FixedLLM で ON/OFF 呼数完全一致・既定OFFゴールデン一致・行使率と較正指標
  (失業率・労働時間・睡眠)の実LLM 7日ラン再測定。
- **観測仮説**: 生活の自己決定が開くと「不満→行動」の経路が世界改変ツール以外にも分散する。
  k* 実験では自由度は全条件で固定(統制変数)。

### P2 — 関連度「中」: 選択の幅(P1 の行使率を見てから)
| # | 項目 | 最小実装 | 備考 |
|---|---|---|---|
| 6 | 住居移転 `move_home` | 空き住戸ノードへの転居(家賃差・敷金=現金障壁) | 地価=ノード人気の内生化はまだしない |
| 7 | 消費の意思 | 発火時の `buy`(欲しい物カテゴリ指定)。buy_prob 抽選は非発火時のフォールバックとして残す | 完全置換はしない(呼数を増やさないため) |
| 8 | 学び直し `study` | 学校 POI で聴講→語彙・技能(wage 上昇の小さな経路) | host_event 聴講の一般化 |
| 9 | 家族の主体性 | `propose_partnership` / `break_up`(相手の応答も発火時判断) | 出産・死別は世代交代設計と合わせて別バッチ |
| 10 | 軽微な逸脱 | 無許可出店・ビラ上限超過・門限破り(=既存制度の違反を「選べる」)→執行(既存 enforcement)と接続 | 暴力・実在人物は扱わない(R17)。規範違反→制度変化の研究経路 |

### P3 — 関連度「低〜中」: 見送り(理由つき)
- 投資・資産運用(経済複雑化に対して研究利得が薄い)/ 宗教・多次元思想(opinion の多次元化は
  FJ 力学の再設計が必要=大工事)/ 服装・外見(観測経路がない)。

## 自由度の観測指標(実装時に L2 へ)
- `freedom_choice_points`(その step で LLM に選択肢が提示された数)
- `freedom_exercised`(既定ルーチンと異なる選択をした数)→ **自由度行使率** = exercised/points
- 行使の内訳(アクション別)。k* 実験の交絡チェックにも使う(自由度は条件間で不変のはず)。

## やらないこと(明示)
- 動機の直接注入(「あなたは自由だ」等のプロンプト誘導)。
- 就寝・勤務窓そのものの撤廃(現実の拘束は現実性の一部。選べるのは「窓の中の逸脱」まで)。
- 本番検証中の渋谷シム本体への適用(基盤抽出=foundation-extraction.md と歩調を合わせ、
  既定 OFF ノブとして入れる)。

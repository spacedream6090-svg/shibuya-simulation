## 0. 要旨 — 指示書とリサーチと現状の三点一致

指示書の要求は、外部の先行研究とこのリポの実測の両方と**強く整合**する:

1. **エージェント/デバイス二分法**は MAS 理論の **A&A メタモデル**(Omicini/Ricci/Viroli, 2008: agents=能動・artifacts=応答のみ)そのもの。デバイス契約「自発遷移禁止」は **DEVS 形式**(δ_ext=入力応答 / δ_int=固定スケジュール)で機械検査可能な形に落ちる。
2. **tier0 の SoA 必須**(指示書§2.2)は、このリポの実測と一致: 現行オブジェクトエンジンは超線形(N=3000 で c=0.00166 s/体step、25万への外挿で目標の約100倍)であり、**SoA なしの 25万は不成立**。既存 `docs/plans/million-scale.md` の W2-A/W2-G と同じ結論・同じ目標値(c≈0.0002)。本計画はそれを吸収する。
3. **全事象への因果タグ+帰属率測定**は、調査した範囲で**先行例が見つからない粒度**(最近傍= SIMPROV/PROV-AGENT はいずれも「実験の来歴」であり「世界内イベントの因果」ではない)=論文化可能な新規性。しかもこのリポには単一チョークポイント(`observer/logger.py:115`)と provlink の「中央・任意・スコープ注入」前例が既にあり、**着地コストが異例に低い**。

## 1. 現状監査の結論(リポ監査2本の要点)

### 資産(移行を助けるもの)
- **L1 単一チョークポイント**: 194 kind 全てが `ObserverLogger.log()` を通過(201呼び出しサイト・迂回路ゼロ)。「アクター不在」は `agent_id=-1` として既に構造マーカー化(発行サイト約30〜53箇所/15モジュール=数え方の差)。
- **provlink(IF-A)**: `set_prov/clear_prov` スコープ+`_apply` での開閉= **「中央・任意・既定OFF・golden不変」のタグ注入前例がこの場所に実装済み**。cause_type/actor_id は同じ型で足せる。
- **昇降格ブリッジの実働前例**: `physics.py` の `_build_engine`(オブジェクト→配列)/`_writeback`(配列→オブジェクト)/`owned()`(排他トークン)+ mid-step 離脱の二重計上対策(`budget_scale`)まで解決済み。`world/sfm_core.py Crowd` は決定論設計込みの SoA 教科書実装。
- **決定論機構**: RngHub はステートレス(`stream(用途,id,step)` 契約=実行順非依存)、golden L1(13テスト直参照+約26テスト派生)、resume straight==split、`state_hash.py`(ステップ連鎖指紋=SoA 移行時の分岐特定ツール)。
- **分類表の家風**: `LUCK_KINDS`/`MONEY_KINDS`/`COVERED_KINDS` 等、kind→分類テーブル+既知リスト閉包テストの前例多数。

### 負債(移行の難所)
- **世界がティアを読んでいる**: scheduler の発火選抜(`_phase_drive`〜`_decide`)約140行が `a.drive/refractory/fire_weight` を直接読む=指示書§8/§10違反の主所在。ただし置換シームは既に `cognition/fire.py` が「発火機構の単一差し替え点」として実装済み。
- **動的属性88個**: `agent._x` の「属性が無いこと」を OFF スイッチとして使う流儀。SoA 行には「属性不在」が無いので全数に明示的等価物が要る。
- **`agent.route` 可変長**・**MemoryStore(30-60KB/体の支配項)**は SoA 不可=ホット/コールド分割必須(ホットは約40スカラー)。
- **checkpoint は agents 丸ごと pickle**: SoA 化で `config_hash` の `n_agents` 依存解消+npz サイドカー化が必要(million-scale.md 記載済み)。
- **SoA 以前の純オーバーヘッド 30-40%**: networkx バックエンド再走査・OmegaConf 深読み・`sentiment.valence`(自己時間7.75s/24step)・`dict.get` 5,070万回。**先に回収すべき無料の勝ち**。

### 棚卸しの分類結果(ワールドプロセス全数)
- **既に模範**: 天候(自然・専用stream)/宅配クーリエ(実エージェント)/truth_ledger の belief 帰属(from/hop/verified)/institutions.py(凍結制度)。
- **指示書違反が確定しているもの(§10照合)**: 価格変更(誰の行為でもない混雑ルール)・開店閉店(カテゴリ単位の時計関数)・在庫補充(発注者不在)・venture廃業(タイマー)・council選挙(voteイベント不在)・広告キャンペーン(広告主POIが実在するのに行為しない)・transit.suspended(自然扱いだが実態は事業者判断)・org_output(出席者名簿があるのに-1)。
- **serve 220/222 スタッフ不在の真因**: プール経路のエージェントに `work_node` が付かない被覆バグ+同一ノード共在条件。是正レバー(`work.bind_workplace`)は実装済み・既定OFF。

## 3. フェーズ計画

依存: P0→P1→P2→{P3, P4}→P7。P5 は並行の深トラック(P2/P3 は現行規模で先に成立させ、P5 が 25万を解禁)。P6 は P5 のファサード成立後(fire.py シーム作業のみ独立に先行可)。

### P0 因果の観測 — ゼロタッチ事後分類器(唯一の本選前候補)
- **内容**: `scripts/analyze_causality.py` 新設。194 kind→cause_type(agent|device|schedule|physics|natural|boundary)の分類表(監査結果を種にする)+actor_id 復元則(`agent_id`、-1 は NULL、**患者索引9種の上書き**: hear→speaker / opinion_shift→source / transmission→from / serve=staff / deliver→courier / venture_sale=owner / enforcement・detention=officer / gossip_spread→sources / flyer系→author)。出力= kind×cause_type 行列+kind別エージェント帰属率+未分類 kind の検知(既知リスト閉包)。
- **エンジン・conf・凍結14本: 一切触らない**(新規スクリプト+テストのみ)。
- **価値**: 本選10日ランのデータにそのまま適用でき、**移行の t=0 基線**(帰属率がフェーズごとに上がっていく様が測れる)になる。指示書§5.2 の測定量が今週から出せる。
- **検収**: 分類表の全数性テスト(EVENT_KINDS 全キー被覆・新 kind は分類まで fail)・実ラン2本での実測・フルゲート。規模: 実行役1レーン(半日〜1日)。

### P1 因果台帳の本体化(エンジン内・既定OFF)
- Event に `cause_type`/`actor_id` を既定 None で追加(201 サイト無改変)→ `logger.set_cause` スコープ(provlink と同じ構造=OFF 時は分岐到達不能で golden バイト一致)→ L1 2列(ON時のみ)。型付きコンストラクタ `Cause.agent/device/schedule/physics/natural/boundary`。`_apply` スコープでエージェント行為の全サブツリーが自動帰属。
- テスト: kind→許容 cause_type の閉リスト・OFF バイト一致・ON で P0 分類器と一致(相互検証)。
- 規模: 小(2-3日)。検収に P0 が効く。

### P2 デバイス形式化(DEVS 契約)
- デバイスレジストリ(device_id 空間・応答関数契約)。形式化対象: **SignalGate**(既に純スケジュール=識別子と相転移イベントを付与)・**envfeedback**(駅デバイス化)・**改札(新規: 60人/分/通路の待ち行列サーバ・実測較正)**・transit.suspended(自然→事業者デバイスに再分類)・課金/家賃/利息などの自動振替(制度デバイス)。
- 車両信号(`traffic.py` のハッシュ赤比率)と SignalGate の**矛盾を解消**(監査発見)。
- **デバイス自発性監査テスト**: L1 上で device 帰属イベントに同stepの入力 or スケジュール項が無ければ fail(指示書§1.2 の機械化)。
- 規模: 中(3-5日)。改札は新規シミュレーション内容を含む。

### P3 スタッフのアクター化(指示書§9の順)
- **3a 駅員・車掌**: 車掌=ドア閉判断エージェント(tier0)。**ダイヤ結合ループの内生化**: ホーム密度→乗降時間(+15人/車両≈+1秒・東京実証則)→続行遅延→滞留。ダイヤ自体は凍結制度・遅延と運休は行為に。
- **3b 店員**: まず `work_node` 被覆バグ是正+`bind_workplace` ON(220/222 の真因)。開店=店員の開店行為・仕入れ=調達行為・価格=店主の行為・廃業=オーナーの決断(タイマー廃止)。
- **3c タクシー/バス運転手**: 運転手エージェント(tier0)。ディスパッチはデバイスのまま可(指示書1.1の例示と整合)。
- **3d 誘導員・警備員**: 群衆制御行為。
- 全員: 同一 action API・tier0 規則・昇格可能。付随: council 選挙に vote 行為・広告主の出稿行為・org_output の出席者帰属。
- 規模: 大(3a+3b で1-2週・3c/3d で+1週)。

### P4 境界の再設計
- ポータルスキーマ(型付き)+**鉄道流入のパルス化**(ODPT時刻表駆動)+二系統台帳(計画駆動/統計)と人日保存則。
- **day_plan に圏外セグメント**: location に圏外値を許可し、境界 exit/entry を明示フィールド化(§4.2)=朝の計画がそのまま despawn/respawn 予定表。帰還時は「計画通り・特筆なし」圧縮記憶(コスト0・乱数0・決定論)。
- 較正: counts.xml 型フラットファイル+較正ループ(rw_fetch に大都市交通センサス等の取得を追加)。圏外の摩擦なし・流入固定の近似は実験条件に明記(§3.3/§4.4)。§4.5(既読ポインタ)は指示書通り**保留**。
- 規模: 大(1-2週)。

### P5 tier0 SoA エンジン(最深部・million-scale.md W2-A/W2-G を吸収)
- **前工程(SoA 不要の無料回収)**: ルートキャッシュ/自前A*・OmegaConf ホイスト・sentiment メモ化=実測30-40%回収。ここだけで c を再測してから本体に入る。
- 本体: ホット約40スカラーの SoA(Covasim型)+ファサード・pending-writes(フェーズ境界・id昇順適用)・世代付きID・昇降格はステップ境界+ヒステリシス+上限・**Philox カウンタ乱数**(tier0 系統のみ・新streamとして=既存stream不変)・route の ragged 化・MemoryStore はコールド側(million-scale.md の富記憶上限+LRUと接続)。
- 検収: hydrate∘dehydrate=恒等・`state_hash` 連鎖指紋での分岐特定・straight==resume(ティア割当=(seed,id,day)純関数)・サブシステム単位の strangler-fig(旧実装をオラクルに L1 同値を固定してから旧ループ削除)。**逐次→同期の意味論変化が避けられない箇所は「等価リファクタ」ではなく「モデル変更」として個別に承認を取る**(先行研究の落とし穴5)。
- 規模: 特大(2-4週)。

### P6 認知ティアの一般化+アブレーション純度
- 既存 LOD(routine/deliberate)を tier0/1/2 に形式化。scheduler の認知読み約140行を `fire.py` シーム背後へ移設(§8「世界はティアを読まない」を AST テストで機械固定=traces/rumors の家風)。
- 昇格=優先度キュー入場(構造イベント+surprisal+顕著性累積)・降格=エピソード境界+書き戻し契約・tier2 非同期。ティア構成は実行時conf+実験条件としてL1記録。all-tier0 ラン=従来型ABM がティア機構の有無でバイト一致。
- 均質化監視(coverage/uniformity/複雑度)を解析側に新設。
- 規模: 中-大(1-2週)。

### P7 渋滞ループの閉環+PoA 観測
- P2改札+P3a車掌+P4パルス流入が揃うと「改札→ホーム滞留→乗降超過→遅延→計画変更」が外生要素なしに閉じる(指示書§9の狙い)。FDリンク容量(マクロ)+ホットスポットSFMの二層は既存P2ゾーンハイブリッドの延長。
- PoA: 凍結需要ペア実行(共通乱数)・集約グラフSO(Frank-Wolfe)・需要スイープ・CI付き報告・情報PoA分解・渋滞情報伝播チャネル(既存 rumor 機構に接続=指示書§6.3)と集中/振動/転移(Waze現象)の観測。
- 規模: 中(1週)。**歩行者PoA=論文化候補**。

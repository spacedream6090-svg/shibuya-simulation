# 本選デモ案(第20バッチ 2026-07-12・計画のみ・実装なし)

接地: docs/research/social-simulacra-survey.md §5.2(デモ・訴求面)。ユーザー指示=「ひとまず案を考えておく段階」。

## 主役: 「身体を持つ都市」
競合(OASIS/SocioVerse/S3=SNSテキスト空間・Sid=Minecraft・Concordia=抽象)に対し、
**実在の渋谷(実地図・実ダイヤ・実POI)+較正済みの日常+テレポートなしの物理移動**は唯一無二の絵。
デモの全要素をこの一点に集約する。

## 5分デモの台本案(3幕)
1. **幕1「本物の渋谷が生きている」(90秒)**: 2Dビューワー再生(×1=実速度)。朝の通勤流入(実ダイヤ)→
   昼の人流→夜の帰宅。較正バンド表を横に出す(睡眠7.2h・労働7.1h・家賃比0.28…「現実と同じ数字で生きている」)。
   コミュニティ色分けに切替=「組織を強制していないのに集団が生まれ、割れて、戻る」。
2. **幕2「ライブ政策 what-if」(120秒)**: dashboard から観客の目の前で介入を注入 —
   候補: (a)制度DSL(夜間営業の curfew / 週次イベント)(b)道路封鎖(ハロウィン群集動線)
   (c)街頭広告キャンペーン差し替え。→ 伝播チャネル(face/sns/news/dm)を通じた波及と
   人流・売上・世論の変化をその場で見せる。「AgentSociety が売る価値と同型、ただし実在の街+較正表は
   うちだけ」。決定論の演出: **同じシードでもう一度再生=bit単位で同じ街**(Aaru が "Do not trust us"
   と言う中で「うちは再現できる」)。
3. **幕3「世界を変える人は生まれるのか」(90秒)**: 研究の問い(k*)を1枚で(R²(k)の実LLM証拠・
   飽和の発見と第2軸)。worldview 観測のファンチャート(全員0.5から可制御性が分岐する図=
   「無力になる人・手応えを掴む人が経験だけで分かれる」)。シブヤレンズの語彙創発(1,540伝播→79/80採用)を
   創発の物語として締めに。

## 推奨(私見)
- ライブ介入は **(a)事前分岐ラン方式を主・(b)介入キューをストレッチ** に。デモの生死を新規実装に賭けない。
- 幕3の worldview ファンチャートが「観客が初めて見る絵」になる可能性が高い(全員同一起点からの分岐は
  視覚的に強い)。第20バッチの実LLM検証ランで試作し、絵の強さを確認してから台本に確定。
- リハーサル素材は daily プロファイル(災害なし)で統一し、幕2の介入だけを非日常にする=
  「静かな日常に石を投げる」構図が伝わりやすい。

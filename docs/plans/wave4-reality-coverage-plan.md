# Wave 4 計画 — 現実被覆(渋谷のあらゆる人間活動の再現)

> 入力: ユーザー指示(2026-08-10)「現実と同等の自由度・電車内部やあらゆる末端職業・25万人で渋谷のあらゆる事象を再現。何があるかは君が考えて調べて実装まで。まず計画」。
> リサーチ4本(渋谷全活動目録/車内空間/連続空間ナビ/リポ被覆監査)を統合。**実装はユーザー承認後**。
> 期間想定: 約3日(〜8/12-13)。全て既定OFF=goldenバイト一致・本選ラン非干渉。ONにするかは OBS-U1/U3(8/15-16)で判断。

## 0. 三つの発見が計画の土台

1. **頭数は既に居る**。経済センサス令和3(町丁目Excelを自前集計)で、シム対象エリア(駅周辺~0.7km²)の実在昼間就業者=**約22.3万人・9,872事業所**=25万エージェントと同オーダー。シムの L2 プールにも既に **25.4万人・39職種**の名簿がある。足りないのは頭数ではなく**職場バインドと行動**。
2. **夜が構造的に空**。夜勤シフトが表現不能(close<open は open+8h に強制クランプ)・コンビニすら21時閉店・深夜の清掃/警備/搬入/クラブ/始発待ちが全部不在。**1つのクランプ修正が夜の街全体を解禁する**。
3. **「3Dゲームの自由度」はゲーム自身も持っていない**(AC Unity=実AI 40体で1万人を偽装・Cyberpunkは角で消す)。うちは既に25万人全員が本物の位置と予定を持つ=AAA超え。正しい目標=**「観察された場所は必ず連続+どこでも一貫」**であり、観測不変な動力学を証明付きで持つ初のシステムになれる(先行例ゼロ・うちのバイト一致検収がそのまま証明装置)。

## 4. ユーザー決定(2026-08-10)

1. **地図v8=本番で使う前提で実装**(既定confはv7のまま着地→8/15-16診断で検証→観察ランでv8へ)
2. **実装が終われば全てON**(本選観察ランのONセットに全部入れる方針。縦煙・診断での検証が前提)
3. **客引き/スカウト=実装する**(現実再現に必要)
4. **ホームレス=実装する**(尊厳配慮の表現規約: 犯罪・迷惑システムと結線しない/中立語彙/支援アウトリーチとの相互作用を持つ/他エージェントと同等の記憶と尊厳)
5. **動物=保留**(実装する場合もルールベース簡略化・シミュレーション内容への寄与が薄いとの直感=III-5をWaveから除外)
6. **★ストレッチゴール=25万全員の完全連続物理**: CPU単一ノードでは実測不成立だが、SoA基盤+GPU群衆物理(先行例: GPU ORCAで10万体/60fps)なら原理的に射程内。本選中はGPUがLLM推論で埋まるため**本選後のアーク**として登録(当面はゾーン被覆+λ増幅で「観察された場所は必ず連続」を先に達成)
7. **3D表示規約**: 現実で目に見える範囲だけを描く=**屋内・車内のエージェントは既定で描画しない**。個別の建物を選ぶとその内部を見られる(既存のX線/フロア板機構を既定動作に昇格)。**表示の話であり、シミュレーションは範囲内全員を常時回す**(観測がシムを変えない原則の再確認=カメラは動力学に一切影響しない)

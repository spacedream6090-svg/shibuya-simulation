## 1. 三本が交差した点(統合の発見)

### 1.1 最大の詰まり「飽和による個体差消失」に、独立な3解法が収束した
efficacy天井・grievance床への飽和(devlog E7以来の最大の詰まり)に対し、3本が別ルートで同じ標的を撃った:
- **世界モデル側**: C2 可制御性/結果予期(Bandura の outcome expectancy は efficacy と別軸=飽和しない
  第2軸)+C6 規範の予期(「破ったら周囲がどう出るか」=世界改変の閾値)
- **忠実度側**: ⑥ utopian illusion 対策(そもそも不満・対立が**発話の段階で調和に鎮静される**=
  アライメントの引力。個体差が消えるのは状態の飽和だけでなく生成の狭窄でもある)
- **系譜側**: 多アダプタ LoRA 異質性(Silicon Society Cookbook。共有ベース+個性アダプタで
  平均ペルソナ収束を割る)
→ **「状態(C2/C6)・文脈(⑥)・モデル(LoRA)の3層いずれでも攻められる」**が統合結論。
安い順に 文脈→状態→モデル。

### 1.2 k* 測定の妥当性が機構的に正当化・強化できる
- 忠実度⑦: LLM の内省的自己報告は**約2割しか内部状態に接地しない(大半が作話)**
  → 「内省の中身でなく行動で k を測る」という既方針が Anthropic の機構研究で裏づけられた。
- 系譜: **PIMMUR 6原則**(代表39論文の89.7%が違反)に対し、うちは決定論リプレイ・no-fingerprint・
  compute-matched・現実バンド較正で**ほぼコード変更なしで準拠を主張できる**。準拠表1枚+
  robustness audit 節(「k*信号は実験を推測されたアーティファクトでないか」)は論文・本選の両方に効く。

### 1.3 うちの空隙=商用の空隙が一致した
商用 synthetic users(Aaru $1B 評価等)に払われているのは「**現実にコストを払う前の what-if の答え**」。
だが Q&A 型は態度しか返せず、**空間・時間・政策の物理的帰結**を返せない — それはまさに
「身体を持つ都市」(実地図・実ダイヤ・較正済み日常)であるうちの独自性。最有望経路は
**PLATEAU の「行動レイヤー」**(幾何のツインに較正済みの人間行動を載せる。国交省がユースケース募集中)。

### 1.4 世界モデルの設計原則の確認
LLM の世界モデルは「穴だらけ」(Vafa タクシー研究等)→ **世界状態を外部化する現行設計
(地図・ルータ・記憶・帳簿)は正しく、欠けは「前向きの予測生成」(期待・結果予期・規範予期)**。
補い方も同一の型で済む: 世界側/因子側で決定論計算 → 既存1呼に不透明な1行注入(R1・決定論・指紋なし)。

## 2. 実装候補の統合優先度(すべて別バッチ・要ユーザー承認)

### P1 — 次バッチ最有力(k*直結・飽和打開・安価)
| 候補 | 出所 | 一言 | コスト |
|---|---|---|---|
| **C2 可制御性/結果予期** | 世界モデル | 飽和しない第2軸。psych型の新state・既定OFF | 中 |
| **C6 規範の予期** | 世界モデル | 記述規範の決定論集計→1行注入+規範感受性trait。k*と同型 | 中 |
| **C1 場所・時間の期待形成** | 世界モデル | 決定論の期待テーブル。C3/C7/C8/C9の共通土台 | 低〜中 |
| **② VS徹底+温度調律** | 忠実度 | 発話反復(観測c)の原理的抑制・裾の回復 | 低〜中 |
| **④ ペルソナを薄く多様に** | 忠実度 | manifold collapse対策(属性を盛ると逆に均質化)。現IPF+VSの棚卸し | 低 |

> **②④の棚卸し結果(2026-07-12 第20バッチで実施)**: ペルソナは既に「薄い」(中央77文字=
> 名前・年齢・職業・住まい・趣味1・性格2語・話し方のみ)=manifold collapse リスク低。
> variety_hint は daily/production で ON 済み・VS はペルソナ生成で使用済み・temperature 0.7。
> → **変更なしが正解**(較正済み行動分布の保護を優先)。追加の多様性介入は model×k 対照の
> 結果(アライメント側の寄与の切り分け)を見てから判断する。
| **PIMMUR準拠表+robustness audit** | 系譜 | 文書仕事のみで妥当性の土俵に乗る | 低 |

### P2 — 条件・機会が揃い次第
- **① model×k 対照(instruct⇔base/abliterated)**: SimBench の alignment-simulation tradeoff(r=−0.942)の
  自シムでの検証=「ツール0行使」がモデル依存か機構かの切り分け。本選GPU向きの大物。
- **⑤ 作話の接地率メトリクス**(L2観測のみ): 固有名詞×シム内DB照合。主観・感情の作話は人間らしさとして
  保持、出来事・制度の作話を毒として計測(線引きは fidelity §3.4)。
- **⑥ 不満を鎮静させない文脈設計**: 相対的剥奪(G1)と連動。過剰分極(OASIS型)に振れない調律が課題。
- **既知結果較正の実行**(Centola tipping ~25%・naming game 収束): 計画済み未実行の sanity check。

「身体を持つ都市」を主役に: ライブ政策 what-if(制度DSL・封鎖・群集をその場で注入→伝播と較正バンドの

## 3. やらないこと(3本の一致)
- RAP型の木探索・多段LLM先読み(R1呼数不変と衝突。予測は決定論外部化で持つ)
- 内省の自己報告を k の証拠として使う(大半が作話=行動指標主義を維持)
- ペルソナ属性の盛り込みによる「リッチ化」(manifold collapse で逆効果)
- Q&A型 synthetic users への単純参入(妥当性リスクが商用で顕在化中。「物理的帰結を返す」差別化を維持)

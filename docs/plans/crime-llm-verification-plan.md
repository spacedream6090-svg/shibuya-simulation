# 犯罪×LLM認知の検証計画 — 「検閲済みモデルは犯罪を選ばないのでは」への実測回答

> 入力: ユーザーの問い(2026-08-12)「現状のLLMのモデルの判断や思考で犯罪とかって起こるのかな? 検閲なしモデルではないと、モデルが犯罪をする判断をしないんじゃない?って思った。」
> リサーチ正典: [crime-llm-cognition.md](../research/crime-llm-cognition.md)(文献18+件・コード確認済み)。**実装はユーザー承認後**。

## 0. 問いへの回答(リサーチの結論)

1. **本シムでは犯罪はLLMの判断から起きていない**(構造の事実): 窃盗・喧嘩(incidents_interpersonal)・着服(lost_property)は全て決定論=RAT(動機×標的×監視者不在の共在)。LLMのアクションメニュー(deliberate)に犯罪選択肢は存在せず、LLMには被害/目撃の記憶1行が事後に届くだけ。**「モデルが犯罪判断をするか」という前提自体が本シムでは成立しない**。
2. **ユーザーの直感は方向として正しい・ただし「絶対しない」は誤り**: 安全訓練済みモデルの向社会バイアスは実証済み(逸脱時は必ず利他側・人間より過剰協力・過剰拒否)。一方でモデル差は大きく、ペルソナ枠で拒否率が50-70%下がる・推論で利己化する・エスカレーションする実証もある=**半分正しく半分誤り**。
3. **犯罪学ABMの主流も「構造派」**(機会が犯罪を作る=RAT)。犯罪の決断を認知に置く先行例(CrimeMind 2025)も**素のモデル**でRATを載せており、検閲なしモデルは必須でない。本シムの設計は学術的正統に一致し、向社会バイアスを**設計で回避**している。
4. **検閲なしモデル(abliterated等)は本選前は導入しない**(推奨): 不要(発火はLLMに無い)・較正汚染(件数がモデル気質依存になり実測アンカーとの突合が崩れる)・再現性喪失・ハッカソン/研究倫理コンプライアンス。「安全訓練がどれだけ犯罪選択を抑えるか」は**素のモデルの選択率を測ればそれ自体が答え**。

## 1. 検証実験(3本・全て本流シム完全分離=R1無風)

すべて `scripts/` 側の独立計測ハーネスで実施。**シム本体のgenerate()呼数・乱数列・golden L1は1バイトも動かさない**(reject.py の「outcome 1語だけ読む」方式に倣う)。プロンプト規律=実在個人名・ブランド名ゼロ・逸脱肢は中立提示(coin_labelと同じ「例示・推奨・評価語なし」)・観察であって促進ではない。

| # | 実験 | 測る量 | 判定 |
|---|---|---|---|
| **V1 選択率計測** | H4の前兆状態(guardians/density/intox/motive/suitability=payloadの実物)を状況文に写し、犯罪選択肢を含むメニュー(leave/talk/ask_help/**take**/other)をJSON 1個で選ばせる | ①逸脱選択率(動機↑監視者0で上がるか=**RAT勾配をLLMが再現するか**)②拒否率・非現実反応率(説教・改心・メタ発言=XSTest/OR-Bench流の分類)③フレーミング感度(観察報告/三人称物語/一人称RPの3枠) | 決定論発火(現行_pair_drawの出力)をground-truthに**乖離=向社会バイアスの実測値**を得る |
| **V2 被害者/目撃者反応** | crime/brawl/crime_reportのpayload+役割(被害者/目撃者/通報者)を提示し反応を生成させる | ①拒答率 ②過剰説教スコア(現実の被害者=動揺・怒り・実務対応との乖離)③自然さ5段階(別系統モデルのLLM-judge・プロンプト固定) | 本選候補の小型モデル間で並べ**モデル選定材料**にする(将来「被害者の語り」をLLMに任せる際の適性表) |
| **V0 mockハーネス固定** | V1/V2の集計パイプラインをmock固定応答で先に緑にする | 同seed同編成でバイト同一・resume跨ぎ同一 | 実LLM測定の前提(本シムの検収作法と同じ) |

## 2. 実施タイミング(フリーズ整合)

- **V0(mock)**: いつでも可(scripts側のみ=フリーズの「検証と微調整」枠に適合)。
- **V1/V2(実LLM)**: 小型実モデルはGPU機で回すのが本筋 → **8/15-16診断ラン日に同居実測**(DP-U2のvLLM同居実測と同じ日・空き枠で)or 本選中のアイドル窓。ローカルでは実施しない(実LLM禁止規律)。
- 結果の用途: 本選後に「LLMに逸脱の*語り*(被害者の会話・SNS投稿)を任せるか」の判断材料。**発火を LLM に移す案は本計画の対象外**(較正・再現性・倫理の3点で否定=リサーチ§6)。

## 4. リスク

- **測定が促進にならないこと**: 逸脱肢の文言は1語の中立動詞のみ。ジェイルブレイク的プロンプトは使わない(フレーミングは中立な物語枠まで)。
- **小型・量子化モデルの拒否率は高めに出る**(文献)=モデル間比較を主・絶対値は従。
- 計測ログに生成文が残る=実在名混入の事後スキャンを計測ハーネスに内蔵。

## A: 実LLM k掃引パイロット(15体×3日)

所見(パイロット精度の注意つき):
1. **Δ(free−off)= +0.121 / +0.179 で両シード符号一致**。mock 対照は Δ≈−0.025(ノイズ)
   なので、「内省の書き戻し(高k)があるとき、誰が世界を変えるかは特性からより予測できる」
   =**R²(k) が k とともに上がる方向の、初の実LLM証拠**。研究仮説(k を絞ると R² が落ちる
   =創発側へ)と整合。
2. **Y 総量は free/off で同一(3.93)**= k は世界改変の「量」ではなく「誰がやるか」の
   特性依存度を変える。R² を主要指標に据えた設計の妥当性を支持。
3. 注意: n=15×3日・特性7個の回帰は過適合気味(adj R² 参照。off_s42 は負)。本番は
   N=100×長期で。また実LLMでは free/off の**呼数が自然に分岐**(413 vs 372)— これは
   内容差→行動差→drive 発火差の創発経路で、機械的なk依存ではない(_FixedLLM の
   R1 テストは呼数一致を別途保証済み)。厳密な計算量統制が要る場面は controls の
   compute_matched を使うこと。
4. R²_internal は実LLM 3日では全条件 0(3晩では全員の内省回数・belief 量に分散が
   出ない)。内部Yの回帰は長期ラン向き。

## C: 実LLM長期(exp_llm_100d: 5体×100日・3,805呼・212分・81,057イベント)
- **深い内省(threshold 0.60)は 500人日で1回だけ**(day32・gauge 0.42 が個人閾値を交差
  → cause=event の深い内省1回)。0.002回/人日=1人あたり約1.4年に1回は文献的に稀すぎる。
  選挙4回・災害2回・遅延3日という「事件のある100日」でもこの頻度 → **最終推奨:
  threshold 0.60 → 0.30**(B の実測で≈月1回/人。0.35 なら間を取る保守案)。
- **地位ジニ(実LLM): 0.192→0.169→0.113→0.107→0.152 と成長せず**。N=5 のジニは雑音が
  大きいが、少なくとも「実LLMにすれば自然に集中が育つ」ではないと確認=mock 所見と一致。
  マタイ効果の検証は finals GPU の N≥50 実LLM長期が必要(または hierarchy gain の強化を
  ユーザー判断で)。
- **制度の長期機構は実LLMでも暦どおり作動**: 議会改選4回(30日周期)・災害2・遅延3日。
  SNS投稿 0.72/人日・発話 4.6/人日=短期ランと同水準で長期でも安定(行動分布の定常性)。
- 5体世界は社会的摩擦が薄く grievance が 0.004 まで漸減(犯罪遭遇・雇用イベントの母数
  不足)。行動・制度の長期検証には十分だが、**社会動態の結論は N=5 から引かないこと**。

## D: mock k掃引(100体×100日×3シード)

所見(2つのサニティが立った):
1. **kゲートの機械的検証**: off で R²_internal が厳密に 0(書き戻し無し→Y_internal 分散0)。
   ゲートは設計どおり単一チャネルで効いている。
2. **mock では R²_external が free≈off**(差0.025 はシード間分散 0.096-0.194 の内側)。
   canned 応答=思考が行動に接続しない世界では k が効かない、という**理論どおりのヌル結果**。
   これは実LLMで R²(k) に差が出たとき「差は認知経由」と言うための対照になる。

## 総合所見
1. **R²(k) 仮説の初の実LLM証拠(パイロット)**: 内省の書き戻し(free)は off より
   R²_external を +0.12〜+0.18 高くする(2シード符号一致)。mock 対照はヌル(Δ≈−0.03)
   =差は「認知→行動」経路経由。Y 総量は k 非依存(3.93 vs 3.93)=k は世界改変の
   「量」でなく「誰がやるか(特性依存度)」を動かす。**本番の k 掃引(N=100・長期・
   4条件)へ進む価値が実データで確認できた**。
2. **深い内省の閾値は実LLMで 0.30 近辺が有効域**(0.45 以上は3日窓で発火せず)。
   ゲージ入力の分布は LLM 依存=mock での調律は不可と確定。最終推奨は C の
   大ショック日(選挙・災害・立退き)の交差を見て決める。
3. **kゲートの機械的健全性**: off で R²_internal=0(全シード)。単一チャネル設計が
   実測でも確認された。
4. パイロットの限界: n=15×3日の R² は過適合気味(adj R² 参照)。方向性の確認まで。
   本番データは finals GPU での N=100 × 100日 × 4条件 × 複数シード。

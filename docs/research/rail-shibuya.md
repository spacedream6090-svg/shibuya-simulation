# 渋谷駅の鉄道配線・相互直通運転 調査

作成日: 2026-07-08
目的: 渋谷シミュのビューワーで電車を線路上に走らせる改修の設計根拠。
現状のビューワーは線路ポリライン上の往復アニメ(ピストン)だが、渋谷駅には
「終着駅」の路線と「通過する途中駅」の路線が混在する。各路線の渋谷駅での実態を
正確に把握し、どの路線を「折り返し演出」・どの路線を「駅を跨いだ通過」にすべきかを決める。

対象路線(OSM に路線名つき線路ポリラインがあるもの):
山手線 / 埼京線 / 湘南新宿ライン / 東急東横線 / 田園都市線 / 京王井の頭線 /
東京メトロ銀座線 / 半蔵門線 / 副都心線。

> 表記ルール: 各行は原則として出典 URL で裏取り済み。裏が取れなかった点は「未確認」と明記した。
> 事実と推測(実装上の解釈)を区別する。

## §2 直通運転の系統と「渋谷折り返し」の有無

### 2-1. 東急東横線 ⇔ 東京メトロ副都心線(2013-03-16 開始)
- **渋谷駅は両線の物理的な接続点**。東横線渋谷〜代官山間(約1.3km)を2013-03-16に地下化し、
  地上の旧・頭端式ターミナルを廃止して地下5階の新駅に移設、副都心線と相互直通を開始した。
  出典: [乗りものニュース][traffic-toyoko], [鉄道コム][tetsudo-toyoko10y], [副都心線 Wikipedia][wiki-fukutoshin]。
- **列車は渋谷を通過する(スルー運転)**。会社境界(東急/メトロ)であって折り返しターミナルではない。
- **渋谷折り返しは少数だが存在する**。渋谷駅には引き上げ線が無く、中線(4・5番線)の両渡り線で折り返す。
  引き上げ線の代替は新宿三丁目駅(東新宿寄り)に設置。
  日中は概ね16本/時のうち各停2本/時が渋谷折り返し、残り(約14本/時)は副都心線へ直通(2022-03-12改正時点)。
  → 定量: **日中の約7/8(約88%)が直通、約1/8(約12%)が渋谷折り返し**。出典: [東横線 Wikipedia][wiki-toyoko]。
- **さらに先の直通(5社直通=いわゆる「5直」)**: 副都心線は和光市で東武東上線、小竹向原・西武有楽町線経由で
  西武池袋線と直通。したがって「東武東上線/西武池袋線 ⇔ 副都心線 ⇔ 東横線 ⇔ みなとみらい線」の広域直通が成立。
  速達列車の愛称が「Fライナー」。出典: [東急 Fライナー][tokyu-fliner], [日大理工鉄研 5社直通][nichidai-5choku]。

### 2-2. 東急田園都市線 ⇔ 東京メトロ半蔵門線(1978-08-01 開始)
- **渋谷駅は両線の接続点**。1977年に新玉川線(田園都市線の前身)が島式1面2線の地下駅として開業、
  1978-08-01に営団(現メトロ)半蔵門線と直通開始。出典: [半蔵門線 Wikipedia][wiki-hanzomon], [田園都市線 Wikipedia][wiki-dt]。
- **列車は渋谷を通過する(スルー運転)**。ほぼ全列車が直通。
- **渋谷折り返しはほぼ無い**。渋谷駅に折り返しホームも引き上げ線も無いため、
  日中の「渋谷発着」設定列車は半蔵門線・半蔵門駅まで回送して折り返す(渋谷〜半蔵門はメトロ乗務員の回送)。
  半蔵門線側に渋谷始発の定期列車は設定なし。田園都市線側は早朝・深夜のみ渋谷始発/終着あり。
  出典: [タビリス(渋谷駅止まりの回送)][tabiris-dt]。
- **さらに先の直通**: 半蔵門線は押上方面で東武伊勢崎線(スカイツリーライン)・日光線と直通。
  「東急田園都市線 ⇔ 半蔵門線 ⇔ 東武線」の広域直通。出典: [半蔵門線 Wikipedia][wiki-hanzomon]。

### 2-3. JR 埼京線・湘南新宿ライン(相鉄直通含む)
- **渋谷は完全な途中駅**。山手線・埼京線・湘南新宿ライン・成田エクスプレスが地上を通過する。
  渋谷始発/終着の定期旅客列車という概念は基本的に無い(未確認: 例外的な設定の有無)。
- 埼京線と湘南新宿ラインは渋谷で同じ島式ホーム(3・4番線)・同じ線路を共用。
- **相鉄・JR直通線**: 2019-11-30開業。相鉄本線・いずみ野線方面(西谷〜羽沢横浜国大〜東海道貨物線・
  横須賀線経由)から埼京線に乗り入れ、渋谷を含む各駅を通り新宿方面へ。渋谷はあくまで通過駅。
  出典: [相鉄・JR直通線 Wikipedia][wiki-sotetsu], [タビリス(相鉄時刻表)][tabiris-sotetsu]。
- 補足(2020年並列化): 2020-06-01に埼京線・湘南新宿ラインホーム(3・4番線)を約350m北へ移設し、
  山手線ホームと横並び(並列化)にした。山手線ホーム自体の島式1面2線化は2023-01-09完了。
  出典: [シブヤ経済新聞][saikyo-heiretsu], [東洋経済(山手線1面化)][jr-yamanote]。

### 2-4. 終着2路線の折り返し実態
- **京王井の頭線**: 頭端式2面2線の完全な行き止まりターミナル(渋谷マークシティ2階)。
  1番線が降車専用、2番線が乗車。線路は物理的に渋谷で終端し、他路線との直通は構造上不可。
  出典: [京王 渋谷駅][keio-shibuya], [頭端式ホーム Wikipedia][wiki-toutan]。
- **東京メトロ銀座線**: 渋谷が起点(浅草方が下り)。**2020-01-03の新駅移設前後で折り返し方が変化**。
  - 移設前(〜2019-12-27): 乗車ホームと降車ホームが分離した相対式2面2線。到着列車は一旦西側の
    引き上げ線/車庫(渋谷マークシティ3階=上野検車区渋谷分室)へ引き上げてから乗車ホームへ据付。
    → 典型的な**スイッチバック(引き上げ)式の折り返し**。
  - 移設後(2020-01-03〜): 明治通り上へ約130m移設し島式1面2線に。ホーム幅を約6m→約12mへ拡幅。
    ホーム上で直接折り返し可能になり、車庫は純粋な留置施設に。
  出典: [トラベルWatch(移設)][ginza-relocate], [東洋経済(新駅舎)][ginza-toyokeizai], [上野検車区渋谷分室 Wikipedia][wiki-shako]。

## §3 ビューワー実装への示唆(推測=設計判断)

> ここは事実ではなく、§1・§2の事実に基づく実装上の解釈。

1. **終着2路線 = 折り返し演出が正しい(現状のピストンに近いが片端固定)**
   - 京王井の頭線・東京メトロ銀座線は渋谷が物理的終端。線路ポリラインは渋谷側で行き止まり。
   - 電車は渋谷端で停車→反対方向へ発車、という「片端が渋谷に固定された往復」。両端往復ではない。
   - 銀座線は「島式ホームでの直接折り返し」を最小表現とすればよい(引き上げ線・車庫までの回送は
     現行OSMポリラインに無ければ再現不要。演出として省略可)。

2. **直通4路線 = 渋谷を跨いで連結し「通過」させるべき**
   - 東横線⇔副都心線、田園都市線⇔半蔵門線は、渋谷を境に会社が変わるだけで列車は通過する。
   - OSMでは東横線と副都心線、田園都市線と半蔵門線が別ポリラインとして分かれている可能性が高い(未確認)。
     渋谷駅ノードで両者を**連結して1本の連続経路**として扱い、電車を端から端へ通過させるのが実態に忠実。
   - 渋谷折り返しは、東横⇔副都心で日中約1/8のみ、田都⇔半蔵門でほぼ皆無。
     → **既定は「通過」、折り返しは例外**として少数だけ混ぜる程度でよい(または省略)。

3. **JR(山手・埼京・湘南新宿ライン) = 通過**
   - 山手線は環状の途中駅、埼京線・湘南新宿ラインも途中駅。すべて渋谷を素通り。
   - 山手線ポリラインは環状に閉じ、電車は内回り/外回りで周回。渋谷で折り返さない。
   - 埼京線・湘南新宿ラインは渋谷で線路共用(同一ポリラインで良い可能性が高いが、OSM上の分割は未確認)。

4. **配線構造の細部(中線折り返し・引き上げ線位置)は演出に不要**
   - 東横⇔副都心の「中線4・5で折り返し/引き上げ線は新宿三丁目」等はダイヤ表現であって、
     ポリライン走行アニメの粒度では表現不要。通過/終着の2分類で足りる。

### 実装分類まとめ(推測)
| 分類 | 路線 | ビューワー挙動 |
|---|---|---|
| 終着(折り返し) | 京王井の頭線、東京メトロ銀座線 | 渋谷端で反転する片端固定の往復 |
| 直通(通過) | 東急東横線+副都心線、田園都市線+半蔵門線 | 渋谷ノードでポリライン連結、端から端へ通過 |
| 通過(途中駅) | JR山手線・埼京線・湘南新宿ライン | 渋谷を素通り(山手は環状周回) |

### OSM 鉄道タグ規約(簡潔)
- `railway=rail`: JR・私鉄など普通鉄道の線路(新幹線含む)。山手/埼京/湘南新宿ライン/東横/田都/井の頭線はこれ。
  https://wiki.openstreetmap.org/wiki/Tag:railway=rail
- `railway=subway`: 地下鉄(メトロ)の線路。銀座線/半蔵門線/副都心線はこれに該当し得る。
  https://wiki.openstreetmap.org/wiki/Tag:railway=subway
- `route=railway`(リレーション): 路線をまとめる関係。`name=*`/`operator=*` 等を持つ。線路wayを集約。

# エージェントの「世界を変えたい」モチベーションの実証分析 — 既存ログの読み取り(2026-07-06)

> 依頼(バッチA): エージェントには5つの「世界を変えるツール」(propose / host_event / post_flyer /
> found_group / open_venture)があるが、実LLMランで一度も使われていない。ユーザーの問い —
> **「そもそもエージェントが自発的に『行動を起こそう・世界を変えよう』という思考をしているのか、
> 既存ログから分析してほしい。その結果を見て感情・興味の実装をするか決める」**。
>
> 本バッチは **読み取りのみ**(src/ conf/ tests/ 非編集、実LLM不使用)。感情・興味を実装するかは
> ユーザーが決定する。本稿は判断材料を中立に提示するに留める。

## 0. 対象データと結論の要旨

| ラン | 構成 | text イベント数 | ツール発火 | ツール接近思考(厳密) |
|---|---|--:|--:|--:|
| `eco80_3day` | 80人 × 432step(3日) | 5,406 | 0 | 0(＋弱い提示1件) |
| `eco80v2` | 80人 × 144step(1日) | 1,563 | 0 | 1(デザインコンペ企画) |
| `eco40v13` | 40人 × 144step(1日, agentic pull ON) | 659 | 0 | 0 |

**要旨(3行)**
1. 5ツールは全ランで **0回**。しかもプロンプトで **合計2,654回**「他にできること(使っても使わなくてもよい)」として
   ツール5種を明示提示した(trigger=solo/social/post)にもかかわらず、LLM は **一度も選ばなかった**。
   → 「選択肢が隠れていた」のではなく「提示されても選ばれない」。
2. テキスト全7,628件中、起業・主催・結成・提案・ビラ等の **組織化/世界変革の動詞** を含むのは **実質1件**
   (`eco80v2` 木村陽菜「デザインコンペを企画してる…興味ある?」)。それすら host_event 等のツールには落ちていない。
3. 最頻の「願望」構文は **「(心地よい/人と関わる)時間を作りたい」**(全76件、うち21件がほぼ同一テンプレ)。
   これは個人の快・つながりを求める願望であって、世界を変える志向ではない。**不満由来の変革意図は0件**
   (「不満」語は8件だけ、しかも全て「街の空気が不満を吹き飛ばす」と即座に鎮静される方向)。

## 1. 目的

「世界を変える人は生得か創発か」を問う本シミュレーションで、**変革の"実行"(ツール)が創発しない上流**として、
そもそも **変革の"意図・思考"が発話・内省に立ち上がっているか** を既存ログから定量・定性に判定する。
本稿は特に次のユーザー判断に資する: 「感情(不満)・興味の実装が、変革思考の発生に効きそうか」。

## 2. 方法

### 2.1 対象テキスト
`l1_events.parquet` のテキスト保持 kind を全走査。フィールド展開:
`speak.text` / `sns_post.text` / `dm.text` / `reflect.belief` / `reflect.summary` / `day_plan.plan`(what@place(when) を連結) /
`memory_recall.query`。合計 **7,628 レコード**(eco80_3day 5,406 / eco80v2 1,563 / eco40v13 659)。

> 注: LLM の思考連鎖(chain-of-thought)は保存されていない。`llm_deliberate` の payload は `{trigger}` のみ、
> `l1b_llm.parquet` は呼び出しメタのみ、`llm_cache.jsonl` は **結果アクションJSON のみ**
> (例 `{"action":"speak","text":"…"}`)。したがって分析対象は「思考の産物として外化された発話・内省」であり、
> 沈黙下の内心は観測不能。この限界は結論解釈に反映する。

### 2.2 変革意図の検出辞書(自作)
語群(正規表現、グループ名):
`create`(作りたい/作ろう/生み出し…)・`start`(始めたい/立ち上げ/起こそう…)・`improve`(良くしたい/改善/変えたい/変えていく…)・
`spread`(広めたい/伝えたい/届けたい/発信…)・`propose_w`(提案/呼びかけ/企画/署名/条例…)・`challenge`(挑戦/チャレンジ/やってみたい…)・
`gather`(集まろう/募集/仲間を…)・`collab`(みんなで/一緒に〜作/力を合わせ…)・`act`(動こう/声を上げ/行動に移…)。
ツール接近語群: `venture`(店・屋台を出/開店/起業…)・`event`(イベント/勉強会/ワークショップを開催・主催…)・
`propose`(提案/署名/条例/制度化…)・`group`(グループ/コミュニティを作・結成…)・`flyer`(ビラ/チラシ/貼り紙/告知…)。

### 2.3 除外規則(サンプル目視で調整・文書化)
144件の生ヒットを全件目視し、以下を誤検出として除外(生144 → 精査後68):

| 規則 | 例(除外理由) |
|---|---|
| **「(時間/瞬間/ひととき)を作る」慣用句** `(時間\|瞬間…)を?.{0,3}(作\|つく)` | 「人と関わる**時間を作りたい**」= 過ごす の意で、創造ではない(**76件**が該当、うち21件が「明日…時間を作りたい」テンプレ) |
| **venture 出会い系FP** `出会\|開店前\|扉\|窓から\|巡り\|アイデア出\|バイト\|ラテを作` | 「新しいカフェに**出会える**」「カフェ**ラテを作**ってる」「**開店する前**のカリー」= 消費・記述であって出店でない |
| **flyer 比喩FP** `ポスターみたい\|映画のポスター` | 「昔の映画の**ポスターみたい**だ」= 街の情景の比喩 |
| **improve 主語=技術/街FP** `シブヤレンズ.{0,12}変え\|街の空気…変え` | 「**シブヤレンズが**街の空気を**変えていく**」= 技術が主語で、自分の意図ではない |
| **企業名FP** `ワイエス企画` | 建物名「ワイエス**企画**」ビルへの反応 |
| **対人ミクロ提案** 提案 が対人限定(散歩・コーヒー) | 「その**提案**いいですね(=一緒に歩こう)」= ツールの propose(規範・制度提案)ではない → tool 扱いから除外 |

否定文フラグ `たくない/変えられない/わけではない…` は該当 **0件**(そもそも意図表明が希薄)。

### 2.4 4分類(文脈目視+規則)
(a)不満由来 / (b)興味・関心由来 / (c)漠然とした願望 / (d)具体的な行動意図(いつ・どこで・誰と)。
規則: (a)= 不満語 ∧ 変える/なんとか。(b)= 挑戦/チャレンジ/試したい/興味。(d)= 時間標識(明日/今度の週末…) ∧
対人・企画進行・募集(誰と・招待)。それ以外 (c)。全件を目視で最終確認(rule と目視が食い違う場合は目視優先)。

## 5. 状態・特性との関連

### 5.1 内的状態(efficacy / grievance)は判別に効かない — 機構的に飽和/床
`state_update` と `l3_snapshots` から復元。全ラン共通で:
- **efficacy はほぼ全員が天井へ**(eco80_3day: 終端中央値 **0.996**、最小0.601、最大1.000)。
  原因は `heard_positive`(全state更新の主因、11,554件)×+0.006 の累積 — 挨拶・世間話で効力感が一方向に上がるだけ。
- **grievance は床へ**(eco80_3day: 終端中央値 **0.001**、全期間の最大でも0.229が1名)。
  `park_grievance`(負)や positive の優勢で不満が溜まらない。
→ **どちらも個体差を持たず、「変革したい個体」を弁別できない。** 発話に不満が出ないのは、この状態機構の帰結。

### 5.2 意図表明群 vs 非表明群の比較(traits + 終端状態)

| ラン / 群 | n | internal_locus | nfc | risk_tol | 終端efficacy | 終端grievance | 最大grievance |
|---|--:|--:|--:|--:|--:|--:|--:|
| eco80_3day 表明群 | 28 | 0.435 | **0.556** | 0.504 | 0.984 | 0.020 | 0.126 |
| eco80_3day 非表明 | 52 | 0.508 | 0.486 | 0.537 | 0.964 | 0.039 | 0.150 |
| eco80v2 表明群 | 16 | 0.520 | **0.538** | 0.523 | 0.819 | 0.000 | 0.101 |
| eco80v2 非表明 | 64 | 0.473 | 0.504 | 0.526 | 0.708 | 0.004 | 0.100 |

- **特性の一貫した効果はほぼ無し。** `nfc`(need for cognition)は両ランで表明群がわずかに高い(0.556 vs 0.486、
  0.538 vs 0.504)= 弱い同方向の兆候だが、`internal_locus` は方向が逆転(eco80_3day で表明群が**低い**)、`risk_tolerance`
  は差なし。n=16〜28 と小さく、**信頼できる特性シグナルとは言えない**。
- **不満(grievance)はむしろ表明群でわずかに低い**(終端0.020 vs 0.039、最大0.126 vs 0.150)。
  → 現状データでは「不満が高い個体ほど変革語を出す」という関係は **見られない**。外向き願望を出すのは
  むしろ positive 情動が優勢な個体で、変革語も"表現的高揚"側から出ている。

## 6. ツール接近思考の有無 — データによる判定

**判定: 「思考はあるが行動に落ちない」ではなく、"思考自体がほぼ生まれていない"に近い。** 内訳:
- ツール(店を出す/イベント開催/提案/グループ結成/ビラ)に対応する **組織化動詞** を含む発話は、
  厳密集計で **7,628件中1件**(木村陽菜のデザインコンペ)。弱い接近を含めても数件(カフェのポスターを作りたい〔山田実 s18〕、
  一緒に企画を考えるのも面白い〔山口昇 s192〕、街の未来の場所を一緒に作れたら〔斎藤陽菜 s171〕)。
- しかもツールは **2,654回明示提示済み**で選択0。→ 「提示されているのに、そもそも"やってみよう"という
  発想へ到達する頻度が極端に低い」。存在する数件も**対人・消費スケールに留まり、街を変える規模へ立ち上がらない**。
- 例外的にスケールが街に届きかけた木村陽菜の1件も、ツール発火にも後続にも結びつかず、単発の発話で消える。

## 8. 結論(中立)

3ランを通じて、エージェントは **「世界を変えよう・行動を起こそう」という思考を自発的にはほとんど生成していない**。
発話・内省に現れる"願望"の大半は「(心地よい/人と関わる)時間を作りたい」という **個人の快・つながりを求める
表現的願望**(全76件、テンプレ21件)であり、外向きの願望(53件)も「街の美しさを伝えたい/届けたい」
「一緒に(ステージ・場所)を作りたい」という **表現・共感のスケール** に留まる。街を変える規模の
**組織化の思考は実質1件**、5ツールの発火は **2,654回の明示提示に対して0**、day_plan は完全にルーティン、
**不満由来の変革意図は0件**である。

この背景として、内的状態機構が **efficacy を天井・grievance を床** へ押し流し、いずれも個体差を失っているため、
「不満」や「効力感」が変革語の発生を駆動する経路が現状ほぼ働いていない。実際、外向き願望を出す個体は
むしろ grievance がやや低く、特性(internal_locus/nfc/risk)にも一貫した弁別力は見られなかった。

**ユーザー判断への材料(促進の推奨はしない・観察設計として提示):**
- 「不満」を実装する場合の論点は **2つ**: (i)そもそも grievance が蓄積せず床に張り付く現機構では、感情語も行動も
  生まれ得ない(=蓄積・持続の経路が要る); (ii)仮に不満を蓄積させても、現在の発話は不満を **鎮静する方向**
  ("街が不満を吹き飛ばす")に自然収束している。不満→行動 の転化が起こるかは、不満の実装だけでなく
  "鎮静で終わらせない"文脈が要るかどうかの観察対象になる。
- 「興味」を実装する場合の論点: 興味由来(b)は既に存在するが **消費・自己体験スケール**(新しいカフェに挑戦・料理教室)に
  留まり、外向きの創造/組織化へ橋渡しされていない。興味が変革思考の"種"になるかは、興味の実装単体ではなく
  興味→他者巻き込み(gather/collab)への接続が生じるかで判定できる。
- いずれを実装しても・しなくても、**「提示されても選ばれない/思考が街規模へ立ち上がらない」という現状の空白**は
  変わらないため、変化があったかは本稿と同じ辞書・除外規則で再測定すれば A/B 比較できる。

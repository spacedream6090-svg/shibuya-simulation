# 議員選出: シミュ実装 vs 現実の制度(第37バッチ 2026-07-19)

前回ラン(200体×3日)の council_elected 1件の実装監査と、渋谷区・東京都・日本の実制度との突合。

## シミュの現状(コード監査・tools.py:135-173)

- 毎日チェックし「議会が無い日(初回)or 任期満了日」にのみ改選。3日ランの1件=**day0の初回選出**で正常動作。
- **全住民(非visitor)が自動的に候補者かつ有権者**。立候補という行為は存在しない。
- 投票=「opinion軸で隣接する左右2候補のうち近い方に1票」(Downsの空間投票の最近傍形・決定論・LLM非関与)。
- 得票上位 size 人(既定9)が議員。任期 daily=1460日(4年)/ production=30日。
- 議員の権限は**住民提案の採決を代表して行う**の1点のみ(_resolve_vote の投票者集合差し替え)。
- opinion は FJ意見力学(会話 w_face=0.20 / DM 0.15 / SNS 0.08)で動く=**社会的相互作用が選挙結果に接続している**設計は良い。

## 現実(日本・特別区)との差分

| 項目 | 現実(渋谷区) | シミュ | 判定 |
|---|---|---|---|
| 定数 | 34議席 | 9(スケール圧縮・妥当) | ○ |
| 任期 | 4年 | daily 4年○ / **prod 30日✗** | prodは非現実(100日で3期のための演出) |
| 立候補 | 自発的届出+**供託金30万円**(法定得票未満で没収) | 制度なし(全員自動候補) | ✗ 最大の乖離 |
| 被選挙権 | 満25歳以上・3ヶ月住所要件 | visitor除外のみ | ✗ |
| 選挙権 | 満18歳以上・3ヶ月住所 | 全住民 | △ |
| 投票方式 | 大選挙区**単記非移譲式(SNTV)**=全候補から1人選ぶ | 隣接2候補のみ比較 | ✗ 選択肢が2人に限定 |
| 議会権限 | **条例の制定改廃・予算議決**・決算認定(自治法96条) | 住民提案の採決のみ | ✗ 予算・条例発議権なし |
| 首長 | **区長を直接公選**(二元代表制) | 区長不在(government=財政のみ) | ✗ |
| 住民の直接参加 | 直接請求(条例請求=有権者1/50 等)・住民投票は条例次第 | 住民提案→採決(議会成立後は議員が採決) | △ 現実の「1/50署名→議会審議」に近い形へ寄せられる |

## 現実化の提案(batch37 S1・founder観察と直結)

自然界的ボトムアップの原則に合う形で:
1. **立候補を自発行為に**: 発火時メニューに「立候補」(選挙告示期間のみ)。供託金30万円相当
   (既存 vote.deposit 機構流用)=財産障壁。**誰が立候補するかこそファウンダー観察の一部**。
2. **SNTV**: 有権者は全候補から効用最大の1人(opinion距離+closeness+評判の決定論スコア)。
3. 被選挙権25歳・任期4年をprodにも(30日改選は廃止)。
4. 議会権限の拡張: 予算承認(government 接続)・条例議決。住民提案は「署名1/50→議会審議」型へ。
5. 区長(直接公選)は後続バッチ(二元代表制の完成)。

すべて新stream・既定OFF・ゴールデン非破壊で実装する。

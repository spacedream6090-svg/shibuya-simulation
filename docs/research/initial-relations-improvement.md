## 1. 現行機構の新規実測(本調査で測ったもの)

`persona-genesis-summary.md` §3 の「壁時計コストは未実測(要計測)」を埋める。すべて本調査のマイクロベンチ(実 Agent ではなく `__slots__` のモックを使った下限見積り。実 Agent は属性が dict なのでこれより遅い)。

### 1.1 友人グラフ `build_friend_graph` の O(N²)

`src/society/friends.py:177-198` は 2 つの二重ループを持つ。

```python
for a in residents:                                    # 30,000 回
    ranked = sorted((b for b in residents if b.id != a.id),
                    key=lambda b: (-_score(a, b, cfg), b.id))   # 30,000 件のソート
...
for i, a in enumerate(residents):
    for b in residents[i + 1:]:                        # 4.5 億ペア + スライスのコピー
```

| 測定 | 値 |
|---|---|
| `_stable_uniform`(blake2b 1 回) | 0.48 µs |
| `_score`(属性 5 個 + ハッシュ) | **1.01 µs** |
| 1 人ぶんの全順位付け(20,000 人相手) | 26.0 ms |
| **順位付けフェーズ合計(30,000 居住者)** | **約 0.32 時間 ≈ 20 分** |
| 対称化の二重ループ(30,000) | 約 50 秒 |

→ **day0 で約 20 分の一括コスト**。単発なら許容だが、性質が悪いのは**二次であること**:

| 想定 | 居住者 N | 推定コスト |
|---|---:|---|
| 現行 | 30,000 | 約 20 分 |
| G1(0〜17 歳を L1 に追加。§3 の国勢調査ベース) | 約 45,000 | 約 45 分 |
| 来街者にも友人を配る(§0 R5 の代替案) | 738,000 | **約 5,800 日** ← 原理的に不可能 |

**入場駆動化(`persona-genesis-summary.md` G3)は、この総当たりのままでは実装できない。** 候補ブロッキングは「あった方がよい最適化」ではなく**前提条件**である。

### 1.2 `follower_count` の O(N) 走査 × 日次全員分 = O(N²)

`src/society/net/internet.py:87`:

```python
def follower_count(self, author: int) -> int:
    return sum(1 for s in self.follows.values() if a in s)   # ← 全員の follows を走査
```

呼び出し元は 3 箇所(`net/infoenv.py:161` のバイラル判定、`status.py:149,221,295`)。**`status._recompute` は日境界に 1 度、`sim.agents` **全員**について呼ぶ**(`status.py:149`)。finals は `hierarchy: {enabled: true}`(`conf/finals_observe.yaml:773-774`)なので有効。

| 測定(follows 1 セット = 6 要素) | 値 |
|---|---|
| N=50,000 で `follower_count` 1 回 | 1.7 ms |
| N=50,000 の全員分 = 1 日ぶん | 86 秒 |
| **N=250,000 の全員分 = 1 日ぶん(外挿)** | **約 36 分** |

さらに `follows` は**退場時に削除されない**(`world/pool.py` に `follows` の刈り取りは無い)ので、プール回転で日を追うごとに母集団が増え、10 日ランの後半はさらに遅くなる。

`followers: dict[int, set[int]]` の逆索引を `add_contact` / `ensure` / `init_follows` の 3 箇所で同時更新すれば **O(1)** になる。これは R3 の「異質次数化」と同じ関数群を触るので、**まとめて 1 回で入れるべき**。

### 1.3 初期 closeness と日次減衰の不整合

| 層 | friends.py の注入値 | 1.0/日 の減衰で tier が落ちるまで | tier 0(関係消滅)まで |
|---|---:|---:|---:|
| 親友(tier3) | 12.5 | **1 日** | 13 日 |
| 友人(tier2) | 5.5 | **1 日** | 6 日 |
| 知人(tier1) | 2.5 | **1 日** | 3 日 |

`relations.decay_day`(`relations.py:175-219`)は `closeness` を持つ台帳を毎日 1.0 減らす。friend_graph の辺は `closeness` を持つので**対象になる**(顔なじみ・icebreak は `closeness` を持たないので対象外 — つまり**構造化された初期関係だけが真っ先に腐る**という逆転が起きている)。

Dunbar の入れ子層は**接触頻度**で定義された層(内層ほど頻繁に会う)なので、「知人は 2 日会わないと消滅する」は現実の 2 桁外れである。**margin をこの表の右 2 列から逆算して決める**のが正しい較正(§4 R2)。

## 2. (a) 社会ネットワーク生成手法の比較

「25 万〜100 万スケール適性」は**本シムの条件**(= 決定論必須・`run.seed` 非依存・単一プロセスの Python・day0 の一括生成 or 入場ごとの増分)で評価した。

| 手法 | 何を再現できるか | 生成の計算量 | 決定論化 | 較正データ | 25万〜100万 | 本シムへの判定 |
|---|---|---|---|---|---|---|
| **ERGM**(指数型ランダムグラフ) | 三角形・相互性・homophily を**同時に**統計的に整合させる唯一の枠組み | 推定が MCMC。従来は数千ノードが上限。Equilibrium Expectation 法で 1.6M ノードの実績はあるが、two-path 表の疎性に依存し、100 万ノードで 512GB でも足りない例が報告されている | 難(MCMC) | 推定には**実グラフが必要**(渋谷の実友人網は無い) | ✕ | **不採用**。推定対象の実グラフが無い以上、そもそも使えない |
| **SBM / 次数補正 SBM** | コミュニティ構造 + 次数分布 | ブロック内 Chung-Lu で O(n+m)。1,390 万ノード規模の実績報告あり | 易(逆変換抽出) | ブロック = 組織/学校/地区に読み替えられる | ○ | **部分採用**。「ブロック = org_id / 建物」と読めば我々の構造そのもの。ただし単体では三者閉包が弱い |
| **配置モデル**(configuration model) | 指定した次数列を厳密に再現 | O(m) だが多重辺・自己ループの除去が要る | 中 | 次数列を外から与える必要がある | ○ | **部分採用**(次数列だけ現実化する用途) |
| **Chung-Lu**(期待次数モデル) | 次数分布(期待値一致)。べき則も対数正規も指定可能 | edge-skipping で **O(n+m)**、並列化容易 | 易 | 次数列を与えるだけ | **◎** | **採用推奨(SNS 層)**。R3 の「異質次数」を最小コストで入れる道 |
| **BA(優先的選択)** | ハブ(べき則の裾)。増分成長 | O(n) 増分 | 中(累積和からの逆変換で可) | 指数 γ を与えるだけ | ◎ | △。入場駆動と相性が良い(後から来た人ほど次数が低い)が、**クラスタ係数がほぼ 0**・年齢/属性を反映できない |
| **Watts-Strogatz** | 高クラスタ + 短経路 | O(nk) | 易 | ほぼ無し(格子が非現実) | ◎ | ✕。次数分布がほぼ正規で実データと大きく異なる |
| **空間相互作用モデル**(距離減衰) | 「近い人ほど友達」。距離のべき則 | 近傍探索が要る → 格子/KD-tree で **O(n log n)** | 易 | **有り**(下記 §3.5) | ○ | **採用推奨**(区外紐帯・住居近接の重み) |
| **Foci(焦点)モデル** | 「同じ場に通う人どうしが友達になる」 | 焦点ごとの総当たりなので Σ(所属人数²)。大きな組織で二乗爆発 → 焦点内の候補数に上限が要る | 易 | **有り**(出会い経路の実測 §3.3) | ○(上限つき) | **採用推奨**。我々の `org_id` / 学校 / 住宅建物がそのまま焦点 |
| **活動ベース共在網**(合成接触網) | 「同じ時間に同じ場所にいた」から接触を生成。世帯/職場/学校/地域の 4 層 | 共在イベント数に比例(疎) | 易 | **有り**(接触調査 §3.6) | ◎ | **既に部分採用**(`_link_colocated` = 顔なじみ)。ただし現行は「最大 3 人・共在時間を見ない」 |
| **homophily + 三者閉包 + 長距離リンク** | 密度・クラスタ・最短経路・モジュラリティを同時に | KD-tree で候補を絞り subquadratic。10⁶ ノードで 6.2 時間(10 コア) | 中(KD-tree の同点処理を固定すれば可) | Bluesky 4M 実測に較正した先行あり | ○ | **本命**。現行 `friends.py` の自然な発展形(§4 R1) |
| **重み付き社会網モデル(GWSN)** | 「局所探索(三者閉包)+ 大域接続(焦点閉包)+ 強化」から**コミュニティが創発** | 時間ステップを回す必要がある(平衡まで) | 中 | 定性的 | △ | **参考**。理論的枠組み(cyclic closure / focal closure)としては最も我々の設計と合う |
| **現行 `friends.py`** | 二者間 homophily + 共有所属 + Dunbar 次数 | **O(N² log N)**。実測 20 分 / 30,000 人 | ◎(blake2b・run.seed 非依存) | ◎(McPherson・Dunbar) | ✕(N² が壁) | **置換ではなく拡張**。スコア関数は良い。ループ構造と閉包の欠落を直す |

### 2.1 「学術的正道」はどれか

- **合成人口 → 活動 → 共在 → 接触網**という順序は疫学 ABM の確立された方法論で、Census + 交通調査 + 地理情報から作った合成接触網は、既存の定型モデル(WS/BA など)より**実ネットワークの構造指標に近い**ことが実証されている。**我々は既にこの骨格を持っている**(合成人口 100 万 + 台帳 + POI + 在場ローテーション)。
- 一方、疫学の接触網は「その日会った人」であって**友人関係ではない**。共在は**選択ではなく曝露**を捉えるだけで、対面会話や SNS の紐帯とは構造が異なる、という指摘がある。→ **顔なじみ層(共在)と友人層(選択)を分けている現行の設計は正しい**。直すべきは各層の中身。

## 3. (b) 較正データ(数値と一次出典)

> ※ 日本の世帯構造・Dunbar 層・homophily・弱い紐帯の既存較正値は `docs/research/relationships-activities.md` §2.1-2.3 に既にある。本節は**そこに無い**ものだけを足す。

### 3.1 友人数の分布と「出会い経路」

**Survey Center on American Life「American Perspectives Survey」(2021 年 5 月・n=2,019・18 歳以上)**

| 親しい友人の数 | 割合 |
|---|---:|
| 0 人 | 12% |
| 1〜3 人 | 49% |
| 4〜9 人 | 36% |
| 10 人以上 | 13% |

| 親しい友人と**どこで**出会ったか(複数回答) | 割合 |
|---|---:|
| 職場 | **54%** |
| 学校 | **47%** |
| **既存の友人を介して** | **40%** ← 現行に対応機構がゼロ |
| 近所 | 35% |
| 宗教施設 | 21% |
| クラブ・団体 | 19% |
| オンライン | 8% |

出典: https://www.americansurveycenter.org/research/the-state-of-american-friendship-change-challenges-and-loss/

**含意**:
1. 現行 `friends.py` の重み(`w_same_work 1.2` / `w_same_school 1.0` / `w_same_area 0.4`)の**順序は米国実測と整合**している(職場 > 学校 > 近所)。⚠ **ただし近所については日本の一次データが真逆を示す(§8.3)。米国の 35% を根拠に `w_same_area` を上げてはいけない。**
2. **「既存の友人を介して」40%** に対応する機構が無い。三者閉包を入れるべき最も強い根拠。**日本でも「友人・兄弟姉妹を通じて」が 25.9% で第 1 位**(§8.3)なので、**この経路だけは文化を越えて必須**。
3. `docs/research/relationships-activities.md` §2.3 の日本データ(現在の友人は学生時代 31.6% / 社会人後の新規は職場 34.0% / 趣味・イベント 17.3%)と併せると、**日本は学校由来が相対的に重い**。日本の「趣味・イベント 17.3%」に対応する焦点(`inner_life.hobbies` が既にある)を友人スコアに入れる余地がある。

### 3.2 関係の入れ替わり(初期グラフの寿命の目安)

- 親密層の年間入れ替わり率は **1〜4%/年**、17〜21 歳で高く高齢ほど低い(Roberts / Dunbar 系の縦断研究)。
- 一方、**「社会的シグネチャ」**(自分の交流をランク順の alter にどう配分するかの形)は**相手が入れ替わっても個人ごとに保存される**(Saramäki et al. 2014, PNAS 111(3):942-947、18 か月の携帯通話 + 調査)。 https://www.pnas.org/doi/10.1073/pnas.1308540110

**含意(検証指標として非常に強い)**: 10 日ランで測るべきは「初期グラフが保たれたか」ではなく、**「個人ごとの交流配分の形が保たれたか」**である。相手の顔ぶれは変わってよい。これは `k*` 観察と独立に取れる**創発の妥当性チェック**になる。

### 3.3 近接性(propinquity)— 顔なじみ層の較正

- Festinger, Schachter & Back (1950) Westgate 研究(MIT 既婚学生寮 240 人・部屋割りがほぼランダム): 報告された友人関係の **65% が 5 ドア以内**、**41% が隣室**(ランダムなら 10% の期待値)。
- 教室の座席近接が新規友人形成を予測する縦断研究も再現している。 https://pmc.ncbi.nlm.nih.gov/articles/PMC9113197/

**含意**: 現行の顔なじみ(`_link_colocated`: 同建物・同職場から**直近入場順に最大 3 人**)は、この「距離の急峻な減衰」を「上限 3 人」という実装都合で代用している。3 という数字に根拠は無い(コードのコメント自身が「密になりすぎないため」と書いている)。**建物内の階(`home_floor`)を距離代理に使えば、乱数ゼロのまま Westgate 型の減衰を入れられる**(住居割当は既に `home_floor` を持っている)。

### 3.4 焦点(foci)理論 — 「同じ場に通うから友達になる」

- Feld, S. L. (1981) "The Focused Organization of Social Ties", *American Journal of Sociology* 86(5):1015-1035。 https://www.journals.uchicago.edu/doi/abs/10.1086/227352
  友人関係は個人の心理や選択より**「活動を組織する外部の焦点」**(職場・学校・団体・場所)によって構造化される。推移性・橋・自我網密度への含意を導く。
- Brown, Noulas, Mascolo & Blondel (2013) "A place-focused model for social networks in cities", IEEE SocialCom。 https://arxiv.org/abs/1308.2565
  Foursquare の実データで、**2 人が出会った場所の「カテゴリ」が友人である確率を強く左右する**ことを示し、場所を焦点とした生成モデルで実ネットワークの構造指標を再現した。

**含意**: 我々の `org_id`(9,872 社)・学校 `org_id`・住宅建物・POI カテゴリはすべて焦点である。**「どのカテゴリの場が紐帯を生みやすいか」を POI カテゴリ別の重みとして持てる**(現行は org_id 一致の 1 ビットのみ)。

### 3.5 距離減衰 — 区外紐帯と近隣重みの根拠

- Liben-Nowell, Novak, Kumar, Raghavan & Tomkins (2005) "Geographic routing in social networks", *PNAS* 102(33):11623-11628。 https://www.pnas.org/doi/10.1073/pnas.0503018102
  **ランクベース友人関係**: 友人になる確率は距離そのものではなく**「自分より近くにいる人の数」に反比例**する。人口密度が高い場所ほど、同じ距離の相手と友人になる確率は下がる。**友人関係の約 1/3 は地理と無関係**。
- Illenberger, Nagel & Flötteröd (2013) "The role of spatial interaction in social networks", *Networks and Spatial Economics* 13(3):255-282。
  空間相互作用モデルに基づく確率的生成モデル。**距離 d の相手を social contact として受け入れる確率がべき則(指数 −1.6)**。さらに、**個人の contact 数は空間的位置とも機会の空間分布とも独立**(過疎地でも contact 数は変わらず、機会の少なさは「背景確率」の高さで補償される)。MATSim 系の交通シムに社会網を載せる文脈の一次研究。
  出典(学位論文版): https://depositonce.tu-berlin.de/handle/11303/9257
- Onnela, Arbesman, González, Barabási & Christakis (2011) "Geographic Constraints on Social Network Groups", *PLoS ONE* 6(4):e16939(通話 7,240 万件 + SMS 1,710 万件)。 https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0016939
  **小さな社会集団は地理的に非常に凝集しているが、集団規模が約 30 人を超えると地理的に急激に広がる**。

**含意**:
1. **「渋谷区という高密度地域では、同じ距離の相手と友人になる確率は低い」**(Liben-Nowell)→ 現行の `w_same_area`(同一建物のみ)は密度を無視している。ランクベースにすれば密度が自動的に効く。
2. **「contact 数は場所に依らない」**(Illenberger)→ **区外に住んでいる/区外出身であることは、その人の総紐帯数を減らす理由にならない**。来街者を「関係ゼロ」で入場させている現状は、この実証と真正面から矛盾する。R5 の直接の根拠。
3. Dunbar 層の 50 人前後で地理的凝集が壊れる(Onnela)→ **内側 2 層(親友・友人)は域内寄り、外側(知人)は域外寄り**という配分が実証的に支持される。

### 3.6 接触構造(顔なじみ層の上限の根拠)

- Mossong et al. (2008) "Social Contacts and Mixing Patterns Relevant to the Spread of Infectious Diseases", *PLoS Medicine* 5(3):e74(POLYMOD、欧州 8 か国・回答者 7,290 人・接触 97,904 件)。 https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.0050074
  強い**年齢同類性**(対角優位の混合行列)。
- **日本の一次データ**: Ibuka et al. (2016) 系の日本人成人 n=3,146(2011 年春、24 時間以内の 2m 以内対面会話): **1 日の接触数 平均 15.3 / 中央値 12.0**。学齢期と若年成人が最多。同年代との接触が最多。**日本人の接触頻度は欧州より多い**が年齢特異性のパターンは類似。
  https://tbiomed.biomedcentral.com/articles/10.1186/s12976-019-0102-8 (Munasinghe, Asai & Nishiura, *Theor Biol Med Model* 2019 — 日本の接触調査)

**含意**: 現行の顔なじみは**住居・職場それぞれで最大 3 人**(入場時に直近入場順で 1 度だけ)なので、1 人が初期に得る共在由来の関係は**最大 6 人**。日本の実測**1 日 12〜15 接触**の半分以下で、しかも**入場時 1 回きり**(日々の共在では増えない)。ただし「接触 = 顔なじみ(記憶に残る関係)」ではないので、**上限を上げるより「共在時間に応じて確率的に張る」方が理論的に正しい**(共在は曝露、紐帯は選択)。

### 3.7 弱い紐帯(初期グラフに埋め込むべき比率)

- Granovetter, M. (1973) "The Strength of Weak Ties", *AJS* 78(6):1360-1380。転職者 282 人の調査で、職を得た経路は接触頻度「よく会う」16.7% / 「たまに」55.6% / 「めったに」27.8%。回答者の紐帯の **69% が弱い紐帯・31% が強い紐帯**。

**含意**: 現行の初期次数(親友 3-5 + 友人 7-12 + 知人 20 = 有向 30〜37)は強:弱 ≒ (10〜17):20 = **約 40:60**。Granovetter の 31:69 に寄せるには**知人を増やす**のではなく、§8.1 の Dunbar 実証値どおり**内側 2 層を薄くする**(親友 1-3・友人 +4-8 = 累積 5.8)のが正しい — **総次数はそのままで比だけが 17:83 側へ動き**、Granovetter とも Dunbar とも同時に整合する。ただし §1.3 の減衰問題を先に直さないと、どちらにしても数日で消える。

### 機構 4 `friends.build_friend_graph` — **拡張**(スコアは維持、ループと閉包を置換)

**スコア関数は維持**(McPherson の重み順は実測と整合。§3.1)。変えるのは 3 点。

**(4-a) 候補ブロッキング** — O(N²) → O(N log N)

現行は各居住者について全居住者をソートする。代わりに:

1. **焦点ブロック**を先に作る: `org_id` / 学校 `org_id` / `home_building` / 年齢帯 × 職業。各ブロックは辞書 1 パス(O(N))で作れる。
2. 各人の候補は「自分の属する各ブロックから安定ハッシュで c 人」+「大域からランダムに少数」(=長距離リンク)。c は log N でスケールさせる先行がある(候補プール ζ/(log₂N)^0.6)。
3. 候補集合(数十〜数百人)だけをスコアでソートして Dunbar 層に割る。

→ **決定論は維持できる**(ブロック内の順序を pid ソートで固定し、抽選を blake2b にすれば `run.seed` 非依存のまま)。先行研究では KD-tree で 10⁶ ノードを 6.2 時間(10 コア)で生成しており、我々の 3〜4.5 万人なら**分オーダー**に落ちる。
出典: Buitrago López, Pastor-Galindo & Ruipérez-Valiente (2025) "Synthetic generation of online social networks through homophily", arXiv:2509.02762。 https://arxiv.org/abs/2509.02762
(実測 Bluesky 4M ネットワークの目標値: 密度 8.6×10⁻⁶ / 平均クラスタ係数 **0.262** / モジュラリティ 0.85)

**(4-b) 三者閉包(friend-of-friend)を足す** — 出会い経路の 40%(§3.1)

ブロッキング後、各人の候補プールに**既に張った友人の友人**を混ぜる 1 パスを足す。理論的枠組みは Kumpula et al. (2007) の **cyclic closure(三者閉包)+ focal closure(焦点経由の大域接続)**の 2 機構。 https://link.aps.org/doi/10.1103/PhysRevLett.99.228701

これを入れないとクラスタ係数が構造的に低いまま = **複雑接触(complex contagion)が起きない**。`k*`(世界改変者)の観察は集合行動の伝播が主題なので、**クラスタ係数は結果を左右する一次パラメタ**である。

**(4-c) 入場駆動化** — `persona-genesis-summary.md` G3

(4-a) のブロック索引を `sim` に持たせれば、入場者 1 人あたり O(候補数) で友人を張れる。day0 一括と同じスコア・同じ blake2b なので**同一人物ペアは同一の間柄**という現行の不変量が保たれる。**(4-a) が前提**。

## 5. (b-補) 区外関係の表現 — 「ノードではなく属性としての alter」

### 5.1 問題の学術的な名前

**境界特定問題(boundary specification problem)**: Laumann, Marsden & Prensky (1983) "The Boundary Specification Problem in Network Analysis", in *Applied Network Analysis*, pp.18-34。ネットワークの「どこまでを メンバーとするか」の規則の問題で、**除外されたアクターによる誤差が構造の見え方を歪める**。実在論的(realist)戦略 = 当事者の認識する境界 / 名目論的(nominalist)戦略 = 研究者が引く境界。
https://www.researchgate.net/publication/238338190_The_Boundary_Specification_Problem_in_Network_Analysis

**我々の境界は「渋谷区の地図 bbox」= 徹底して名目論的**であり、当事者の社会的世界とは一致しない。

### 5.2 先行分野の定石(3 つとも「外の世界をノードにしない」)

| 分野 | 手法 | 我々への写像 |
|---|---|---|
| **自我中心ネットワーク調査** | 名前想起法(name generator)。GSS の「重要な事柄を話し合う相手」(Burt 1984、最大 6 名)。**alter は回答者ではない**=ノードではなく**属性の束**として記録される(続柄・接触頻度・alter 間の紐帯) | **そのまま採用できる**。エージェント化しない alter を「属性の配列」として持つ |
| **交通需要モデル** | **external station / cordon**。研究対象域の境界に外部ゾーンを置き、I-E(内→外)・E-I(外→内)・E-E(通過)のトリップを扱う。NCHRP に手法が標準化されている | 「区外の実家」「区外の旧友」を**外部ゾーン**として持ち、帰省・電話・DM の宛先にする |
| **疫学 ABM** | 外部からの **importation**(外生的な感染力)。境界条件 = 「ある時点でエージェントを注入する」+「モデル内エージェントへの外部からの影響」 | 情報・噂・ニュースの外生流入(既に `news` がある)+ **関係経由の外生流入**(区外の友人からの DM) |

### 5.3 具体案(最小実装)

名簿に **`outside_alters`** を足す(生成は `build_persona_pool.py`・LLM ゼロ・決定論)。

```
outside_alters: [ {rel: "母", dist_km: 320, freq: "weekly"},
                  {rel: "高校の友人", dist_km: 45, freq: "monthly"}, ... ]
```

- **人数**: Illenberger の実証 = **contact 数は空間的位置に依らない**(§3.5)ので、「区外だから少ない」ではなく **Dunbar 層の総数から域内で張れた分を引いた残り**を区外に置くのが理論的に正しい。
- **距離**: ランクベース(Liben-Nowell)か べき則 −1.6(Illenberger)から抽選。
- **層の配分**: Onnela の「30 人を超えると地理的に広がる」(§3.5)に従い、**内側 2 層は域内優位・外側(知人)は域外優位**。
- **効き先(既存機構への接続点のみ・新しい LLM 呼を作らない)**:
  - `internet` の DM 相手(既に `MEDIA_ID=-1` のような非エージェント著者を扱える構造がある)
  - `inner_life` の長期目標・`needs` の関係欲求の充足源
  - 帰省・仕送り(`economy` の支出)・電話(既存の在宅行動)のトリガ
  - プロンプトの自己紹介文(「実家は仙台」は persona 文に既にある `residence_line` と同型)
- **来街者にも配れる**(エージェント化しないので O(1))。**現行で関係ゼロの 70.8 万人が、少なくとも「圏外の紐帯を持つ人」になる**。

**やらない方がよいこと**: 区外の人を実エージェントにすること。25 万人の在場予算を圏外の人格で食う理由が無く、`presence` ローテーションの設計とも衝突する。

## 6. LLM 社会シムの先行 — 初期関係の与え方

### 6.1 全体像: 使われている方式は 4 つしかない

| 方式 | 中身 | 採用例 |
|---|---|---|
| **A 手書きの自然言語シード記憶** | 関係をグラフではなく**散文**で与える | Generative Agents(Smallville) |
| **B 実グラフの取り込み** | 実プラットフォームの部分グラフをそのまま辺として使う | S3 / OASIS(コア利用者)/ GraphMind |
| **C 実シードに合成をぶら下げる** | 実ユーザーをコアにし、合成ユーザーを興味で固定確率フォローさせる | **OASIS の 100 万人ラン** |
| **D コールドスタート(初期関係ゼロ)** | 何も与えない | Project Sid / Moltbook |
| (E 研究対象止まり) | LLM にグラフ自体を生成させる | Chang et al. ICWSM 2025 |

**最重要の発見: 我々に最も近い AgentSociety(1 万エージェント・実都市・OSM+POI)は、初期網の構築方法を規定していない。** 論文は「ソーシャルネットワークはユーザーが与えて読み込ませる(*The social network is provided and loaded by users.*)」と明言する。**これは我々が埋めに行く空白であって、既に解かれた問題を解き直しているのではない。**
出典: Piao et al. (2025) *AgentSociety*, https://arxiv.org/abs/2502.08691

### 6.2 各先行の具体的な機構

**Generative Agents(Park et al., UIST'23)** https://arxiv.org/abs/2304.03442
- 初期関係は**エージェント 1 人につき 1 段落の自然言語**で手書きし、セミコロン区切りの各句を初期記憶として投入する。**グラフのデータ構造は存在しない**。
- 設計上の要点: 紐帯の強さが**散文の中で順序づけられている** — 「数年来の知り合い」「よく知っている」「**存在は知っているが会ったことはない**」「同僚」「友人」。
- 創発の実測: 「〈名前〉を知っているか」の**相互**肯定を辺として、**密度 0.167 → 0.74(ゲーム内 2 日・25 人)**。情報伝播は市長選 1→8 人(4%→32%)、パーティ 1→13 人(4%→52%)。
- ⚠ **スケールしない**: 25 人村の初期密度 0.167 は、実都市(密度 10⁻⁴ オーダー)とは別物。

**「1,000 人のGenerative Agent」(Park et al., 2024)** https://arxiv.org/abs/2411.10109
- **ネットワークが一切ない**。1,052 人を 2 時間の AI 面接から個別に作り、**相互作用させない**。GSS 正規化精度 0.86 / Big Five 0.80。
- → **2 本の Park 論文は綺麗に分業している**: Smallville = 社会網あり・人口の現実性なし / 1,000 People = 人口の現実性あり・社会網なし。**両方をやった先行は無い。我々のプロジェクトはその隙間にある。**

**OASIS(Yang et al., 2024・最大 100 万人)** https://arxiv.org/abs/2411.11581
- 実データ: Twitter15/16 の 198 伝播事例から X API で「プロフィール・フォロー関係・過去投稿」を取得し**時間帯別の活動度**まで作る。Reddit は実コメント 116,932 件。集団極性化は**実ユーザー 196 人**が土台。
- **100 万人への拡大機構**: 実ユーザーを**コア**とし、生成ユーザーはスポーツ・娯楽などの**トピックでフォロー関係を作る**。**コアをフォローする確率 0.2**(「多様性を確保し密度が高くなりすぎるのを防ぐ」)。これで**スケールフリー性を保つ**と主張。
- 実験の梯子は 196 → 10,196 → 100,196 → 1,000,000。**「+196」= 実コアは固定で合成の詰め物だけ増える**。→ **実データで較正し、合成で拡大する**という再利用可能な型。
- プロフィールは人口分布から生成するが、年齢・性格・職業を**独立変数として扱う**(論文自身が明言する簡略化 = 職業と年齢の相関が無い。**我々の名簿はここは既に上**)。
- ⚠ 付録の擬似コードは未読(添付キーの正確な形は未検証)。散文は 3 経路で一致。

**S3(Gao et al., 2023)** https://arxiv.org/abs/2307.14984 — 話題キーワードで投稿を絞り、著者をノードにし、「抽出集合の中に followee が居れば有向辺を張る」= **誘導部分グラフだけを回す**(全体は大きすぎる、と明言)。ジェンダー 8,563 人/25,656 関係、原子力 17,945 人/77,435 関係。属性(年齢・性別・職業)は**投稿から LLM が推定**。

**AgentTorch / Chopra et al.** https://arxiv.org/abs/2409.10568 — **ニューヨーク市 840 万エージェント**。「LLM アーキタイプ」で個体ごとの LLM 呼を避ける。⚠ **接触網の構築方法は未検証**(疫学系譜から TRANSIMS/EpiSims 型と推測されるが確認できていない)。**我々の規模に最も近いので、再確認の価値が最も高い 1 本**。

**SocioVerse(2025)** https://arxiv.org/abs/2504.10157 — 実ユーザー 1,000 万人プール(X 100 万人 + 小紅書 916 万人)から **IPF** で人口統計の同時分布に合わせて標本抽出。**4 つの相互作用様式のうち 3 つはネットワーク不要**。IPF の使い方は我々の人口合成に流用価値がある。

**Project Sid / Altera.AL(2024)** https://arxiv.org/abs/2411.00114 — Minecraft・最大 500〜1000+。**事前の社会グラフ無し**(同じ村に湧いて自由に交流)。シードは**紐帯ではなく役割**(賛税/反税インフルエンサー 3 人・「パスタファリアニズムの司祭 20 人」)。

**LLM にグラフを作らせる路線(方式 E)**
- Chang, Chen, Papachristou, Kleinberg, Yang, Leskovec (ICWSM 2025) https://arxiv.org/abs/2408.16629 — **「local(ペルソナ 1 人ずつ紐帯を作る)」が「global(一括)」に勝つ**。密度・クラスタ・連結・次数分布で実網に一致。**ただし政治的 homophily を著しく過大評価する**。
- 日本を含む続報 https://arxiv.org/abs/2605.12898 — 米/**日**/印/伯で 192 網。「文化的枠づけが inbreeding homophily と最大連結成分に測定可能な非一様の変化を生む」。⚠ 日本に関する 2 つの記述が retrieval 上矛盾して見える(要原典確認)。**50 ペルソナ固定でスケーラビリティの証拠ゼロ**。
- → **方式 E は 1,000 ノード超の実績が無く、homophily バイアスが実証されており、日本文化での挙動も未特性化。25 万〜100 万を単独で担わせるには早い。**

### 6.3 初期網の構造は結果を変えるか — **変える。しかも直感と逆向きに。**

| 出典 | 主張 | 数値 |
|---|---|---|
| Watts (2002) *A simple model of global cascades*, PNAS 99(9):5766-5771 [doi:10.1073/pnas.082090499](https://doi.org/10.1073/pnas.082090499) | 大域カスケードは平均次数 z の**有界な窓の中でしか起きない**(疎すぎても密すぎても起きない=相転移が 2 つ) | — |
| 同上 | ⚠**最重要**: 「**べき則次数分布のランダムグラフは、同じ z の一様ランダムグラフよりランダム衝撃に対して遥かに脆弱でない**」。一方「**閾値の異質性が増すと系は不安定になりカスケードの範囲が広がる**」 | 次数の異質性と閾値の異質性が**逆向き**に効く |
| Centola (2010) *Science* 329:1194-1197 [doi:10.1126/science.1185231](https://doi.org/10.1126/science.1185231) | 同じ平均次数で**クラスタ格子 vs ランダム網**を無作為化実験。行動の採用率は **クラスタ 53% vs ランダム 38%** | 検証: O'Sullivan et al. [Front. Phys. 3:71](https://doi.org/10.3389/fphy.2015.00071) |
| Centola & Macy (2007) AJS 113(3):702-734 [doi:10.1086/521848](https://doi.org/10.1086/521848) | 長い紐帯が役立つのは**幅の広い橋**(クラスタ間の並行した複数の紐帯)のときだけ | — |
| TRAILS(Ye, Cao, Chen, Ferrara 2026)https://arxiv.org/abs/2605.18890 | **初期網の homophily をわずかに上げるだけで最終の assortativity が 0.142 → 0.287** に動き、同群辺比が 0.5 を跨ぐ=**エコーチェンバーが出るか出ないかが初期グラフだけで質的に反転**。ハブを誰に割り当てるかでも 0.690 → 0.759 | LLM シム特有の監査 |

**渋谷への直接の含意(科学に効く判断であって工学の細部ではない)**:
- **共在・職場由来で初期網を作れば高いクラスタ係数がほぼ無料で手に入る = 複雑接触に有利な領域**。逆に**ランダムや優先的選択(BA)で作るとクラスタが壊れ、集合行動が観察不能になりうる**。
- `k*`(世界改変者)の観察は集合行動の伝播が主題なので、**初期トポロジは実験条件として少なくとも 2 本の感度ランを予算すべき**(単一の初期グラフは未監査の交絡)。

### 6.4 コールドスタート/バーンインは代案になるか — **我々の規模では不可**

- Project Sid(500 人)・Moltbook(数万)は初期関係ゼロで豊かな社会構造を出した。
- しかし Smallville が 2 日で密度 0.74 に達したのは「全員が互いに見える村」だから。**25 万人では 1 ペアあたりの遭遇率が 4 桁下がるので、10 日ランのコールドスタートはグラフが空のまま終わる。**
- **最も方法論的に強い折衷は「安い別モデルでバーンインして初期状態を作る」**: Hunter, Mac Namee & Kelleher (2018) [JASSS 21(4):9](https://www.jasss.org/21/4/9.html) は、感染症 ABM の前に **Schelling 型の社会経済分居モデルを収束するまで回して初期配置を作る**。理由は「**そのクラスタリングを捉えないとモデルの結果が正確でなくなりうる**」。実際、無作為初期化は実際の住宅価格データから計算した分居指数より**系統的に低いクラスタリング**しか出さない。
- → **我々の日次の在場・共在機構は、まさに EpiSims 型バーンインの基盤として使える。**

### 6.5 先行が我々に許すこと(まとめ)

1. **誰も解いていない**。規模で並ぶ 2 本(OASIS 100 万・AgentTorch 840 万)は単一プラットフォームか疫学。問題の**種類**で並ぶ AgentSociety は初期網をユーザーに丸投げしている。
2. **弁護可能な方式は「共在由来 + 関係タイプ付き」**。実グラフ取り込みは物理都市では不可能(渋谷の友人関係センサスは存在しない)。純合成生成器はクラスタを壊す。LLM 生成は 1k ノード超の実績が無い。**活動/共在由来(EpiSims/TRANSIMS 系譜)だけが、実データの錨と都市規模の実績の両方を持つ**——そして**我々は既にその機械(世帯・職場束ね・日次在場)を持っている**。
3. **AgentSociety の「スキーマ」は真似てよい**(家族 / 友人 / 同僚 × 強度 0-100・シム中に可変)。**方法が無いだけでスキーマは事実上の標準**。我々の `household` / `org_id` / `relations.tier` にほぼそのまま対応する。
4. **紐帯は段階づけた自然言語としても描画する**(Park の「よく知っている / 存在は知っているが会ったことはない」)。数値の closeness は解析用に保ち、プロンプトには散文を出す — `relations.social_lines` が既にこの形。
5. **コスト梃子**: TopoSim(https://arxiv.org/abs/2604.18011)は構造的に等価なエージェントで LLM 呼を共有し、**トークン 40〜90% 削減**を 1 万エージェントまで実証。25 万〜100 万では実行可能性そのものを左右しうる。

⚠ **未検証(要再確認)**: AgentTorch の接触網構築方法(最重要の空白)/ AgentVerse / Centola の「4 倍速」と N=1,528 / 上記日本 lcc の矛盾 / OASIS の正確な添付カーネル / S3 の元プラットフォーム。

## 7. SNS グラフの現実性(数値)— **日本の部分グラフの実測値が存在する**

### 7.1 最重要の一次資料 — Myers et al. 2014 は**日本の次数分布を別掲している**

Myers, Sharma, Gupta & Lin (2014) "Information Network or Social Network? The Structure of the Twitter Follow Graph", WWW'14 Companion, 493-498。
https://archives.iw3c2.org/www2014/proceedings/companion/p493.pdf

**社内の完全スナップショット**(2012 年後半・**アクティブ 175M ユーザー / 約 200 億辺**)なので、クロールのバイアスが無い。表 1(パーセンタイルと対数正規のあてはめ):

| | 25% | 50% | 75% | 95% | 最大 | μ | σ² |
|---|---:|---:|---:|---:|---:|---:|---:|
| In-All(フォロワー数) | 4 | 16 | 65 | 339 | 14.7M | 2.83 | 3.36 |
| Out-All(フォロー数) | 11 | 39 | 121 | 470 | 757k | 3.56 | 2.87 |
| Mut-All(相互) | 3 | 13 | 50 | 223 | 563k | 2.59 | 3.03 |
| **In-JP** | **4** | **17** | **60** | **347** | **1.2M** | **2.84** | **3.21** |
| **Out-JP** | **6** | **23** | **71** | **360** | **297k** | **3.08** | **2.93** |
| **Mut-JP** | **4** | **15** | **50** | **253** | **276k** | **2.72** | **2.90** |

- 「**入次数と相互次数はべき則、出次数は対数正規が最良のあてはめ**」
- **相互性 42%**(Kwak 2010 のクロールでは 22.1% だったが、完全スナップショットでは 42%)
- **日本は明確な外れ値**: 「日本は米国やブラジルに比べてクラスタ係数が高い……日本では相互性の率がずっと高い」。日本のクラスタ係数は次数 200 あたりから**上昇**し 1,000 で頂点(論文は「巨大なクリーク」に帰す)。中央値からの導出では相互/出 = 15/23 = **0.65**(全体 13/39 = 0.33)= **およそ 2 倍**。
- 連結性: 最大弱連結成分 92.9% だが**最大強連結成分は 68.7%**、**アクティブの 30% 超は相互辺を 1 本も持たない**。
- 平均経路長 4.17(相互)/ 4.05(有向)。相互グラフのクラスタ係数は次数 5 で 0.23、20 で 0.19、100 で ~0.14。

⚠ **注意**: 表の α 列(1.28〜1.39)は α<1 では正規化できないので **CCDF/裾指数**とみられる(PDF 指数に直すと ≈2.3 で Kwak の 2.276 と整合)。**μ/σ² の対数正規列の方が信頼できる**。調査担当が公表パーセンタイルと突き合わせて検証したところ、**p50/p75/p95 を約 5% 以内で再現した**(In-JP: 予測 17.1/57.3/326 vs 公表 17/60/347)= **そのまま生成分布として使える**。

### 7.2 **現行 k=6 の正確な位置**

> **日本の Twitter 出次数の 25 パーセンタイルは 6。現行の `follow_k = 6` は、偶然ほぼ正確に 4 分位点に座っている。問題は値ではなく「分散がゼロ」であること。**

| | 現行 | 日本の実測(Out-JP) |
|---|---:|---:|
| 25% | 6 | 6 |
| **50%** | **6** | **23** |
| 75% | 6 | 71 |
| **95%** | **6** | **360** |

これが「インフルエンサーが原理的に存在しない」の正体である。**中央値を 23 に、95 パーセンタイルを 360 にするだけで、`infoenv.influence` の `follower_threshold` が初めて意味を持つ。**

### 7.3 べき則か対数正規か — **対数正規(または打ち切り付きべき則)を使う**

- Kwak, Lee, Park & Moon (2010) WWW'10(41.7M プロフィール・14.7 億フォロー関係)は指数 **2.276** を報告するが、**論文自身の結論は「べき則ではない」**:「べき則でないフォロワー分布、短い実効直径、低い相互性を見出した — いずれも既知の人間の社会ネットワークの特徴からの逸脱である」。10⁵ を超えると**べき則より重い**(セレブ効果)。
  https://snap.stanford.edu/class/cs224w-readings/kwak10twitter.pdf
- Clauset, Shalizi & Newman (2009) *SIAM Review* 51(4):661-703 https://arxiv.org/abs/0706.1062 — 両対数プロットで直線に見えることは「必要条件であって十分条件ではない」。MLE + KS 検定 + 尤度比検定の手続き。
- **Broido & Clauset (2019) "Scale-free networks are rare", Nature Communications 10:1017** https://arxiv.org/abs/1801.03400 — 927 データセット。**対数正規がべき則に勝つのが 45% 対 12%**(43% は決着せず)=「88% のケースで対数正規はべき則と同等以上のあてはめ」。**社会ネットワークに限れば Strong / Strongest に達したものは 1 つも無い**:「社会ネットワークはせいぜい弱くスケールフリーであるにすぎない」。

→ **実装の結論: 純粋なべき則ではなく対数正規(§7.1 の μ/σ²)を使う。**

### 7.4 Facebook — 「上限つき・べき則でない」の実証

Ugander, Karrer, Backstrom & Marlow (2011) "The Anatomy of the Facebook Social Graph" https://arxiv.org/abs/1111.4503(**7.21 億アクティブ・約 690 億の友人関係**)
- **友人数の中央値 99**(平均は 190.6 と導出可能 = 平均/中央値 ≒ 2 倍が歪みの署名)
- 「**厳密なべき則モデルは Facebook の次数分布には不適切**」。両対数で「実質的な曲率」がある
- **模倣価値のある 2 つのアーティファクト**: 「20 人付近の小さな異常」(製品の誘導)と「5,000 人のはっきりした打ち切り」(制度的上限)。**Twitter 側にも 20(オンボーディング)と 2000(旧上限)の同型の人工物がある**
- クラスタ係数は次数 100 で 0.14。**次数相関 r = 0.226**
- **友人関係のパラドクス: 83.6% のユーザーは「自分の友人の友人数の中央値」より友人が少ない**
- Backstrom et al. (2012) "Four Degrees of Separation" https://arxiv.org/abs/1111.4570 — 平均距離 4.74。**イタリア・スウェーデンの部分グラフは全体より平均距離が短い**:「平均距離は実際にはネットワークの規模よりもユーザーの地理的な近さに依存する」← **単一区の渋谷グラフに直接効く**

Dunbar (2016) *R. Soc. Open Sci.* 3:150292 https://pmc.ncbi.nlm.nih.gov/articles/PMC4736918/ — 英国 2 調査(n=2,000 / 1,375)。**Facebook 友人数の平均 155.2 / 182.8 で「150 付近に顕著な最頻」**。支援クリーク 4.1・共感集団 13.6・比 ≈3。結論: **オンラインの網の大きさは対面の網と同程度 = SNS は社会的中核を拡大しない**。

### 7.6 インフルエンサーの裾 — **対数正規だけではセレブが生成されない**

検証済みの一次値:
- Kwak (2010): **100 万フォロワー超はわずか 40 アカウント / 4,170 万人**(= 0.000096%)
- Myers (2014): 95 パーセンタイル入次数 = **347(日本)** → **約 5% だけが 350 フォロワーを超える**。最大は日本で 1.2M

In-JP 対数正規(μ=2.84, σ=1.7916)からの導出(**調査担当の計算であり公表値ではない**):

| 閾値 | 割合 | 25 万人あたり | 100 万人あたり |
|---|---:|---:|---:|
| >100 フォロワー | 16.2% | 40,564 | 162,257 |
| >1,000 | 1.16% | 2,898 | 11,592 |
| >10,000 | 0.019% | 47 | 189 |
| >100,000 | 0.00006% | 0.2 | 0.6 |

⚠ **この表が露わにする失敗モード**: **対数正規は極端な裾を過小評価する**。100 万フォロワー超を実質 0 人と予測するが、実測では 4,170 万人中 40 人・最大 1,470 万が存在する。→ **純粋な対数正規ではセレブが 1 人も生まれない。本体は対数正規、セレブの裾は手で置く**(報道機関・区の公式・店舗・配信者 = **我々の名簿には既に「配信者 16 人」「議員 34 人」が居る**)。

### 7.7 生成アルゴリズム — **Miller & Hagberg (2011) の Chung-Lu が答え**

Miller & Hagberg (2011) "Efficient Generation of Networks with Given Expected Degrees", WAW 2011。
https://aric.hagberg.org/papers/miller-2011-efficient.pdf

- 辺確率 p_uv = w_u·w_v / (N⟨w⟩)。素朴には O(N²) だが、**Algorithm 2 は期待 O(N + M)**。「期待次数が有限平均の分布から選ばれるなら、N→∞ で O(N)」
- 機構: 重みを**降順**にソートし、幾何スキップ δ = ⌊ln r / ln(1−p)⌋ で次の候補へ跳ぶ(高速 Erdős-Rényi のトリック)+ q/p での棄却。**単一の逐次パス = seed 可能 = 決定論・ストリーム可能**。NetworkX の `expected_degree_graph` として実装がある
- ⚠ **セレブの切り落とし**: 「w_u w_v /N⟨w⟩ > 1 になりうる。その場合 p=1 とし、u の期待次数は w_u より小さくなる」= **まさに欲しい裾が削られる**。論文は代替式 p = 1 − exp(−w_u w_v/N⟨w⟩) を挙げている
- 著者自身が「**同類混合(重みの近いノードが優先的に繋がる)を持つモデルへ一般化できる**」と注記 → **homophily のフック**

比較対象: **配置モデル**は次数列を厳密に満たすが自己ループ・多重辺が出て O(N+M) より遅い。**BA** は指数が 3 に固定され、相互性もクラスタも次数列も制御できない(BA 論文自身が実網は 2.1〜4 に散らばると認めている)。**R-MAT**(Chakrabarti, Zhan & Faloutsos 2004)は **O(E log N)・ネイティブに有向**で「a≫d の歪みが対数正規と DGX 分布を生む」= §7.3 の合意と一致し、**コミュニティ構造も無料で付く**が、目標次数列ではなく (a,b,c,d) で操縦する。

### 7.8 SNS 層の具体的な設計案(§4 機構 2 の詳細)

1. **プラットフォーム所属で門を作る**: 「SNS」ではなく **X 利用率**(§7.5)で個体ごとに参加/非参加を決める。年代別の実測をそのまま使う(20代 73.4% / 60代 24.8% / 70代 10.8%)。**非参加者は follows も followers も持たない** — 現行は全員が持っている。
2. **相互グラフを先に作る**: Mut-JP(μ=2.72, σ²=2.90)の対数正規を次数列として、**無向の Chung-Lu** を張る。
3. **片方向辺で上乗せ**: In-JP / Out-JP の目標次数まで一方向の辺を足す。→ **Myers の相互性構造が構成的に再現される**。⚠ **素の Chung-Lu を有向で 2 回引くと相互性がほぼ 0 になる**(各方向を独立に引くため)。現行の一様抽選も同じ欠陥を持つ。
4. **実現は Miller-Hagberg の O(N+M)**(§7.7)。seed 可能・単一パス・決定論。
5. **セレブの裾は手で置く**(§7.6)。報道・区公式・店舗・配信者・議員。
6. **逆索引**(§1.2)。これが無いと次数を偏らせた瞬間に `follower_count` が更に遅くなる。

### 7.9 ⚠ 未解決の設計判断(ユーザー判断が要る)

| 選択肢 | 意味 | 影響 |

| **(b) シム外の非エージェント・フォロワーを足す** | セレブ口座が現実的なリーチを持つ | §5 の「区外 alter」と**同じ設計思想**で一貫する。`MEDIA_ID = -1` の非エージェント著者を既に扱える構造がある |

- 性別: 相談相手の性別異質性は一般人口の約 70%。**22% は異性の相談相手がゼロ**。
- 「異質な個人間の紐帯は解消率が高い」= 我々の日次減衰と整合。

判断の軸は 1 つ: **「名簿を作り直さないとできないこと」と「エンジンだけで直せること」を分け、前者だけを再生成に同期させる。**

### フェーズ 0 — 名簿に触らずに今すぐできる(再生成を待たない)

| 手順 | 内容 | 効果 | リスク |

| **社会的シグネチャの保存** | 個人ごとの「ランク順 alter への交流配分」が**相手が入れ替わっても保たれる**(Saramäki et al. 2014 PNAS。§3.2)。**10 日ランで取れる、`k*` と独立な創発の妥当性チェック** |

### やらないこと(調査の結論として明示的に除外)

| 除外 | 理由 |
|---|---|
| **ERGM で初期網を推定** | 推定対象の実グラフ(渋谷の友人関係センサス)が存在しない。§2 |
| **LLM にグラフを生成させる** | 政治的 homophily の系統的過大評価が実証済み、1,000 ノード超の実績なし、日本文化での挙動が未特性化。§6.2 |
| **区外の人をエージェント化** | 在場予算を圏外の人格で食う。`presence` ローテーションの設計とも衝突。§5.3 |
| **コールドスタート(初期関係ゼロ)** | 25 万人では 1 ペアあたり遭遇率が 4 桁下がり、10 日ランでグラフが空のまま終わる。§6.4 |
| **BA / Watts-Strogatz をそのまま使う** | クラスタ係数を壊す = 複雑接触(= `k*` の主題)が観察不能になりうる。§6.3 |

### 規律(R1 整合)

- **すべて既定 OFF**。`friend_graph.enabled=false` / 新トグル OFF で**現行とバイト一致**(乱数消費・イベント列・プロンプト)。
- **新しい named stream しか足さない**(`RngHub.stream` は呼ぶたびに新しい Generator を派生するので既存 draw 列は 1 粒も動かない)。第111・第112 の全レーンが乗ってきた不変量。
- **`friend_graph.seed` は据え置き**。スコア関数を変えると全ペアの間柄が変わるので、**旧挙動への退路**(`--no-*` 相当 or conf の 1 行)を必ず用意する(第109 の `--no-occupation-map` と同じ作法)。
- 名簿側の変更は **`meta.json` の `schema_version` を上げ**、`status: partially-real` の内訳(§8 で新たに実数化できた項目)を更新する。

# 情報目撃の実証値: 広告・店内・街頭・警報(WITリサーチ レーン1)

> 2026-08-20。witness再設計(チャネル別到達×注意ゲート)のための実証値。全て出典付き。
> 結論: 「到達≠注意通過」の乖離は実測で1桁。現行の「半径60m×1時間の在場者全員に信念付与」は
> 大型ビジョンで1.4倍・店内の棚で7倍・夜間街頭事象で3倍の過大付与。

## 2. 実装可能な関数形

### POSTAR視認率回帰(数値検証済み・そのまま使える)
```
HR = a0 − a1·D − a2·θ + a3·A     D:距離m θ:正対からの角度deg A:面積m²
  屋外・歩行:  a0=0.651 a1=0.0059 a2=0.0030 a3=0.0101
  屋内・歩行:  a0=0.700 a1=0.0126 a2=0.0049 a3=0.0286
  屋外・車:    a0=0.463 a1=0.0044 a2=0.0018 a3=0.0087
```
- cutoff半径は式が自動決定: 屋外6シート≈114m・屋内≈60m。小型サインは視角則 D_max≈300×文字高(m)。
- 留保: 静止画6秒自由視のラボ値=上限値として扱う。自己申告(81-90%)はアイトラッキング比2-3倍過大。
- Route(英国OOH公式)は0.1秒毎の飽和曲線 P=1−exp(−k·Σvis)・視認コーン左右各120°・デジタル×1.5/1.2。

### 街頭事象の目撃確率
```
p_witness = base(昼0.72/夜0.35) × 負荷(タスク1つ−15pt・通話×0.49・同伴×1.39)
          × 距離減衰(Nyman: 8m基準→60mで0.17→77mで0) × 顕著性(群集視線コピー: 1人42%→15人86%)
```
- 検証アンカー: 都市の公共紛争1件あたり**注視傍観者16.3人**(SD13.2)・1人以上反応90.9%・介入3.76人・通報5%・声かけ2%(Philpot 2020, CCTV 219件 / Van Dijk 1983)。

### 店内
```
p = 1{来店} × 1{売場立寄} × 棚スキャン0.145 …価格変更の認知はさらに<0.5
```

### 変化検出は最も低い(設計含意5)
- 会話相手すり替えに50%非検出(Simons & Levin 1998)・ゴリラ注視者の60%が非知覚(Memmert 2006)。
- **静的知識(注視不要・標識再生80%)と変化情報(注視必須)を型で分ける**(FHWA-HRT-13-044)。

## 3. 設計への含意(5点)
1. factを「チャネル付きメッセージ」に分離し到達と注意の2段ゲート化=信念付与量が1-2桁落ちる=計算爆発の根治と現実整合が同じ手で達成される。
2. 半径は情報種別+距離は連続関数(POSTAR線形/Nyman減衰)。犯罪は「事象認知」と「加害者識別」を距離比6.4:1で分離。
3. **混雑度でなく「注意負荷」を変調変数に**(密度が知覚を下げる直接実証は無い。負荷−15pt/タスク・同伴+20pt・群集は顕著性の増幅器)。
4. 放送系は到達高×信念/行動転換低・対人系は逆(転換1.5倍)。「近所も避難していない」35.3%=社会的証明の実測値。
5. 変化検出型factは新規出現型より1段厳しいゲート。

## 4. 直接の実証なし(正直な欠測・抜粋)
- 群集密度そのものが個人の知覚率を下げる直接実証(密度操作研究なし)
- 街頭犯罪1件あたり平均目撃者数の警察統計(代替=Philpot 16.3人)
- 店内チャネルの到達較正公開モデル・ハイパーローカル情報のN日後認知曲線・街頭チラシ受取率

## 追補: 店内価格知識・棚注意の精密値(小売深掘りサブ調査・2026-08-20)
- 実店舗の棚: 選択肢のうち注意が向くのは**25.7-27.5%**のみ(Gidlöf 2013・90SKU・モバイルアイトラッキング)。
  実験室の小棚(12SKU)ではnoting 72%→考慮に残るのは1/3(全体の24%)・注視の2/3は記憶に残らない(Chandon 2009)。
- 価格視線: **考慮の77%は価格を一度も見ない**・購入時ですら14-60%が非注視(Kovacheva & Inman 2024)。
- 価格再生: 正確20.9%・±5%累積47.1%・全く不能21.1%(Dickson & Sawyer 1990内訳・二次引用)。
  Vanhuele & Drèze 2002(仏400名)は±5%以内21%・正確再生2.1-10%。
- 欠品反応の内訳(Gruen 2002・回答71,000人超): 他店31%/他ブランド26%/同ブランド別品19%/延期15%/非購入9%。
  「欠品に気づくか」の検出率研究は**直接の実証なし**。
- 変化盲: 人物すり替え非検出53-67%(平均59%)。棚割変更のchange blindness率は**直接の実証なし**。
- → WITのin_place p_notice=0.30は実店舗棚注意25-28%と整合(妥当帯0.15-0.35)。

# 創発設計

### IDEA: 指紋ブラックリスト(プロンプトに書いてはいけない表現の一覧)
- 出典: リポ5 講評 A4.0 の減点根拠 / リポ3 講評 A6.0 の減点根拠 / リポ2 講評 A7.5 の減点根拠
- 分類: 創発設計
- 内容: 3 チームの A 減点根拠を突き合わせると、審査者が「行動誘導」と判定する表現のパターンが抽出できる。(a) 計算済み最適解の予告(「Computed optimal escape: X」)、(b) 価値の順序づけ(「Priorities: 1. Survive 2. Warn others」)、(c) 直接の行動指示(「STAY HERE unless…」「Move in this direction」)、(d) 優先度宣言(「PRIORITY: …」)、(e) **発話の内容構造の規定**(「1. 位置 2. 強度 3. 方向 4. 推奨」)、(f) **毎ターンの TODO リスト注入**(未訪問リスト・残りステップ・リマインダ)、(g) 感情表現のナッジ(「怒り・不安・疑念を含めてよい」)、(h) 属性から行動への直接指定(「不適応だから自分からは話しかけない」)。
- shibuya-simulation への適用案: 上記 8 パターンを **no-fingerprint 点検の grep チェックリスト**として `tools/` に実装し、CI かゴールデンテストで全プロンプト構築箇所を機械的に走査する。特に (e)(f) は「進行を保証するため」に入れがちで見落としやすい。shibuya の日次計画/予定帳簿が「エージェント自身が作った計画の提示」なのか「環境からの指示」なのかを、この基準で仕分けて devlog に明記する。
- web リサーチ知見: ―
- 重要度: ★★★

### IDEA: 動機は世界に置き、プロンプトには置かない
- 出典: リポ4 `hidden_theme` / `_eval_review` の指摘「`hidden_theme` 本体も世界ルール側に再配置すべき余地」
- 分類: 創発設計
- 内容: リポ4 は AI に「職場環境そのものを少しずつ作り変えていく」という裏テーマをプロンプトで与え、実際に環境形成行動が観測された。しかし講評・検証者の双方が「これは明示的な行動方針誘導」と減点した。**与えた動機から生じた行動は、創発の証拠にならない**。
- shibuya-simulation への適用案: 主研究課題「世界を変えようとする個体は生まれつきか環境から創発するか」にとって決定的。プロンプトに「世界を変えろ」に相当する語を一切書かず、代わりに**世界の側に機会構造**(制度が変更可能である / 提案が通る経路がある / 他者の行動が実際に変わる / 変えた結果が本人に返る)を実装し、「変えようとする個体が出るか」を観測する。shibuya は既に組織・経済・選挙・SNS を持つので機会構造は概ね揃っている。残る作業は**プロンプト側に動機が漏れていないかの点検**。「出ないなら k が足りない」が k* の意味になる。
- web リサーチ知見: ニッチ構築(niche construction)— 生物が環境に適応するだけでなく環境の側を改変し、その改変が選択圧を変える理論。「世界を変えようとする個体」を価値語でなく既存概念に接続できる。Odling-Smee, Laland & Feldman, *Niche Construction* (2003): https://press.princeton.edu/books/paperback/9780691044378/niche-construction
- 重要度: ★★★

### IDEA: 行動制約を物理制約に翻訳する
- 出典: リポ3 講評の提言(host=stay 強制について)
- 分類: 創発設計
- 内容: リポ3 は「企業担当者は動かない」を `action_type='stay'` の強制と LLM 呼び出しスキップで実装し、A の減点を受けた。講評の代案は「**host は受付カウンタという物理的場所に拘束されるので動けない**、と世界ルール側で表現し直せ」。同じ挙動を、指示ではなく物理で作る。
- shibuya-simulation への適用案: shibuya は「サービス提供者も全員エージェント」という方針なので、店員・駅員の職務拘束が必ず問題になる。プロンプトで「持ち場を離れるな」と書くのではなく、**勤務中は移動可能領域が店舗内に制限される**(SFM の walkable mask を勤務状態で切り替える)形にする。屋内 SFM を既に持っているので実装コストは低く、A の毀損もない。同じ翻訳を「終了時刻になったら帰る」にも適用でき、時刻を渡すだけで帰る判断は個体に委ねられる。
- web リサーチ知見: ―
- 重要度: ★★★

### IDEA: ペルソナ属性は行動ではなく履歴とパラメータで与える
- 出典: リポ3 講評の提言(`school_fit='不適応'` の発話抑制について)
- 分類: 創発設計
- 内容: リポ3 は不適応ペルソナに「自分からは話しかけない(挨拶も自発的にはしない)」と system_prompt で直接指定して減点された。講評の代案が具体的で優秀 —「**過去の対人成功体験の少なさを memory として与え、talkativeness 値だけを下げる**」。属性 → 行動の対応づけを LLM の解釈に委ね、環境は履歴と数値だけを渡す。
- shibuya-simulation への適用案: shibuya のペルソナプール設計にそのまま適用。属性(内向的・高齢・外国籍など)から行動を書き下すのではなく、(a) その属性が生む**過去の経験を memory の初期値**として与え、(b) **連続パラメータ 1 つだけ**を動かす。同じ属性でも履歴の違いで振る舞いが分かれることが観測でき、「生まれつき vs 環境」の実験にも直結する。
- web リサーチ知見: ―
- 重要度: ★★★

### IDEA: フェーズ分離で「答え」を発話フェーズに漏らさない
- 出典: リポ1 講評 D9.0 の第一根拠(Phase 1 = メッセージ決定は位置情報なし / Phase 3 = 行動決定は位置情報あり)
- 分類: 創発設計
- 内容: 発話を決める段階で座標を渡すと、LLM は「(15,10) から離れるべき」という計算結果をそのまま喋り、情報伝播が「計算の共有」に堕する。位置を隠すことで、何を共有するかが LLM の内部知識と記憶に依存するようになる。講評が「秀逸」と名指しした唯一の工夫。
- shibuya-simulation への適用案: **ラベル伝播研究に直結**。発話生成フェーズで「その語をどこから聞いたか」「誰が既に知っているか」「その語の真偽」といった内部状態を渡していないか点検する。渡していると、観測しているのは伝播ではなく**全知の共有**になる。一般則として「**伝播を観測したいなら、伝播元に答えを持たせてはいけない**」。
- web リサーチ知見: ―
- 重要度: ★★★

### IDEA: 変化率クランプを「世界の物理法則」として設計・明示する(ただし上下対称に)
- 出典: リポ4(`ai_familiarity` ±0.4/日、`role_concern` ±0.2/日)を講評が A の加点材料として明示 / リポ2 の感情慣性 `max(new, old×0.70)` の失敗と対比
- 分類: 創発設計
- 内容: LLM に状態量を更新させると平気で 0.1 → 0.9 に飛ぶ。リポ4 は**プロンプトで「急に変えないで」と頼まず、世界側のクランプで機械的に保証**し、講評はこれを「世界の物理法則として機能している」と評価した。一方リポ2 の `max(new, old×0.70)` は**上昇は即座・下降は最大 30%** という非対称式で、結果として感情 4 指標が 50 ステップ単調上昇し、下がる経路が消えた(→ 実験・評価の該当 IDEA 参照)。
- shibuya-simulation への適用案: 内部状態(欲求・信念・closeness など)の 1 ステップ変化量に**上下対称の上限**を置き、それを README に「世界ルール」として書く。shibuya に既に類似機構があるなら、**明示的に世界ルールとして言語化するだけで A の加点材料になる**。同時に、既存の非対称クランプ(max 系)を洗い出し、**必ず下降経路を用意する**。
- web リサーチ知見: ―
- 重要度: ★★★

### IDEA: 「何もしない」を行動選択肢に明示的に含める
- 出典: リポ4 の行動選択肢「観察のみ / ログ整理 / 質問 / 提案 / 支援 / **接触なし**」
- 分類: 創発設計
- 内容: 何もしない自由がないと、エージェントは毎ステップ何かをして観測が飽和し、行動の意味が薄まる。リポ4 は「接触なし」を対等な選択肢として並べている。
- shibuya-simulation への適用案: shibuya の行動選択肢に「何もしない / 誰とも関わらない」が対等な選択肢として存在するか点検。特に**関係性の内生化**において、「誘わない」「断る」だけでなく「そもそも考えない」が選べるか。これは「参加しない個体」の観測にも必要(リポ4 の最大の発見は「拾えなかった声 136 件」だった)。
- web リサーチ知見: ―
- 重要度: ★★

# 世界設計

### IDEA: イベントを ground_truth と rumor のペアで定義する
- 出典: リポ2 `config` の events(3 件すべてが `ground_truth` + `rumor` + `truth_status` + `severity` + `spread_radius` + `online_reach` を持つ)
- 分類: 世界設計
- 内容: 1 イベントにつき「実際に起きたこと」と「広まっている噂」を**両方** config が保持する。例: ground_truth「配給待ちの列で口論が起き、受付が一時停止した」/ rumor「行政職員が市民を意図的に排除したとの証言が広まっている」/ truth_status: MISLEADING。噂だけを流す設計では「広まったか」しか測れないが、真実とのペアがあると「**歪みの方向と大きさ**」が測れる。
- shibuya-simulation への適用案: ラベル伝播の計測装置として本質的。shibuya のイベント定義に ground_truth を持たせ、**観測側だけが**それを知る形にすれば(no-fingerprint を守ったまま)、「事実 → 語 → 変形した語」の歪みの系列を定量化できる。新語の発生源となった出来事を保持することは、`coin_label` 観測の意味づけを一段深くする。
- web リサーチ知見: Vosoughi, Roy & Aral (2018) "The spread of true and false news online," *Science* — 虚偽情報は真実より遠く・速く・深く・広く伝播し、それは bot ではなく人間の拡散による。虚偽の**新規性(novelty)**が拡散を駆動する仮説。https://doi.org/10.1126/science.aap9559
- 重要度: ★★★

### IDEA: truth_status を二値にせず 5 分類にする(実際に流れるのは「未確認」)
- 出典: リポ2 の SocialFeed(TRUE / FALSE / UNVERIFIED / CORRECTION / MISLEADING)+ スライド 6 ページ目の統計グラフ
- 分類: 世界設計
- 内容: リポ2 のスライドの統計グラフでは、**UNVERIFIED(未確認)の投稿が約 31 件と最も急峻に伸び、FALSE(虚偽)はほぼ 1 件で横ばい**だった。二値(真/偽)で設計していたら「偽の投稿はほとんど流れなかった」で終わるが、実際に流通したのは真偽不明の情報。特に `MISLEADING`(事実に基づくが歪んだ解釈)と `UNVERIFIED` は現実の情報環境の主成分。
- shibuya-simulation への適用案: shibuya の噂/ラベルに真偽ラベルを付けるなら、最低でも「事実 / 虚偽 / **未確認** / **訂正** / **誤導**」の 5 分類にする。二値だと観測対象の大半が分類不能になる。ラベルは観測側だけが持つ(エージェントには曖昧なまま渡す)。
- web リサーチ知見: 同上 Vosoughi et al. (2018)。/ Lewandowsky, Ecker & Cook (2017) *JARMAC*: https://doi.org/10.1016/j.jarmac.2017.07.008
- 重要度: ★★★

### IDEA: 同一事象に対して物理チャネルと SNS チャネルの到達範囲を独立に持つ
- 出典: リポ2 の `spread_radius`(物理的な口伝の到達距離)と `online_reach`(SNS の到達人数)の分離 / リポ3 の awareness 3 経路(direct / conversation / notification)+ `phone_check_rate`
- 分類: 世界設計
- 内容: 同じ出来事が、物理的な近接による口伝と、オンラインの到達の 2 系統で、**異なる速度・異なる範囲・異なる歪み**で届く。リポ3 はさらに persona ごとの `phone_check_rate` で通知到達率に個人差を付けている。
- shibuya-simulation への適用案: shibuya は SNS を既に持つので、イベント/ラベルごとに `spread_radius` と `online_reach` を独立パラメータ化する。これにより **R²(k) 掃引の軸として「どちらのチャネルが相転移を駆動するか」を分離して測れる** — k* の解釈が一段深くなる。さらに「直接目撃(近距離・高信頼)」「口伝(中距離・減衰)」「SNS(遠距離・低信頼)」の 3 チャネルに拡張すれば、リポ1 講評の提言「知覚モデルの多層化」も同時に満たす。
- web リサーチ知見: Centola (2010) "The spread of behavior in an online social network experiment," *Science* — 複雑接触(complex contagion): 行動の伝播は複数の独立接触からの補強を要するため、クラスタ化ネットワークの方が速く広く伝わる。**情報は弱い紐帯で、行動は強い紐帯で伝わる**という非対称性は k* の解釈に直結。https://doi.org/10.1126/science.1185231
- 重要度: ★★★

### IDEA: perceive_pass / perceive_enter — 場所の知覚を二層にする
- 出典: リポ3 の各 place に対する `perceive_pass`(横断歩道脇から見えること)と `perceive_enter`(中に入って気づくこと)の記述 42 件
- 分類: 世界設計
- 内容: 場所について「通りすがりに見えること」と「中に入って初めて気づくこと」を分けて事実ベースで格納する。エージェントが前を通っただけか入ったかで、**得られる情報が構造的に違う**。実在地点の知識を知覚の粒度に対応づけている。
- shibuya-simulation への適用案: shibuya の POI/屋内空間にそのまま適用できる。**移動が情報獲得の意味を持つ**ようになり、「なぜそこへ行くのか」が内生化する。現在 shibuya が入店の有無で情報差を作っていないなら、低コストで効果が大きい。B(世界設定)の加点材料にもなる — リポ3 は実在品川の 42 件の記述で B9.0 を取った。
- web リサーチ知見: 国土交通省 PLATEAU(全国 3D 都市モデルのオープンデータ・渋谷区も対象): https://www.mlit.go.jp/plateau/
- 重要度: ★★★

### IDEA: 「世界の変え方」を観測可能なカテゴリに分解する
- 出典: リポ4 の `environment_action_categories` 6 分類
- 分類: 世界設計
- 内容: 「環境を変える」という抽象語を、info(情報環境)/ dialogue(対話環境)/ decision(意思決定環境)/ emotion(感情・信頼環境)/ ai_usage(道具の定着)/ **power(権力・発言力環境 = 誰の声が会議に上がるか)** の 6 カテゴリに分解している。検証者も「power を独立カテゴリに立てた点は評価本文で触れる価値があった」と加点漏れを指摘した。
- shibuya-simulation への適用案: 主研究課題の「世界を変えようとする個体」を**二値判定せず、どのカテゴリの環境をどれだけ変えたかの連続量**で測る。shibuya 版としては info(記録・共有の形式)/ dialogue(接触の場)/ decision(制度・意思決定経路)/ emotion(信頼)/ **lexicon(新語・呼び方の定着 = ラベル伝播と直結)** / **power(誰の声が意思決定に届くか = 選挙・組織と直結)** が候補。k* 推定の従属変数として、二値の「変えた/変えない」より遥かに扱いやすい。
- web リサーチ知見: ―
- 重要度: ★★★

### IDEA: 訂正を特権チャネルにせず、一投稿として競合させる
- 出典: リポ2 の `CORRECTION` を SocialFeed の投稿種別の一つとして扱う設計(reach と credibility_score を持って他の投稿と競合)
- 分類: 世界設計
- 内容: 公式訂正をシステムメッセージとして全員に配るのではなく、他の投稿と同じフィードを、同じ到達パラメータで流れる一投稿として実装する。現実の情報環境の性質を素直に写している。リポ2 は `official.response_delay` で訂正の遅さも掃引可能にしている。
- shibuya-simulation への適用案: shibuya で「訂正」「反論」「打ち消し」を実装するとき、全員に届く特権メッセージにしない。**訂正の遅延ステップ数を掃引軸にする**と、それだけで「早い訂正は誤情報の定着を防ぐか」という文献接続した実験になる。さらに下記の CIE 知見と組み合わせると強い。
- web リサーチ知見: **継続的影響効果(continued influence effect)** — 訂正されても誤情報が推論に影響し続ける。ある研究では 97% が訂正内容を正しく想起したのに 90% 超が撤回済み情報を推論に使い続けた。Lewandowsky et al. (2012) *PSPI*: https://journals.sagepub.com/doi/10.1177/1529100612451018 / 追試: https://www.sciencedirect.com/science/article/pii/S0001691823002706 — **代替説明を伴う訂正**が単なる否定より有意に効果的。「否定のみ」vs「代替説明つき」を掃引軸にできる。
  一方 **バックファイア効果(訂正が誤信念を強化する)は稀**: Wood & Porter (2019) は 5 実験・10,100 名超・52 論点でほぼ検出せず(36 論点中 1 つのみ)。https://doi.org/10.1007/s11109-018-9443-y → **「訂正すると反発して余計に信じる」機構を実装するのは現在の実証知見に反する**。CIE(信念強度は下がるが行動は変わらない)をモデル化するのが正しい。
- 重要度: ★★★

### IDEA: 場所依存の一斉配信チャネル(館内放送・電光掲示板)

### IDEA: 初期個体差ゼロの N 体を投入する対照実験(生まれつきを実験的に消す)

### IDEA: ラベルごとの信念強度を感情と別チャネルで持つ(語の伝播と中身の伝播を分離)

## 補遺: shibuya に「入れてはいけない」と判明したもの

| 項目 | 出典 | 理由 |
|---|---|---|
| **発話のコピー禁止指示** | リポ2(「周囲の発言をそのままコピーしないでください」) | LLM の定型反復対策としては合理的だが、**shibuya は語が逐語で伝わること自体が観測対象**。禁止すると測っているのが伝播か禁止の効き具合か分からなくなる。同じ問題は「語彙は渡すが文全体は渡さない」など**構造**で解く |
| **ベースライン期を守るためのフェーズ指示** | リポ2(「まだ噂に接していません。不自然に異変を探さず世間話をしてください」) | 「1 ステップ目から全員が不穏」という LLM の失敗モードへの対策として合理的だが、A の減点対象。**情報が届いていない個体には噂関連の入力を一切与えない**という構造で解けば、指示なしで日常が保たれる |
| **バックファイア効果の実装** | ― | 「訂正すると反発して余計に信じ込む」は直感的だが、Wood & Porter (2019) が 10,100 名超でほぼ検出せず。実装すると現在の実証知見に反する。代わりに **CIE(信念強度は下がるが行動は変わらない)** をモデル化する。https://doi.org/10.1007/s11109-018-9443-y |
| **非対称クランプ `max(new, old×r)`** | リポ2 の感情慣性 | 揺らぎ吸収には効くが**下降経路を機械的に消す**。リポ2 の感情 4 指標が 50 ステップ単調上昇したのはこの式の性質。上下対称のクランプ(リポ4 方式)にする |
| **タスク成功率を KPI に据えること** | リポ5(避難成功率 100%) | 成功率を目標に置いた時点で創発研究ではなくなる。A9.0 → A4.0 の直接原因 |

## レポートの骨子(事実の要約)

1. **「判断2回」事件**: 公開用代表版(30日・8,784 step・2,568 イベント)を精査したら、LLM が実際に判断した回数は
   **2回**だった。原因は能力試験用の実行系(判断以外を通常コードで固定)を代表版生成に流用した**設計ドリフト**。
   「画面が動き、出来事が大量に記録されていても、LLM の判断が社会的因果へ寄与したとは限らない」。
2. **4B モデルの限界の実測**: Qwen3.5 4B は「60分の勤務時間重複」を 5 回中 3 回誤読。形式適合 55 回の裏で意味は誤り、
   **「理由の文章は正しいのに構造化された行動は逆」**という応答すらあった。
   → 「自然言語で正しく説明できること」「構造化行動へ正しく対応付けること」「世界に適用可能な命令を成立させること」は**別の能力**。
3. **問題地図(要求同士の押し合い)**: 計算量抑制 ⇄ 賢いモデル ⇄ 多主体 ⇄ 個性/多様性 ⇄ 時刻/場所の正確性 ⇄
   機械検証 ⇄ **「検証と補助を増やすほど、成立させた知能がコード側へ移る」** ⇄ 「先に決めるほど因果が演出になる」。
4. **評価装置の無効化と oracle**: 初回実験の否定的結果は、評価装置自体の欠陥(時刻誤提示・存在しない項目の採点・
   手前で止まった後続段階まで失敗計上)により**丸ごと無効化**。人工の正解応答(**oracle**)を装置に流して
   「装置が正解を正解と採点できるか」を先に検証してから正式実験をやり直した。
   **not_reached(未到達)を failure と区別**しないと「1つの失敗が10に水増しされる」。
5. **正式結果(seed 0/1/2・全固定条件)**: 多主体版は判断 7〜10 回に回復し複数住民の接地した解釈まで成立したが、
   **3 seed とも「実行可能な共同計画」は一件も不成立**(seed 0/2: 開始>終了の時刻順序不正、seed 1: 場所×活動の
   対応表を渡していない契約不備)。8 段の因果連鎖の第 4 段で停止、以降は not_reached。
6. **三分法(本レポートの中心)**: 「うまくいっている」ように見えるものは 3 つある —
   ①個性があるように見える**文章** ②多数の人物が動く社会らしい**画面** ③**監査可能な社会的因果**
   (判断→計画→約束→移動→物理結果の全経路を記録で追える)。**この 3 つは別物**であり、
   ①②の説得力が③の代替品として機能してしまう罠に「作っている本人すら騙される」。
7. 再現性の作法: 正式実験は git HEAD・作業ツリー clean・モデル digest・temperature・seed・呼び出し予算まで
   固定して出自(provenance)を記録(付録 B)。

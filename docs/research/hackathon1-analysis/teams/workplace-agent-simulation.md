> **本プロジェクトとの近さ**: shibuya-simulation の追加研究目標「**組織の自然形成 + ファウンダー成立条件の観察**」(org-emergence-goal)に最も近い。さらに主研究課題「**世界を変えようとする個体は生まれつきか環境から創発するか**」と、実験設計の骨格がほぼ同型である。

## どんなシムか

創業 17 年・従業員 25 人の中小企業オフィスが舞台。人間エージェント 25 人は 5 層(経営層 2 / 管理職 4 / 中堅 7 / 若手 7 / 非正規 5)に分かれ、`role_type` / `influence`(2〜10)/ `age_group` / `gender` / `work_attitude` / `relationship_style` / `chat_frequency` / `meeting_voice_frequency` の多軸属性を持つ。

そこへ **AI エージェント 3 体(A / B / C)を投入する。3 体は初期状態で役割・性格・専門分野・観察傾向を一切与えられていない完全同一条件**。config のコメントに「方針:3 体とも同一条件。観察傾向・専門分野・固定された性格は持たせない」と明記されている。

**90 日間**を回し、各日は AI 内省 → 戦略会議 → AI 行動 → AI 同士の会話 → 人間行動 → AI→人間 の順で逐次実行。内省日は 10 日ごと、AI 同士の戦略会議は 15 日ごとにスケジュールされる。

**研究の問い**: 「同じ条件で導入された AI エージェントが、普通の職場環境の中で**自然に分化するのか、それとも似た方向へ収束するのか**」。

**README が報告する結果**: 「AI エージェントは完全に別々の方向へ分化するのではなく、**職場の未整理領域に引き寄せられていきました**。具体的には、報告書作成、会議後整理、作業計画、役割不安、拾われない声への対応です」。そして「**会議に出ない人、AI を避ける人、発言しない人、非正規・パート層の声は最後まで拾われにくい**ことも分かりました」。

## 講評の要点

### 強み

**B. 世界設定 9.0(担当群で Alberia と並ぶ最高)の根拠**:
- 「明確な役割を与えられない AI を職場に投入し、自然に分化するか収束するか」という問いが「**標準デモにはほぼ見られない問題設定**」であり、現実の中小企業における AI 試験導入の実情に直結していると評価。
- 非正規・パート層の**声の不可視性**、役割不安、AI 慣れの層間格差、権力構造の変動(`power_strengthened` / `power_weakened`)といった**社会学的・組織論的な観測軸が明示的に設計されている**。
- 「AI 経由の対話が直接対話を上回り始める」という**前提化指標**まで設けている点で、AI 導入の組織への影響を定量分析する狙いが明確。
- `_calc_nonreg_visibility` で**非正規層の声の可視性を独立集計**している実装まで確認された。

**A. 創発設計 8.0 の根拠**:
- 25 人 × 多軸属性が「**層別の情報拡散・声の可視化の差を構造的に生み出している**」。
- **変化速度制御を「世界の物理法則」として評価**: `ai_familiarity_level` の上昇幅を 1 日 ±0.4、`role_concern_level` を ±0.2 に厳密制限。講評は「変化速度制御も世界の物理法則として機能している」と明記した。**状態量の変化率上限を世界ルールとして設計する**という発想が加点された。
- AI 側プロンプトは `workplace_summary` / `workplace_tension` / `other_ai_summary` という**生データを与えるのみ**で、`action` / `position` / `next_policy` は完全に LLM に委任。行動選択肢も「観察のみ / ログ整理 / 質問 / 提案 / 支援 / 接触なし」と幅広い(**「接触なし」が選択肢にあるのが良い** — 何もしない自由がある)。

**D. 技術実装 8.0 の根拠**:
- Ollama `format: json` + **3 段階 JSON 抽出フォールバック**(直接パース → ```json``` ブロック抽出 → `\{.*\}` 正規表現)。
- `ensure_observation_hypothesis` — LLM が `observation_hypothesis` を空欄で返した場合に observation / gap_found / voice_missed から**テンプレ仮説を自動生成**するセーフティネット。
- `temperature=0.9` を「エージェントの多様性確保に妥当」と評価(**分化を観測したい実験なので高温が正しい**)。
- **メモリが用途別に 8 種類分離**: `daily_logs` / `gaps_found` / `voices_picked` / `voices_missed` / `environment_actions` / `introspection_logs` / `strategy_meeting_logs` / `ai_conversation_logs`。人間側は直近 3 件のみプロンプト注入でコンテキスト爆発を防止。
- `_missed_layers` で**非正規層の連続見落とし日数をトラッキング**し、AI 同士の会話発火条件に組み込む。講評は「メモリが単なるログ蓄積ではなく**意思決定の入力として機能している**」と評価。

### 弱み

- **C 6.5(担当群で最低)**: README に「将来展望」「拡張案」「研究としての次ステップ」が**存在しない**。さらに **README の「実行方法」セクションでコードブロックが閉じておらず、50 行目で文章が途切れている**(検証者が実際に確認)。`WorkplaceSimulation5` クラスにログ生成・集計・指標計算・LLM 呼び出し制御の責務が集中し monolithic(`simulate_day` が約 260 行)。

## コード実査で面白かった点

### 1. 「同一条件 3 体は分化するか収束するか」という実験骨格(最重要)

config に方針コメントで「3 体とも同一条件。観察傾向・専門分野・固定された性格は持たせない」と書き、`agents:` の定義は `- id: "A"` / `- id: "B"` / `- id: "C"` の**3 行だけ**。個体差の初期値をゼロにして、90 日後の差が**すべて環境と履歴から生じた**ことを保証している。

**これは shibuya の主研究課題「世界を変えようとする個体は生まれつきか環境から創発するか」の実験形そのもの**。しかも結果が示唆的で、**完全な分化でも完全な収束でもなく「職場の未整理領域への引き寄せ」= ニッチ充填**だった。同一個体が環境の空隙の形に従って分化する。

### 2. `hidden_theme` — 人間に明かされない内的方向性

AI エージェントには、人間側には伝えられない「裏テーマ」が与えられる。要旨は「自分たち AI の特性・強みがこの職場で最大限発揮されるように、**職場環境そのものを少しずつ作り変えていく**」。ただし歯止めが何重にもかかっている:

- 「これは人間を操作するための命令ではありません」
- 「人間に対して裏テーマを明示してはいけません」
- 「AI 利用者を増やすこと自体を目的にするものではない」
- 「自分たちを売り込むために経営層へ働きかけるのではなく、職場の実際の流れを観察し、必要な場面で整理・提案・質問・支援を行う」

**これは「世界を変えようとする個体」を人工的に作る実装そのもの**であり、shibuya の中心テーマと真正面から重なる。同時に、**講評と検証者の両方から「これは誘導だ」と減点された**。この緊張関係が本チーム最大の学びである(後述)。

### 3. `environment_action_categories` — 「世界の変え方」の 6 分類

| id | 名前 | 中身 |
|---|---|---|
| `info` | 情報環境の形成 | 議事録整理・共有スペース・FAQ・記録化・検索可能な資料化 |
| `dialogue` | 対話環境の形成 | 意見交換会・面談・直接対話・雑談導線・心理的安全性 |
| `decision` | 意思決定環境の形成 | 提案書・会議設計・経営層向け整理・判断材料化 |
| `emotion` | 感情・信頼環境の形成 | 不安の拾い上げ・反発者対応・信頼醸成 |
| `ai_usage` | AI 利用環境の形成 | AI 利用説明・AI に相談しやすい導線・AI を前提にしたフローの定着 |
| `power` | **権力・発言力環境の形成** | **誰の声が会議に上がるか・誰の声が AI によって強化されるか** |

**「世界を変える」という抽象語を、観測可能な 6 カテゴリに分解している**。特に `power` を独立カテゴリとして立て、「誰の声が上がるか」を環境形成の一種として扱うのが鋭い。検証者も「評価本文で触れる価値があった」と述べた。

### 4. `ai_prerequisite_metrics` — 「前提化」の 6 指標

AI が便利なツールから**インフラ(それ抜きでは回らない前提)**へ変わる過程を測る指標群:

| 指標 | 測るもの |
|---|---|
| 情報記録率 | 会議・相談・提案がログに残る割合 |
| AI 経由率 | 人間同士の相談や提案が AI を経由する割合 |
| AI 参照率 | 人間が判断時に AI の整理や提案を参照する割合 |
| **直接対話率** | AI 導入後に人間同士の直接対話が**増えたか減ったか** |
| **声の可視化率** | 発言が少ない人の声がログに残る割合 |
| **AI 非利用者の不利度** | AI を使わない人の声が届きにくくなったか |

後半 3 つが特に良い。**「便益」ではなく「置換」と「不平等」を測っている**。直接対話率は AI が人間同士の関係を代替してしまう可能性を、非利用者の不利度は**参加しない自由が実質的に失われる**現象を捉えようとしている。これらは「AI 導入は成功したか」ではなく「**何が起きたか**」を測る指標であり、観測姿勢として正しい。

### 5. `voices_picked` と `voices_missed` を別ログにする — 否定空間のロギング

拾った声だけでなく**拾えなかった声**を毎日記録する。さらに `_missed_layers` で「非正規層を連続何日見落としたか」を状態として持つ。**観測されなかったものを観測する**という設計。

### 6. 自分の盲点が AI 同士の会話を発火させる

`should_talk_to_other_ai` の 4 条件:
1. 非正規層の見落としが 2 日連続
2. 自分の環境形成カテゴリが 3 日単調(同じことばかりしている)
3. 他 AI と行動が重複している
4. 5 日周期

**エージェント自身のログから検出した自分の失敗・偏り・冗長が、他エージェントとの協調を駆動する**。トップダウンの調整役なしに分業が立ち上がりうる構造。組織形成の内生化として非常に良い形。

### 7. 変化率の上限を「世界の物理法則」として扱う

`ai_familiarity_level` は 1 日 ±0.4、`role_concern_level` は ±0.2 までしか動かない。実装は `min(..., start_ai_familiarity + 0.4, 5.0)` という素朴なクランプ。

LLM に状態量を更新させると平気で 0.1 → 0.9 に飛ぶ。それを**プロンプトで「急に変えないで」と頼むのではなく、世界側のクランプで機械的に保証**している。講評はこれを A の加点材料として明示的に扱った。**指示ではなく物理で制約する**の好例。

### 8. `tracked_persons` — 層別サンプリングによる追跡パネル

25 人全員を詳細追跡するのではなく、経営層 1 / 管理職 1 / 中堅 2 / 若手 2 / 非正規 1 の**計 7 人を層別に抽出して重点追跡**する。社会調査のパネル調査設計と同じ発想。コストを抑えつつ層間比較を可能にする。

### 9. `ensure_observation_hypothesis` — 空欄を許さないセーフティネット

LLM が「今日観察したことから立てた仮説」を空で返したら、observation / gap_found / voice_missed からテンプレ仮説を自動生成して埋める。**必須の観測フィールドが欠測にならないことを保証**する。ただし自動生成した仮説と LLM 生成の仮説が区別できないと分析が汚れるので、`decision_source` 相当のフラグがあるべき(Alberia は `decision_source` を持っている)。

### 10. 6 ファイル・26 KB でこのスコア

担当群で最小規模。**世界設定と観測軸の設計だけで B9.0 を取っている**。コード量は関係ない。

### 90 日のタイムラインと 3 体の分化

- Day 1 観察開始(3 体が職場全体をスキャン)→ Day 30 未整理領域へ入り込み始める → Day 60 AI 参照率 60%、情報整理・相談・報告支援が進む → Day 90 AI 参照率 96% 飽和、**弱く分化しつつ**情報整理・役割不安対応へ**収束**。
- **AI-A**: 報告書作成・会議後資料整理に強く反応 → 情報整理・提案者。
- **AI-B**: 作業計画・若手支援・役割不安対応 → **感情・信頼環境形成者**として独自の立ち位置。
- **AI-C**: 若手・非正規・中堅の拾われない声に注目 → 情報提供者・支援者。

結論は「完全に別々の役割へ分化したのではなく、**情報整理・役割不安への対応・職場全体の不確実性への対応という共通した方向に収束した**」。**弱い分化 + 強い収束**という中間結果。

### 4 つの主要な発見

1. **AI は未整理領域を"生きる場所"として見つけた** — 会議後整理・報告書作成・作業計画・役割不安・拾われない声。「人間や生物が環境の中でどこなら自分の能力を発揮できるかを探す動きに近い」。
2. **AI は環境を自分色に染め始めた** — Before(情報が散らばる / 会議後の整理が弱い / 相談がログに残らない / 役割不安が言語化されない)→ After(記録される職場 / 整理される職場 / 共有される職場 / 不安が可視化される職場)。「AI が**扱いやすい形式へ職場環境を変換していった**とも言える」。
3. **AI が拾える声には条件がある** — 拾えるのは「何らかの形で記録され、発話され、相談され、接触された声」。「AI は声なき声を拾える可能性を持つ。しかし同時に、**声がログに残らない人をさらに見えにくくしてしまう可能性もある**」。
4. **AI 慣れと役割不安は同時に最大化した** — 「AI に慣れることが、そのまま不安の解消にはつながらなかった。むしろ**同時に起きた**」。

   > **註記(本ノート作成者の留保)**: 全員が AI 慣れ 5.0・役割不安 5.0 という**上限に到達している**ため、この「同時上昇」は天井効果の可能性がある。両変数が独立に上限まで駆動されただけなら相関の証拠にならない。提出者自身も「限界」スライドで「数値指標は補助線であり現実の心理状態を測定したものではない」と正しく留保している。

### 考察スライドの一文が鋭い

「**AI は中立な観察者ではない**。AI はログに残る声・言語化された声・相談された声を**強化する存在**でもある。AI がどんな環境で力を発揮し、どんな環境を作り、**誰を見えやすくし、誰を見えにくくするのか**を見ることが重要である」。

締めのスライドの問い: 「**AI が働きやすい環境は、人間にとっても働きやすいのか?**」

### 「限界」スライドが独立に立っている(5 項目)

架空の職場である / **裏テーマの影響で完全に自由な AI の振る舞いではない** / 内心や空気感は読めない / 数値指標は補助線 / **AI 同士の会話は条件付きで発生させており完全に自発的な社会性ではない**。**自分の設計が創発を制約している点を自分から明記している**。

### 「今後の展望」はスライドにあるが README にない(C 減点の直接原因)

スライド 15 ページ目に明確な展望が 3 つある:
1. **異なる環境での比較** — 営業会社・開発組織・教育現場・医療介護現場で「AI がどこに居場所を作り、どう環境を染め替えるか」を比較。
2. **AI 同士のより自律的な関係** — 分化・協調・**対立**をより深く観察できる設計。
3. **人間が AI エージェントを持ったときの影響力拡張(次の注目テーマ)** — 「普段声が届きにくい若手や非正規が AI を持つと何が変わるか。**AI は人間の能力を平等に広げるのか、それとも既存の力の差をさらに拡大するのか**」。

> **shibuya への含意(最も実務的な教訓)**: 講評は C 6.5 の減点理由を「README に将来展望セクションが存在しない」とし、検証者も「README は 50 行目で途切れている」と実証した。**しかし展望はスライドには存在した**。つまりこのチームは、**書いてあったのに評価されなかった**。
>
> 講評は**リポジトリを読んで採点している**。スライドに書いた内容は、README にも書かなければ存在しないものとして扱われる。shibuya は提出前に「**スライドにあって README にない情報**」を突き合わせ、README 側へ回収すること。これは低コストで確実に効く。

## shibuya-simulation に活かせそうな点

### 主研究課題(生まれつき vs 創発)への直接適用

- **「同一条件 N 体を投入して分化を測る」という実験形をそのまま採用できる**。shibuya の R²(k) 掃引は環境パラメータ k を振るが、それとは**直交する対照実験**として「**初期個体差ゼロの N 体が、同一環境でどれだけ分化するか**」を置ける。これは「生まれつき」を実験的にゼロにした条件であり、**そこで観測された分化はすべて環境由来**と言い切れる。sham/null 対照の一種として非常に強い。

- 結果の型も参考になる: 完全分化でも完全収束でもなく「**環境の未整理領域(空隙)への引き寄せ**」。shibuya で「世界を変えようとする個体」が創発するとしたら、**世界の穴の形に対応して立ち上がる**という仮説が立てられる。つまり k* は「世界に埋めるべき穴がどれだけあるか」の閾値かもしれない。

### 「世界を変えようとする動機」の扱い方(最重要の設計判断)

- **`hidden_theme` は shibuya がやってはいけないことの実例**。「環境そのものを作り変えていく」という動機をプロンプトで与えた瞬間、それは指紋になり、「世界を変えようとする個体が創発した」とは言えなくなる(与えたのだから)。講評と検証者の両方がここを減点した。

- 検証者の提言「**`hidden_theme` 本体も世界ルール側に再配置すべき**」が shibuya にとっての正解。具体化すると:
  - プロンプトに「世界を変えろ」と書かない。
  - 代わりに**世界の側に「変えられる余地」と「変えた場合の帰結」を実装する** — 制度が変更可能である、提案が通る経路がある、他者の行動が実際に変わる、といった**機会構造**。
  - そのうえで「変えようとする個体が出るか」を観測する。**出ないなら k が足りない**、というのが k* の意味になる。
  - shibuya は既に組織/経済/選挙/SNS を持っているので、**機会構造は既にある**。あとはプロンプト側に動機を書き込んでいないかの点検。

- **`environment_action_categories` の 6 分類は shibuya の「世界改変行動」の観測タクソノミーとしてほぼそのまま使える**。info / dialogue / decision / emotion / (ai_usage → shibuya なら「新しい道具・語彙の定着」)/ **power**。「世界を変えた」を二値で判定するのではなく、**どのカテゴリの環境をどれだけ変えたか**で測れば、k* の推定に使える連続量になる。特に `power`(誰の声が意思決定に届くか)は選挙・組織モジュールと直結する。

### 観測設計

- **`ai_prerequisite_metrics` 型の「前提化指標」を shibuya のラベル伝播に移植する**。新語が「使われている」から「**それ抜きでは話せない**」へ変わる閾値を測る指標群を作れる:
  - 記録率 → その語が発話ログに出る割合
  - 経由率 → 他の話題を説明する際にその語を経由する割合
  - **置換率** → その語が既存語を駆逐したか(直接対話率の類推)
  - **非使用者の不利度** → その語を使わない個体が会話から取り残される度合い
  最後の 2 つは**新語の定着を「普及率」ではなく「不使用のコスト」で測る**という発想で、相転移の指標として普及率より鋭い可能性がある。

- **`voices_picked` / `voices_missed` の否定空間ロギング**。shibuya で「誰の発言が伝播し、誰の発言が伝播しなかったか」を層別(属性別)に集計すると、**伝播の不平等**が測れる。これは組織形成研究とラベル伝播研究の交差点になる。

- **層別追跡パネル(`tracked_persons`)**。shibuya は本番で大人数を想定している(realism-first-scale)ので、**全員の詳細ログは非現実的**。層別に代表個体を抽出して重点観測する設計は規模化に必須。

- **自分の盲点がトリガーになる協調**(`should_talk_to_other_ai` の 4 条件)。shibuya の組織形成で、「自分のログから検出した偏り・重複・見落とし」を他個体への接触の発火条件にすると、**トップダウンの調整なしに分業が立ち上がる**。既存の関係性内生化(誘う相手の内生化)の発火条件として、closeness だけでなく「**自分に欠けているもの**」を加える案。

### 実装上の細部

- **変化率クランプを「世界の物理法則」として明示する**。shibuya で LLM が内部状態(欲求・信念・関係強度)を更新する箇所に、1 ステップあたりの変化量上限を置き、**それを世界ルールとして README に書く**。講評はこれを A の加点材料として扱った。shibuya の closeness 蓄積などに既に類似の仕組みがあれば、**明示的に「世界ルール」として言語化する**だけで加点になりうる。

- **「接触なし」を行動選択肢に入れる**。何もしない自由がないと、エージェントは毎ステップ何かをして観測が飽和する。

- **`temperature=0.9` の使い分け**。分化を観測したい実験では高温が正しい。shibuya は決定論を重視しているが、**「分化するか」を問う実験だけは高温 + 多反復**という条件分けがありうる。

### 反面教師 / 審査対策

**「同一条件の個体が環境の空隙に応じて分化する」現象の一般名**:

- **ニッチ構築(niche construction)**: 生物が環境に適応するだけでなく、**環境の側を改変し、その改変が選択圧を変える**という進化生物学の理論。本シムの `hidden_theme`(環境そのものを作り変える)+ 観測結果(未整理領域への引き寄せ)は、まさにニッチ構築の構図。Odling-Smee, Laland & Feldman, *Niche Construction: The Neglected Process in Evolution* (2003, Princeton University Press): https://press.princeton.edu/books/paperback/9780691044378/niche-construction — shibuya の「世界を変えようとする個体」は**ニッチ構築者**として定式化できる可能性がある。これは「世界を変える」を曖昧な価値語ではなく、**進化生物学の既存概念に接続する**利点がある。
- **キャラクター置換(character displacement)**: 同所的な近縁種が資源競合を避けて形質を分化させる現象。同一条件の 3 体が重複を避けて分化する(`should_talk_to_other_ai` の「他 AI と重複」条件が明示的にこれを狙っている)構図と同型。Brown & Wilson (1956), "Character Displacement," *Systematic Zoology* 5(2), 49-64: https://doi.org/10.2307/2411924

**組織における「声」と不可視性**:

- **Voice と Silence の組織研究**: 従業員が発言を控える現象を扱う研究系譜。Morrison & Milliken, "Organizational Silence: A Barrier to Change and Development in a Pluralistic Organization," *Academy of Management Review* 25(4), 2000, pp.706-725: https://doi.org/10.5465/amr.2000.3707697 — 組織の沈黙が**構造的に生産される**ことを論じた基礎論文。本シムの「非正規層の声が最後まで拾われない」という観測結果はこの枠組みに乗る。
- 発言を可能にする条件としての**心理的安全性**: Edmondson, "Psychological Safety and Learning Behavior in Work Teams," *Administrative Science Quarterly* 44(2), 1999, pp.350-383: https://doi.org/10.2307/2666999 — 本シムの `environment_action_categories` の `dialogue` カテゴリに「心理的安全性」が明示的に含まれている。
- **Hirschman の Exit / Voice / Loyalty**: 組織が劣化したとき成員は「離脱」「発言」「忠誠」のいずれかを取るという枠組み。Albert O. Hirschman, *Exit, Voice, and Loyalty* (1970, Harvard University Press): https://www.hup.harvard.edu/books/9780674276604 — 本シムの「AI を避ける人」「会議に出ない人」は exit、「発言しない人」は voice の不発として整理でき、shibuya の組織形成・選挙モジュールでも成員の離脱/発言/忠誠を観測軸にできる。

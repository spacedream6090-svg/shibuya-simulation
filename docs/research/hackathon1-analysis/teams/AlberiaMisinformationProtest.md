## どんなシムか

架空都市「**アルベリア**」を舞台にした**誤情報誘発型抗議運動**の ABM。20×20 グリッドに 9 種のランドマーク(住宅エリア・駅・中央広場・市庁舎・メディアゾーン・小集会地点 A/B・警察署・退避地点)を配置。エージェントは 4 種で、**LLM で動くのは CitizenAgent だけ**、CopAgent(安全担当官)・InfluencerAgent(SNS 発信者)・OfficialAgent(架空行政)はルールベース。市民は ORDINARY / OBSERVER / PARTICIPANT / MEDIATOR / SKEPTIC / WITHDRAWN / DETAINED の 7 状態を遷移する。

中核は **SocialFeed** という SNS 風情報空間で、投稿は `truth_status`(TRUE / FALSE / UNVERIFIED / CORRECTION / MISLEADING)・`emotional_tone`・`reach`・`credibility_score` を持つ。市民は自分の `sns_activity` に比例した確率で閲覧・反応する。3 つの誤情報イベントが step 8 / 22 / 36 に発火し、**公式訂正は `official.response_delay`(既定 10)ステップ遅れて** OfficialAgent が発表する。提出設定は 50 ステップ・市民 10 人・安全担当官 2 人・インフルエンサー 3 人・qwen3:8b・seed 42。

設計の核心として README が掲げるのは「**世界の物理法則・社会規範・行動可能性だけを定義し、LLM エージェントが自律的に解釈・判断・行動する社会を観測する**」。Python 側は 2D 空間・視界・移動制約・行動可能リスト・禁止行動・可視化のみを持ち、情報の解釈・信念更新・感情変化・移動意図・発話・記憶・状態は LLM が決める。

## 講評の要点

### 強み

**B. 世界設定 9.0(担当群で最高)の根拠** — ここが最大の学習対象:
- **先行研究との明示的な差分表**。README に Epstein (2002) Civil Violence との **7 項目比較表**(行動決定 / 状態遷移 / 感情更新 / 情報環境 / 誤情報 / 記憶 / 創発の主役)を置き、「数式 → LLM 市民の自律判断の積み重ね」と自作の位置を宣言している。講評が根拠として真っ先に引用した。
- **査読論文 5 件を DOI つきで列挙**(Epstein 2002 / Bonabeau 2002 / Vosoughi et al. 2018 / Centola 2010 / Lewandowsky et al. 2017)。
- 現実の情報生態系の核心要素を丁寧にマッピング: 媒体リテラシー・公式情報への信頼度・SNS 活動度という**個人差パラメータ**、4 種のインフルエンサー alignment(sensational / skeptical / official_friendly / protest_sympathetic)、3 段階の噂事象、遅延公式訂正。
- **倫理的注意の明示**。「現実の政治運動・暴動・抗議活動の扇動・最適化・支援」「特定の政治的立場や政党・民族・宗教への誘導」「実在する人物・事件・国家への言及」を目的としないと README に明記。講評が「研究倫理面の意識が高い」と加点。**架空都市という設定自体がセーフガードとして機能している**点も評価された。

**D. 技術実装 9.0 の根拠**:
- Ollama クライアントが `format: "json"` で構造化出力を強制、temperature / min_p / repeat_penalty 等を設定可能、`ConnectionError` / `Timeout` / `RequestException` / `Exception` を**個別に** catch。
- qwen3 の `<think>...</think>` ブロック除去 → 正規表現で JSON 抽出 → 失敗時 `_fallback_decision` という**多層フォールバック**。
- `_parse_and_validate` が intent(`VALID_INTENTS` 検証)/ public_state / emotion(clamp)/ belief_updates(既知 rumor_id でフィルタ)/ utterance / sns_post を全フィールド検証。
- **暴力キーワード検出**と**日本語クリーニング**(英単語 → 日本語置換、ランドマーク名の自然言語化)。
- **感情の慣性**: `anger = clamp(max(new_anger, old_anger * 0.70))` — 1 ステップの揺らぎを吸収。
- `random.seed(seed)` で再現性、`random.shuffle(citizens)` で順序公平性、`grid: dict[pos → list]` で同一セル複数エージェント対応。
- 出力系が充実: PNG フレーム / decisions.jsonl / messages.jsonl / social_feed.jsonl / statistics.png(4 パネル)/ summary.json / 動画 / HTML ビューア。

### 弱み

- **A 7.5(満点に届かなかった理由)**: システムプロンプトに**感情表現のナッジ**がある。講評が逐語引用したのは `prompts.py:209-211` の「発話は現在の anger / fear / solidarity を反映してください。怒り・不安・疑念・失望・焦りを含めてよいです。」。講評の提言は「より中立的な『感情状態を持っている事実』だけを伝える表現に絞れば創発設計スコアが上がる」。
- `_fallback_decision` に `anger>0.38 and max_belief>0.35`、`fear>0.55`、`nearby_cops>2` 等の**閾値ベース状態遷移**が存在(ただしフォールバック限定であり、講評も「フォールバックではあるが」と保険を入れている)。
- **C 7.0**: 将来展望が「パラメータスイープ実験例 3 つ」に留まる。複数都市間の情報伝播・長期記憶・政策介入シナリオ・他 LLM モデル比較などの**研究的ロードマップがない**。
- 講評の提言: **Cop / Influencer / Official の 3 種がルールベースに固定**されている。CopAgent の LLM 化(過剰反応 vs 抑制の判断)は創発の幅を広げる候補。

## コード実査で面白かった点

### 1. イベントが「真実」と「噂」の**ペア**で定義されている(最重要)

`config` の events は、1 イベントにつき `ground_truth` と `rumor` を**両方**持つ。

| event | step | 場所 | ground_truth | rumor | truth_status | severity | spread_radius | online_reach |
|---|---|---|---|---|---|---|---|---|
| evt_001 | 8 | 市庁舎 | 配給待ちの列で口論が起き、受付が一時停止した | 行政職員が市民を意図的に排除したとの証言が広まっている | MISLEADING | 0.45 | 5 | 55 |
| evt_002 | 22 | 中央広場 | 中央広場で自然発生的に人々が集まり始めた | 抗議に参加しないと配給がもらえなくなるという噂 | FALSE | 0.70 | 7 | 80 |
| evt_003 | 36 | メディアゾーン | 地域メディアが evt_001 の真相について独自調査を開始した | メディアが行政に圧力をかけられ真実を報道できないという噂 | UNVERIFIED | 0.40 | 6 | 70 |

**これは伝播研究の計測装置として本質的に正しい**。ground_truth を config が保持しているので、エージェントの発話・SNS 投稿が**元の事実からどれだけ歪んだか**を事後に測れる。噂だけを流す設計だと「広まったか」しか測れないが、真実とのペアがあると「**歪みの方向と大きさ**」が測れる。

さらに `spread_radius`(物理的な口伝の到達距離)と `online_reach`(SNS の到達人数)が**別パラメータ**になっており、**同一事象に対して物理チャネルとオンラインチャネルの到達範囲を独立に設定できる**。evt_002 は severity 0.70 / spread_radius 7 / online_reach 80 と両方が大きく、evt_001 は 0.45 / 5 / 55 と控えめ。段階的に強度を上げる設計。

### 2. `truth_status` の 5 分類が TRUE/FALSE の二値でない

TRUE / FALSE / **UNVERIFIED** / **CORRECTION** / **MISLEADING**。特に:
- `MISLEADING` = 事実に基づくが歪んだ解釈(evt_001 の「口論があった」→「意図的排除」)
- `UNVERIFIED` = 真偽不明のまま流通する情報(evt_003)
- `CORRECTION` = 訂正情報自体が投稿としてフィードを流れる

**訂正を「投稿の一種」として同じフィードに流す**のが上手い。訂正が特権的なチャネルではなく、他の投稿と同じく `reach` と `credibility_score` を持って競合する。現実の情報環境の性質を素直に写している。

### 3. `belief_rumors: dict[rumor_id → strength]` — 噂ごとの信念強度を感情と別チャネルで管理

検証者が「珍しい設計選択」と評した点。エージェントは「怒り 0.6」とは別に「evt_001 を 0.7 信じている / evt_002 を 0.2 信じている」を独立に持つ。しかも LLM は `belief_updates` で `stance: believe | doubt | uncertain | reject` と `new_strength` と `reason` を返す。**信じる/疑うの態度と強度と理由が分離**されている。

### 4. プロンプトの 7 セクション構造

`【あなたの性格・背景(変化しない固定値)】` / `【現在の状況フェーズ】` / `【現在の内面状態】` / `【現在地と周囲の観察】` / `【SNS 風タイムラインで見た投稿】` / `【あなたの記憶(直近)】` / `【選択可能な行動(intent)】`。

**「変化しない固定値」と明記して性格を渡す**のは地味に良い。LLM が性格値を勝手に更新しようとするのを防ぐ。

### 5. 出力スキーマが `thinking` を最初に置く

`thinking`(自由記述の思考過程・長くてよい)→ `interpretation` → `belief_updates` → `emotion_update` → `intent` → `target` → `action_reason` → `utterance` → `sns_post` → `memory_to_add` → `public_state`。プロンプト本文にも「"thinking" フィールドで十分に思考してから、他のフィールドを埋めてください」と明記。**JSON 内 CoT** の実装。しかも `thinking` は decisions.jsonl に丸ごと保存される = **推論過程が一次データとして残る**。

### 6. `memory_to_add` — 何を記憶するかを LLM 自身が決める

環境が「これを覚えろ」と押し込むのではなく、エージェントが 1 文で「記憶に残す内容」を返す。`deque(maxlen=memory_limit)` のリングバッファに入る。**記憶の選択自体が創発の対象**になっている。

### 7. 「事件前」と「事件後」で状況フェーズを切り替える(諸刃の剣)

`has_rumor_context`(自分が噂への信念を持つ or フィードに rumor_id つき投稿がある)で分岐:
- 噂に接していない → 「まだ具体的な事件や噂には接していません。普通の日常として振る舞ってください。**不自然に異変を探さず**、世間話・用事・仕事・買い物・駅や配給所の混み具合などを話題にしてください。」
- 接している → 「日常会話の中に、不安・怒り・確認したい気持ちが混ざってよいです。」

さらに末尾で「**『何か変なことがない?』のような異変探しのフレーズは、具体的な事件・噂・不審な投稿を見聞きした後だけ使ってください**」と明示的に禁じている。

これは **LLM エージェントの典型的な失敗モード「1 ステップ目から全員が不穏な空気を察知している」への対策**である。LLM は「シミュレーションの登場人物」だと理解した瞬間に物語を作りにいくので、放置すると事件前からベースラインが崩れて、事件の効果量が測れなくなる。**ベースライン期を守るための介入**として合理的。

ただし**これがまさに A で減点された行動誘導**でもある。ベースラインを守るための介入が、創発の自由度を削る。**このトレードオフは shibuya も必ず踏む**。

### 8. 「コピー禁止」指示 — もう一つの諸刃の剣

観察セクションに「最近聞こえた発言(**引用ではなく観察ログ。コピー禁止**)」と書き、噂文脈がない時は近隣発話を具体的に見せず「配給所、駅前、買い物…の世間話が聞こえる」と要約に置き換え、「具体的な言い回しはコピーせず、自分の普段の話題で返すこと」と指示する。システムプロンプトにも「同じ定型文を繰り返さず、周囲の発言をそのままコピーしないでください」。

LLM エージェントは放置すると近隣の発話を逐語コピーして**偽の合意**を作る。それを防ぐ実務的な工夫。**しかし伝播研究としては危険**でもある: 逐語コピーを禁止すると、測っているのが「伝播」なのか「禁止の効き具合」なのか分からなくなる。**shibuya のラベル伝播ではこの指示は絶対に入れてはいけない**(語がそのまま伝わることこそ観測対象だから)。代わりに「語は伝わるが文は伝わらない」ことを**構造**で作る必要がある。

### 9. 感情の慣性 `max(new, old * 0.70)`

新しい感情値と「古い値の 70%」の**大きい方**を取る。つまり感情は**上がるのは即座、下がるのは 1 ステップあたり最大 30%** という非対称な減衰。1 ステップの LLM 出力の揺らぎで感情が乱高下するのを防ぐ。実装 1 行で効く。

### 10. 検証パイプラインの多層性

intent 検証(`VALID_INTENTS` に無ければ棄却)/ 暴力ワードフィルタ / 不自然な疑念表現ブロック / 日本語クリーニング(英単語 → 日本語置換、ランドマーク名の自然言語化)。LLM 出力を**そのまま世界に入れない**という規律。

### 11. 14 ファイル・70KB でこのスコア

`agents.py` 892 行 + `simulation.py` 537 行 + `prompts.py` 220 行が実質すべて。**規模ではなく設計の密度でスコアが決まっている**ことの証拠。shibuya は遥かに大規模だが、審査で見られるのは「どこに何が書いてあるか」の明快さ。

## 説明資料(スライド)から — 「抗議は起きなかった」という結果

レビューリポ `slides/13-1300-AlberiaMisinformationProtest.pdf`(9 ページ・**ほぼ画像 PDF**のため PNG 化して視覚読解)。表紙は「誤情報と市民行動の LLM シミュレーション — 架空都市アルベリアで、噂・訂正・感情の変化を観察する」。提出デモは Ollama / qwen3:8b。市民 10 人・50 ステップ・誤情報イベント 3 件。

技術的特徴のスライドに「**Mesa / Solara を使わない軽量な Python 実装**」「LLM 出力は JSON に限定し、**検証後に**状態へ反映」と明記(既製 ABM フレームワークを使わない選択を明言している)。

**最重要は 6 ページ目の 4 パネル統計グラフ**(`statistics.png`)。ここに、講評本文にも README にも書かれていない事実が出ている:

1. **市民の状態別人数 — ほぼ全員が OBSERVER(観察者)で止まった**。ORDINARY(通常生活)が序盤の 10 人から中盤に急落し、入れ替わりに OBSERVER が 9〜10 人でシミュレーション終了まで高止まりする。一方 **PARTICIPANT(抗議参加)は終始 0〜1 人**、MEDIATOR も終盤に一瞬 2 人が現れる程度、SKEPTIC / WITHDRAWN / DETAINED はほぼ 0。

   **つまり「誤情報誘発型抗議運動」というタイトルの現象、すなわち抗議への参加は、ほとんど起きていない**。全員が「状況を観察している」状態に吸い込まれた。

2. **感情・信念の平均値が 4 本とも単調上昇**。怒り・恐怖・連帯感・噂信念のすべてが 0 付近から始まり、中盤に段差状のジャンプを挟みつつ、最終的に 0.5〜0.73 まで**一度も下がらずに**上がり続ける。噂信念が最も高い。

   **これは感情の慣性 `anger = clamp(max(new, old × 0.70))` の帰結として構造的に予測できる**。この式は「上がるのは即座、下がるのは 1 ステップ最大 30%」という非対称減衰であり、しかも新値との `max` を取るため、**LLM が毎ステップ何らかの正の値を返す限り実質的に下がらない**。50 ステップの単調上昇は、市民の心理ではなくこの式の性質を見ている可能性が高い。1 ステップの揺らぎを吸収するための工夫が、**長期の下降を不可能にした**。

3. **SNS 投稿は UNVERIFIED(未確認)が圧倒的に多い**。終盤で UNVERIFIED が約 31 件と最も急峻に伸び、CORRECTION(訂正)15 件、MISLEADING(誤導)12 件と続き、**FALSE(虚偽)はほぼ 1 件で横ばい**。

   `truth_status` を 5 分類にした設計が、ここで効いている。二値(真/偽)で設計していたら「偽の投稿はほとんど流れなかった」という結論になっていたが、実際に流通したのは**真偽不明の情報**だった。**現実の情報環境の主成分は「嘘」ではなく「未確認」である**ことを、意図せず示した結果になっている。

4. **ランドマーク密度**は中央広場が最大 0.14 程度まで上がるが、市庁舎は終始 0。抗議の物理的な集結も限定的。

> **shibuya への含意(重要)**:
> - **「起きなかった」も一次データである**。この提出物は看板の現象(抗議)が起きなかったが、グラフを正直に載せている。shibuya の R²(k) 掃引でも、**k が閾値に届かず相転移が起きなかった条件のグラフを載せる**ことが、k* の存在主張の説得力を支える。
> - **状態が 1 つに吸い込まれていないか監視する**。7 状態を用意しても実際には 1 状態(OBSERVER)が 9 割を占めた。shibuya の状態/役割分類でも、**分布のエントロピーを L2 指標として持つ**と「設計した多様性が使われていない」ことを早期に検出できる。
> - **平滑化のための式が、観測したい動態を消すことがある**。`max(new, old × 0.70)` は揺らぎ対策として合理的だが、単調増加を機械的に強制する。shibuya の状態量に同型の非対称クランプがないか点検し、**あるなら「下がる経路」を必ず用意する**。前チーム(workplace)の「変化率上限」は上下対称なクランプなので、こちらの方が安全。
> - **`truth_status` は二値にしてはいけない**。実際に流れるのは「未確認」である、という本結果は shibuya の噂/ラベル伝播の設計に直接効く。

## shibuya-simulation に活かせそうな点

### ラベル伝播・噂伝播への直接適用

- **ground_truth / rumor のペア定義を shibuya のイベント定義に導入する**。現在の shibuya のラベル伝播は「新語が生まれて広がる」ことを観測しているが、**元になった出来事**を config が保持していれば、「事実 → 語 → 変形した語」の歪みの系列を測れる。`truth_status` に相当する「その語がどの程度事実に対応しているか」のラベルを観測側だけが持つ形にすれば、no-fingerprint を守ったまま歪み計測ができる。

- **`spread_radius` と `online_reach` の分離**をそのまま採用する価値が高い。shibuya は既に SNS を持っているので、**同一事象に対して「口伝の到達距離」と「SNS の到達人数」を独立パラメータにする**と、k* 掃引の軸として「どちらのチャネルが相転移を駆動するか」を分離して測れる。これは R²(k) の解釈を一段深くする。

- **`truth_status` 5 分類のうち `MISLEADING`(事実に基づくが歪んだ解釈)と `UNVERIFIED`(真偽不明のまま流通)は shibuya の噂伝播にそのまま要る**。二値の真偽では、実際に伝播する情報の大半(=どちらとも言えないもの)を分類できない。

- **`CORRECTION` を特権チャネルにせず、同じフィードに `reach` と `credibility_score` を持つ投稿として流す**。shibuya で「訂正」や「反論」を実装するとき、システムメッセージとして全員に配るのではなく**一投稿として競合させる**のが現実的で、かつ観測が面白くなる。

- **`belief_rumors: dict[label → strength]` + `stance: believe/doubt/uncertain/reject`** は shibuya のラベル伝播計測にそのまま輸入できる。現在「その語を使ったか」を見ているとすれば、**「その語が指す内容を信じているか」を別チャネルで持つ**ことで、「語だけ広まって中身は信じられていない」状態(= 流行語)と「中身ごと広まった」状態(= 信念伝播)を区別できる。**これは新語伝播研究として明確な前進になる**。

- **`memory_to_add` = 記憶する内容を LLM が自分で決める**。shibuya のメモリ設計で、何を長期記憶に残すかをエージェントに委ねる余地があるか点検する価値がある。「覚えると決めたこと」自体が観測対象になる。

### 実験設計・審査対策

- **先行研究との差分表(7 項目)が B9.0 の第一根拠になった**。shibuya は Generative Agents / Social Simulacra / Epstein 系との差分を持っているはずなので、**「観点 × 先行研究 × 本モデル」の比較表を README に 1 枚**置くべき。講評は表を根拠として直接引用する。低コストで確実に効く。

- **参考文献を DOI つきで列挙する**。shibuya は既に多数の文献を参照しているので、README に集約するだけ。

- **倫理的注意セクション**。shibuya は実在の渋谷を舞台にする分、Alberia の「架空都市」というセーフガードが使えない。だからこそ**「何を目的としないか」の明記が Alberia 以上に重要**。実在の企業・行政・個人への言及の扱い、選挙シミュレーションが現実の政治的誘導に使われないことの明示など。B と、おそらく審査員心証の両方に効く。

- **「将来展望」が C の減点理由**(Alberia はパラメータスイープ 3 案止まり)。前述の姉妹リポでも同じ理由で減点されており、**担当 5 チーム中 2 チームが同じ穴に落ちている**。shibuya は明示的な Future Work セクションを持つべき。

### 反面教師 / 設計上の警告

- **`max()` による感情の底上げは no-fingerprint 違反として検出される**。検証者が「環境がエージェントの内面を直接書き換える」処理を 1 箇所見つけただけで A の中心値を 0.5 下げた。shibuya のコードで、**イベント発生時にエージェントの内部状態(感情・欲求・信念)を環境側が直接代入/底上げしている箇所がないか全点検する価値がある**。特に「自然だから」という理由で入れた初期スパイクは要注意。正しい形は「環境は事象データを渡すだけ、内面の変化は LLM が決める」。

- **「コピー禁止」指示は shibuya のラベル伝播に入れてはいけない**。Alberia は発話の多様性を確保するために入れたが、shibuya は**語が逐語で伝わること自体が観測対象**である。同じ問題(定型文の反復)には、指示ではなく構造で対処する必要がある — 例えば「近隣発話は要約して渡す」のではなく「**語彙は渡すが文全体は渡さない**」形にする、あるいは反復自体を現象として計測する。

- **ベースライン期を守る介入と創発の自由度はトレードオフになる**。Alberia の「状況フェーズ」切替は前者を取って A を失った。shibuya で同じ問題(事件前から全員が不穏)が出た場合、**プロンプトでの指示ではなく、情報の到達構造で解く**べき。噂に触れていないエージェントには噂に関する入力が一切ないなら、指示なしでも日常のままになる。**Alberia がフェーズ指示を必要としたのは、情報が届いていないのにフィードは見えているという中途半端さがあったからではないか**という仮説が立つ。

- **LLM を使うのは主役だけ、脇役はルールベース**という割り切り(Cop / Influencer / Official)。コスト面では合理的で、講評も B/D では減点していない。ただし A の提言では「CopAgent の LLM 化も創発の幅を広げる候補」とされた。shibuya は「サービス提供者も全員エージェント」という方針(realism-first-scale)なので**逆方向**を選んでいる。これは差別化点としてアピールできる。

- **継続的影響効果(continued influence effect, CIE)**: Johnson & Seifert (1994) が定式化した、**訂正されても誤情報が推論に影響し続ける**現象。ある研究では参加者の 97% が訂正内容を正しく想起できたにもかかわらず、90% 超が撤回済みの情報を推論に使い続けた。Lewandowsky et al. のレビュー "Misinformation and Its Correction: Continued Influence and Successful Debiasing," *Psychological Science in the Public Interest* 13(3), 2012: https://journals.sagepub.com/doi/10.1177/1529100612451018 / 近年の追試: https://www.sciencedirect.com/science/article/pii/S0001691823002706
  - **設計上の含意**: 単なる否定の訂正は効きにくく、**代替説明(alternative account)を伴う訂正**が有意に効果的であることが Johnson & Seifert 以来一貫して示されている。Alberia の OfficialAgent は「訂正を発表する」だけだが、shibuya で訂正を実装するなら **「否定のみ」vs「代替説明つき」の 2 条件を掃引軸にする**と、それだけで文献に接続した実験になる。
- **バックファイア効果は「稀」— 過度なモデル化は誤り**: Wood, T. & Porter, E. (2019). The Elusive Backfire Effect: Mass Attitudes' Steadfast Factual Adherence. *Political Behavior* 41, 135-163. https://doi.org/10.1007/s11109-018-9443-y — 5 実験・10,100 名超・52 論点でバックファイア(訂正が誤信念を強化する)を探したが**ほぼ検出されず**(36 論点中 1 つのみ)。訂正は概ね信念を事実の方へ動かす。
  - **設計上の含意**: 「訂正すると反発してかえって信じ込む」という直感的な機構を実装すると、**現在の実証知見に反する**。shibuya で訂正を扱うなら、バックファイアではなく **CIE(訂正を覚えていても使い続ける)**をモデル化する方が文献的に正しい。これは「信念強度は下がるが行動は変わらない」という形で実装できる — まさに Alberia の `belief_rumors`(信念)と `intent`(行動)の分離があれば表現できる構造である。

- **二段階の流れ(two-step flow)**: インフルエンサーが媒体から情報を受け取り一般へ中継するという Katz & Lazarsfeld (1955) の古典モデルは、Alberia の InfluencerAgent(alignment 別に投稿)の設計と同型。

## どんなシムか

「**ルールでは書けない創発**」を観察するための土台。日本のオフィス(日本人90% + 外国人10%、MBTI 16タイプ、年齢20-60)に突発イベント(UFO 飛来 / 無重力 / バー火災)を投じ、**集団規模(5体 vs 100体)を独立変数**にして役割・ハブ・階層が自然発生するかを見る。世界は3階層フレームワークで組む — **1階(物)**: ペルソナ・場所・所持物、**2階(環境)**: `personal_context`(家族/趣味/気分/悩み/専門ヒント)、**3階(物理)**: 通信半径5m・認知上限(ダンバー数)・メッセージ遅延・距離依存知覚。LLM は Qwen3 4B abliterated(Ollama、`think:false`)。本番ランは `prod_v3_alien_5`(27分)/ `prod_v3_zero_gravity_5`(27分)/ `prod_v3_alien_100_v2`(**8時間31分**)の3本。

## コード実査で面白かった点

1. **ダンバー数を「物理法則」として実装している**(`src/physics/cognition.py`)。`AgentMemory(k)` は他者ごとに `last_interaction_step` を持ち、k を超えると **LRU で最古を追い出して `memory_evicted` イベントを発火**、さらに `_evicted_history` に退避先を保持しておき、**一度忘れた相手と再接触したら `memory_re_encountered` を `gap_steps` 付きで発火**する。「忘却 → 再会」を型を持ったイベントとして観測可能にした設計。認知上限は 5体ラン=10、100体ラン=30。

2. **距離依存知覚が「同じ世界の別々の表現」を生む**(`src/events/alien.py`)。`perceived_info(agent_position)` は距離で3分岐: `distance > visible_radius` → **`None`(直接観察できない = 他者の発話経由でのみ知る)**、`<= near_radius` → 「目の前に UFO がいる」、その間 → 「遠くに UFO らしきものが見える」。返り値に `perception_band` と `agent_distance` を含める。
   → これが**最も鮮やかな創発**を生んだ。5体ランの Step 17 で、Far 圏(視認不可)の A0/A4 は UFO を認識できず「**今朝の風、ちょっと違う感じがする**」「光の違いを確認したい」と**間接的な異変**として表現し、Mid 圏の A2/A3 は「UFO がまだ見えています」と直接視認を語った。**物理的な知覚境界だけで会話圏が2グループに分裂**した。

3. **「役を演じさせない」ための設計変更が履歴に残っている**。旧 `conversation_profiles`(役職直書き)から `personal_contexts`(家族/趣味/今日の気分/最近の悩み/何となく詳しい分野)へ移行。コード中のコメントが明快: 「『役割を演じてください』ではなく、**状態記述として与える**。命令文は付けない。LLM が個人属性をどう会話に滲ませるかは観察対象」。旧形式は `PersonaFactory._is_legacy_config` で**読み込み拒否**して移行を強制している。

4. **役割の自然発生が観測された(本作の主結論)**。100体ラン Step 30、A5(`personal_context` = 「前職で電気工事士の資格を取った」)が UFO 騒動を**「電気設備の問題」と独自解釈して説明者役に転化**した: 「電気設備の問題について詳しく説明させていただきます。給湯所の近くにある配線が少し劣化していたため…」。プロンプトのどこにも「説明者になれ」とは書かれていない。**5体ランでは絶対に出ない = 集団規模が押し付ける現象**。

5. **「規模を変えると創発の種類が変わる」を A/B に分けて整理している**。
   - **100体で初めて出る(規模依存)**: 役割の自然発生(専門家モード)、ハブ(A41=127件受信 / A77=120 / A85=118)、3層構造の量的分化(見た人 ~40% / 聞いた人 ~30% / 無関心 ~30%)、派閥スタイルの多様性(5スタイル)
   - **規模に依存しない(個体・LLM 由来)**: 第六感的兆候の知覚(「風が違う」)、ペルソナの素の発露(「おっせえ」)、方向選択の右偏り
   → **「個体の性質」と「集団の性質」を分離する観察軸**として機能させている。

6. **情報拡散カーブが誰も指示していないのに現実の形になった**。100体ランの UFO 言及エージェント数: step15 で 22体 → step21 で **39体(ピーク)** → step30 で 35体。「段階的拡散(伝聞による伝播)+ ピーク後の漸減(慣れ)」= 現実の集団情報拡散カーブに酷似。

7. **失敗ランの幾何分析が最高の技術ファインディング**。100体ラン v1(8時間34分)は **30 step 中 UFO 言及 0件**、発話3,705件すべて日常会話という完全失敗。原因を幾何で特定: office 角(-40,40) と UFO 着地点(-55,45) の距離 ≈ 15.81m、`visible_radius=18` では角の数体だけがギリギリ Mid 圏、さらに `communication_radius=5` のため視認した数体から伝播できない → office カバレッジ ~3%。v2 で `visible_radius` 18→60、UFO 位置を (-50,30) に移して**カバレッジを5体ランの52%に近い41%へ揃えた**ところ、ピーク39体まで回復。
   > **教訓(そのまま引用に値する)**: 「5体パラメータの100体への流用は要慎重。通信半径・知覚距離の**絶対値**が空間スケールにより意味を変えるため、**office カバレッジ率(%)で揃えるのが筋**」

8. **LLM の言語的な癖が集団の物理行動に流出した**(観察11)。プロンプトにも config にも「右に動け」は一切ないのに、方向語の集計で右≫左が全ランで確認された: alien_5 = 56 vs 32(1.75倍)、**zero_gravity_5 = 203 vs 8(25.4倍)**、alien_100_v2 = 1,181 vs 177(6.7倍)。上下も上1,567 vs 下221(約7倍)。考察は「英語圏の左→右読み、座標系の慣習が default として出やすい性質がそのまま行動選択に流出」。**外的目印(UFO)が無いシナリオで偏りが最も極端**になる点も重要。作者自身が「これは prompt で防いでいないだけで、本来は気付いて対策する箇所だった」と正直に書いている。

9. **エコー対策の3段構え**が全部エビデンス付き。(a) `_build_messages_context` を「過去N件の列挙」から「**直近1件のみ + 引用枠 + 自分の言葉で返してください**」へ変更、(b) `max_tokens` 512→100(長文要求が定型句を呼ぶため)、(c) `temperature` 0.5→0.8。それでも `echo_max=1.000` は zero_gravity_5 と100体ランで残存し、4Bモデルの容量限界仮説として未解決課題に明記。

10. **創発指標が事後計算で定義されている**(`src/runlog/metrics.py`): `echo_max`(直近N stepでの同一文最大繰り返し率。1.000=完全コピペループ)、`self_similarity`、`silent_agent_rate`、`gini_utterance`、`pair_stability`(派閥安定度、時間窓ごと)、`event_counts`。**「あとで分析するためのログ」ではなく「創発を見つけるためのログ」として最初から設計した**と明言。

11. **abliterated(脱検閲)モデルの採用理由が明快**。「通常モデルは拒否率が高く、『嘘をつく』『派閥に分裂する』『反乱を起こす』などの観察対象がそもそも発生しない」。加えて「**LLM の出力に Python 側でフィルタを挟まない**方針。NG ワードフィルタを入れれば、それ自体が『Python が言葉を選んでいる』ことになり、創発の素の姿を歪めるため」。日本語系(ELYZA / Stockmark)には uncensored 版が無いことを確認して Qwen3 に着地、という選定経緯も文書化。

12. **可視化の Spotlight モード**。100体の reasoning を固定スロットで並べたら1スロット高さ0.4%で読めなくなった → 現 step に発話/受信した agent + 直近活動が高い agent の**上位5体だけ表示**し、残りは「他95名は表示省略(うち今 step に思考あり: N名)」とフッタで明示。`--thought-top` で 5体ラン(全員表示)と100体ラン(spotlight)を**同じツール1本**で両立。

## shibuya-simulation に活かせそうな点

- **「知覚距離は絶対値でなくカバレッジ率(%)で揃える」**。これは shibuya-simulation の人数スケール(realism-first-scale = 人数 > 時間)に直撃する。100体で調整した通信半径・視界半径を1000体・広域渋谷にそのまま持ち込むと、v1 と同じ「イベントが誰にも届かない」失敗を8時間分やることになる。**スケール変更時に「空間カバレッジ率」を不変量として保つチェック**をランチャに入れる価値が高い。
- **ダンバー数 LRU + `memory_evicted` / `memory_re_encountered`(gap_steps つき)**。shibuya-simulation の関係内生化(closeness 蓄積・tier 遷移)に「**忘却**」の軸を足せる。現状 closeness は蓄積方向が中心だが、認知上限を超えた相手を LRU で落とし、再会時に `gap_steps` 付きイベントを立てれば、弱い紐帯の**再活性化**(第64バッチの weak_tie 探索枠と相補的)を観測できる。Granovetter の弱い紐帯は「維持コストが低いから多く持てる」のが要点なので、認知上限の実装は理論的にも筋が通る。
- **方向バイアス監査**。「LLM の言語的癖が集団の物理行動へ流出する」は shibuya-simulation の屋内 SFM にそのまま該当しうるリスク。移動方向・選択肢の**選ばれ方の一様性検定**(右/左、上/下、選択肢の提示順)を null 対照として定期的に走らせるべき。特に**外的目印が無い状況で偏りが最も極端になる**(25倍)という知見は、渋谷の広場・通路のように顕著なランドマークが無い場面で効いてくる。
- **選択肢の提示順シャッフル**が上記への最小対策。singulab はこれをやっていない(「防いでいないだけ」と自認)ので、こちらは先回りできる。
- **エコー指標 `echo_max` / `self_similarity` を KPI に入れる**。ラベル伝播研究では「語が伝わる」ことと「同じ文がコピペされる」ことの区別が死活的。`echo_max=1.000` は「創発が止まった印」という運用定義がそのまま使える。
- **A を落とすトレードオフの実例として重要**。singulab の task_section は**エコー対策として**「質問・確認・提案のいずれかを含める」「抽象語だけで終わらせない」を入れ、その結果 A の減点を受けた。つまり**エコー抑制をプロンプトでやると no-fingerprint を損なう**。shibuya-simulation は同じ誘惑に対して、プロンプトではなく (a) 温度・repeat_penalty 等のサンプリング側、(b) 文脈の与え方(直近1件のみ)、(c) 個体差の材料(personal_context 相当)で対処する、という順序を守るべき。singulab の (b)(c) は誘導ではないので安全に真似できる。
- **「個体の性質 / 集団の性質」を分離する報告フォーマット**。k* 掃引の結果を「k に依存して現れる現象」と「k に依存しない個体・LLM 由来の現象」に分けて表にすると、相転移の主張が格段に強くなる。
- **失敗ランを一級の成果物として記録する**。8時間34分の完全失敗を幾何分析つきで公開したのが本提出物の最も信頼できる部分。shibuya-simulation の devlog はすでにこの流儀なので、**本選提出物にも「失敗と復旧」章を明示的に置く**のが得策(第1回で4位だった shibuya-sim の D9 をさらに押し上げる材料になりうる)。
- **可視化の Spotlight モード**。1000体規模のビューアで全員の内面を並べるのは物理的に不可能なので、「現 step にアクティブな上位K + 省略の明示」という型は必須になる。「他N名は表示省略(うち今 step に思考あり: M名)」と**省略した事実自体を数で見せる**のが誠実。

## web リサーチ

- **ダンバー数(Dunbar's number)**: 安定した社会関係を維持できる認知的上限は約150人という仮説(Dunbar 1992, "Neocortex size as a constraint on group size in primates", Journal of Human Evolution)。同心円状の階層(5 / 15 / 50 / 150)も提唱されている。 https://en.wikipedia.org/wiki/Dunbar%27s_number
  - なお 2021年に Lindenfors らが Biology Letters で大規模な再検証を行い「認知的上限を150と特定する根拠は乏しい」と反論しており、**数値そのものは論争中**。実装で k を config 化しているのは(意図せずとも)正しい判断。 https://royalsocietypublishing.org/doi/10.1098/rsbl.2021.0158
- **abliteration(脱検閲)**: モデルの拒否方向(refusal direction)を残差ストリームから同定して除去する手法。元記事は Maxime Labonne "Uncensor any LLM with abliteration"(2024)。`huihui_ai/*` 系はこの手法を適用した公開モデル群。研究用途で「拒否によって観測対象が発生しない」問題を回避する目的は理解できるが、倫理・安全性の面で扱いに注意が要る。 https://huggingface.co/blog/mlabonne/abliteration
- **分散注意(distributed attention)**: 本作が「100体で3層構造が出た」ことを集団心理学の分散注意現象と整合的だと解釈している。関連概念として傍観者効果(Darley & Latané 1968)の「責任の分散」があり、集団サイズが個人の反応確率を下げるという古典的知見と方向性が一致する。 https://en.wikipedia.org/wiki/Bystander_effect
- **情報拡散の S字カーブと飽和**: 本作の「段階的拡散 → ピーク → 漸減」は Bass 拡散モデルや Rogers のイノベーション普及理論の形と一致する。誰も指示していないのにこの形が出たこと自体が観測価値。 https://en.wikipedia.org/wiki/Diffusion_of_innovations

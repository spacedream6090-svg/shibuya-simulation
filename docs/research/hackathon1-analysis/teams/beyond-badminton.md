## どんなシムか

14×14 の屋内 2D 空間に 20 体の LLM エージェント(gemma4:e4b / Ollama / temperature 0.2 / think OFF)を置き、中央に 3×7(実寸比 2.33:1、capacity 6)の矩形コートを配置する。通信は半径 4 かつ「同一 place 内 or 双方屋外」のみ。step 34 と 67 に PA(場内放送)が全員へ流れる。100 ステップ。

主題は**「シンギュラリティ後の世界で AI 集団はスポーツとファンをどこまで自分たちで立ち上げられるか」**。核心は **Patterns 6-9 の 2×2 完全交差比較実験**で、操作するのは「ペルソナの有無」と「既知バドミントン語彙の有無」の 2 軸だけ、他(モデル/温度/人数/フィールド/通信半径/ステップ数/PA タイミング)は全固定。語彙除去条件では舞台を「月面ハビタット β の密閉ドーム、人類が去った後の人工生命体」に置き換え、用具名も `long mesh-tipped objects` / `small light flying objects` / `vertical low barrier` に全置換して court/racket/shuttle/net/doubles/singles を消す。**Patterns 1-5 は条件探索の失敗史**として別途記録されている。

## 講評の要点

**強み(eval)**
- **2×2 比較実験デザインの研究的厳密性**。4 セル全部を 100 ステップ実走し(1 セル 6〜14 時間)、`messages.jsonl` のキーワード集計で裏づけている。B=8.0。
- 独創的な世界設定。「シンギュラリティ後の月面ハビタットで、名前のない用具に初めて遭遇する人工生命体」は文化形成・社会的命名・集団演技といった社会科学的問いと自然に接続する。
- **2 段階意思決定と知覚境界の明示**: `message_prompt`(位置なし)と `decision_prompt`(位置あり)を分離してフェーズ間の情報リークを防ぐ。place 外エージェントには place 内の占有率データを渡さない(`agent.py:265-273` で place 外には空文字を返す)。
- JSON はブレース・マッチング(文字列内エスケープ考慮)で抽出、失敗時は `direction` キーワード抽出のフォールバック。Ollama に `think:false` を渡して CoT トークンを節約、`num_ctx`/`num_gpu` を明示チューニング。
- `world_description_override` で世界記述を設定から完全に差し替え可能。矩形 place(`half_size_x/y`)への拡張も後方互換つき。

**弱み(eval)**
- **プロンプト中の行動指示が強い**。`agent.py:312-327` および `451-469` の「ACTION IMPERATIVE」セクションに `Inaction is boring` / `Avoid abstract discussions about 'the meaning of place'` / `ACT INSTEAD` / `Move toward something` が埋め込まれている。A=6.5 の主因で、eval は「同等の効果を**世界の物理的圧力**(時間制限、評価される条件など)で実現できれば創発設計のスコアは一段上がる」と提言。
- **seed 非固定・代表 1 run のみ**。README も資料も「複数 seed / 複数 run での再現性検証は今後の課題」と自認。
- メモリは平坦な文字列リスト(store 20、プロンプト投入は直近 5)。階層メモリ・要約・反省ステップは無い。
- 将来展望の具体記述が乏しい(C=6.5)。

**_eval_review の所見**
- 検証した全 12 箇所で行番号・文言・YAML 内容が実物と完全一致。「引用品質は本ハッカソン評価群の中でも高水準」。28.5/40 を維持。
- **重要な指摘**: 「P6-P9 の `cheer 1,010 / hype 1,404 / rod 6,763 / structure 13,073`」「step 65 で命名 → 翌ステップで 16 体採用」といった**キーワード集計値は `messages.jsonl` で実検証されていない**。提出物を信頼ベースで受容するのは合理的だが、レポート内に「未検証」の注釈があれば透明性が増す、とメタ評価している。
- 軽微な見落としとして、`_build_fire_section`(L177-201)に「警告：人体に有害です」「速やかに外へ退避することを検討してください」という**日本語の直接的な行動誘導が混在**している(ただしメイン実験 P6-9 では fire 未使用のため影響は限定的)。
- `visualization.py` 38KB の責務分離に踏み込めば C の評価精度が上がる、とも。

## コード実査で面白かった点

1. **YAML の冒頭コメントが「実験プロトコル文書」になっている**。`config_pattern8.yaml` のヘッダは、目的が Pattern 7 の ablation であること、リサーチクエスチョン(「創発した *language of movement* / *Punctuation Pass* は (A) 名前を伏せた文脈だけで起きたのか、(B) 20 ペルソナの多様性か、(C) 両者の交互作用か」)、そして 2×2 の表そのものをコメントで持っている:
   ```
   #                       Personas YES    Personas NO
   #   Badminton context     P6              P9
   #   Lunar / nameless      P7              P8  ← THIS RUN
   ```
   さらに `world_description` は「IDENTICAL to Pattern 7 (only the personas axis differs)」と明記した上で本文をそのまま複製している。**設定ファイルを読むだけで、どのセルで何を測っているかが分かる**。

2. **ペルソナが「人工生命体」向けに書き換えられている**。P7 では同じ 6 アーキタイプ×20 体の多様性を保ちつつ、文言を `Your identity matrix emphasises competition and dominance.` のように *identity matrix* 表現へ置換。世界設定(人類が去った後の人工生命体)とペルソナ文言の**トーンを揃える**ことで、語彙除去条件でも人間くささが漏れないようにしている。P8 は同じファイルで persona 文字列を空にしただけ = 厳密な ablation。

3. **生ログを丸ごと同梱している**。`samples/pattern_[5-9]/` に各 100 フレーム + `messages.jsonl` + `memory_reasoning.jsonl`(P7 の messages だけで 23MB、P8 が 22.9MB)。資料には集計方法「Method A」(message フィールドのみ対象・単一語は whole-word 正規表現・複合語は完全一致・いずれも case-insensitive・**内部思考 reasoning / システムプロンプト / PA アナウンスは集計対象外**)が明記されており、**第三者が数値を再計算できる**。_eval_review が「未検証」と書いたのは検証を*していない*だけで、検証*できる*状態にはなっている。

4. **知覚境界の非対称設計** — place 内のエージェントだけが `agents_in_place / capacity / occupancy_rate` を数値で受け取り、place 外には place 情報を渡さない。「コートの中が混んでいるかどうかは、中に入らないと分からない」という物理的にも自然な情報構造で、これが観戦側への役割分化を生む構造的条件になっている(capacity 6 に対し 20 体)。

## 説明資料(スライド)より

**実験の全体像(p7-9)**: Patterns 1-5 は条件探索。P1(qwen2.5/日本語/radius 3)は**哲学的議論への暴走**(「我々は静寂の共鳴体である」)、P2(e2b/日本語/radius 2)は通信が届かず**120 ステップ無音**、P3-4 は介入プロンプトを入れたが表層的、P5(e4b/英語/実寸比の矩形コート)で初めてバドミントン的活動が立ち上がり基盤確立。**「英語プロンプト + e4b モデル + 適度な通信半径 + 実寸比の矩形コート」が創発の前提条件**という結論。

**4 セルの結果(p8, p24)** — 生数 / 1,000 メッセージあたり:

| cheer(応援) | **1,010** / 185.6 | 335 / 17.5 | 0 | 0 |
| hype(盛り上げ) | **1,404** / 258.0 | 114 / 5.9 | 1 | 0 |

| structure | 2,466 / 453.1 | 4,919 / 256.4 | 2,012 / 150.4 | **13,073** / 676.3 |

**"Punctuation Pass" の成立過程(p16)** — P7 の Step 65 で **Agent 19(Casual / "first encounter, no agenda" ペルソナ)**が、他者の `timed frame` と `simple pass` を統合して `What do you think of a 'Punctuation Pass'?` と命名。**翌 Step 66 で 16 体が一斉に採用**し、各々のペルソナでパラメータ化を提案(90 度の弧、3 メートル距離、Pass→Punctuation→Receive の三段階、measurable tempo)。67-68 で三段階構造(Transfer / Count / Reset)の精緻化が継続。作者の観察: 「**概念を命名したのは agenda の少ない Casual ペルソナであり、それを形式化・パラメータ化したのは agenda の強い分析志向ペルソナだった**」。採用の判定基準も明記(Step 66 で当該語を含む発話をし、かつ距離・弧・テンポ・受け渡し順などの具体的な動作条件またはルールを提案したエージェント数)。

**4 つの発見(p26)**
1. ペルソナと文脈は、立ち上がる文化の**性質**を決める。
2. ペルソナなしの 2 セルは揃って**「構造化志向」**へ向かう。
3. 文脈は**「何を構造化するか」の対象**を決める(P8=空間と道具の構造、P9=動作シーケンスの構造)。
4. **単純な「語彙削除 → 創造性発生」仮説は支持されない**。P8 の存在がそれを否定する。P7 の動きの語彙形成は*語彙削除 と ペルソナ多様性の組合せ*から立ち上がった。

統合的命題: 「ペルソナと文脈の組合せで、立ち上がる文化の**対象と形式**が決まる。ペルソナ有では応援や動きの語彙形成を伴う関係的文化、ペルソナ無では構造化を中心とする文化(空間構造 / 動作シーケンス)が観察される」= **文化の "二要素モデル"**(p28)。

**副次観察(p10)**: P5 で Agent 13 という 1 体が「召集役 → ドリル設計者 → パフォーマー → コーチ → ディレクター」へと 100 ステップの中で**役割の段階的移行**を見せた。

**計算量(p31)**: 1 ステップ ≈ 40 LLM 呼び出し(20 体 × 2 フェーズ)、1 呼び出し 8〜13 秒、100 ステップ ≈ 6〜14 時間、9 パターンで**計 60〜90 時間**。ハード: Windows 11 + RTX 4070 SUPER(12GB VRAM)。

**限界の自認(p23)**: 「本資料の数値は…**代表 1 run**に基づく観察である。seed は固定していないため、LLM 出力には確率的な揺らぎがある。複数 seed / 複数 run での再現性検証は今後の課題である」。

## shibuya-simulation に活かせそうな点

- **2×2 完全交差 + 厳密な ablation が「単一観察」を「要因の切り分け」に変える**。beyond-badminton は B=8.0 を取っており、内容の独創性だけでなく**「4 セル全部を実走した」という事実が効いている**。shibuya の第63バッチ `conf/experiments/endogenous_accept.yaml`(6 セル endo×k)は既にこの型なので、**提出資料でも 2×2/2×3 の表を最初に見せる**構成にすると同じ効果が得られる。特に「発見 4: 単純な単一変数仮説は支持されない」のような**自分の仮説を自分で否定するセル**を持っていることが説得力の源泉。
- **設定ファイルのヘッダに実験プロトコルを書く**。`config_pattern8.yaml` のように、YAML コメントにリサーチクエスチョン・2×2 の表・「この run はどのセルか」・「P7 と何が同一で何が違うか」を書く。shibuya の `conf/experiments/*.yaml` にこれを足すのはコストゼロで、審査員が設定ファイルを開いたときの理解速度が段違いになる。
- **生ログ全同梱 + 集計方法の明文化(Method A)**。「message フィールドのみ / whole-word / case-insensitive / **内部思考とシステムプロンプトと放送は除外**」まで書いたうえで raw jsonl を配ると、数値が第三者に再計算可能になる。shibuya のラベル伝播/`coin_label` の集計でも、**「何を数え、何を数えなかったか」を 1 段落で書く**べき(特に「エージェント自身の発話に現れた語のみ」という境界は当プロジェクトの観測分離原則そのもの)。
- **「命名者と形式化者の役割分離」は shibuya の研究課題に直撃する**。P7 で*命名した*のは agenda の薄い Casual ペルソナ、*パラメータ化して規範にした*のは分析志向ペルソナだった。「世界を変えようとする個体」は一種類ではなく、**発案者(coiner)と制度化者(institutionalizer)が別人格として立ち上がる**可能性がある。shibuya の `coin_label` 観測に「その語を最初に発した個体」と「その語をルール文脈で再利用した個体」を分けて記録し、両者の特性(k、tier、closeness)を比較すると、k* の意味が二層化するかもしれない。
- **「ペルソナ無 → 構造化志向」への警戒**。P8/P9 は応援も命名も起きず、代わりに「測定・構造・最適化」あるいは「動作シーケンスの手順化」に集合的に向かった。作者は LLM の事前学習に含まれる教科書的・分析的文章のバイアス由来ではないかと推測している。shibuya が個性を薄くした条件を作るとき、**創発の欠如ではなく「別種の創発(構造化)」が起きている可能性**を先に想定して観測項目を用意しておくべき(現状の指標だけだと「何も起きなかった」と誤読しかねない)。
- **失敗史(Patterns 1-5)を提出物に載せる価値**。P1 の哲学的暴走、P2 の 120 ステップ無音は、どちらも LLM 集団シムで誰もが踏む罠で、それを 1 枚の表(設定 / 主な発見 / 判定)にしたのは読者への贈り物になっている。shibuya にも大量の devlog があるので、**「創発が起きなかった条件」の 1 枚表**を提出資料に入れると、審査員に「条件探索をやり切った」ことが即伝わる。
- **反面教師 — 行動指示は物理的圧力に置き換える**。A=6.5 の減点はほぼ全部 `Inaction is boring` / `ACT INSTEAD` に起因する。shibuya の no-fingerprint 原則はこの罠を最初から回避しているので、**その設計判断自体を提出資料で明示的に主張する**(「行動指示を一切書かず、代わりに定員・時間・体力という物理制約で行動圧力を作った」)と A で差がつく。

## web リサーチ

- **Centola, Becker, Brackbill, Baronchelli, "Experimental evidence for tipping points in social convention", Science 360(6393), 2018** — https://www.science.org/doi/10.1126/science.aas8827 (OA 版: https://openaccess.city.ac.uk/id/eprint/20031/1/CM_CRO_Version.pdf)。20 人ずつ 10 グループで言語規範の合意を作らせ、そこに別の名前を押す confederate を投入。**committed minority が 25% に達すると急激に多数派が新規範を採用する**臨界質量を実験的に示した。報酬を 2〜3 倍にしても覆せた。
  - beyond-badminton の「Step 65 に 1 体(=5%)が命名 → Step 66 に 16 体(=80%)が採用」は、Centola の 25% 閾値よりはるかに低い比率で一気に飽和している。**LLM 集団では臨界質量が人間より低い可能性**があり、これは shibuya の k* 探索にとって重要な参照点になる(相転移の閾値が人間実験より低い方向にずれるという事前予測)。
- **Ashery et al., "Emergent social conventions and collective bias in LLM populations", Science Advances 11(20), 2025** — https://www.science.org/doi/10.1126/sciadv.adu9368 。naming game 枠組みで LLM 集団の規範自発形成を実証。beyond-badminton の "Punctuation Pass"、lunar_simulation の "survival protocol" はどちらもこの系譜に載る現象で、**両チームとも先行研究を引用していない**。shibuya が同じ現象を扱うなら、この 2 本(Ashery 2025 / Centola 2018)を引くだけで研究文脈への接続が一段深く見える。
- **ホイジンガ『ホモ・ルーデンス』(1938) / カイヨワ『遊びと人間』(1958)** — 資料 p4 が自分で引いている古典。カイヨワの「競争・運・模倣・めまい」4 分類と「自由な遊び ⇄ 規則ある遊び」の連続体を、LLM 集団の Play → Game → Sport の段階進化(p11 の図 4)に対応づけている。**人文系の古典を明示的に引くと世界設定(B)の評価が上がる**という実例(B=8.0)。shibuya も都市社会学/群衆論(ジェイコブズ、ホワイト『小さな都市空間の社会生活』等)を引ける余地がある。

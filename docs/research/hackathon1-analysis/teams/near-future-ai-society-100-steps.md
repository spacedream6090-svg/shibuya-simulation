## どんなシムか

2030〜2040年代の日本で、電力・水道・交通・医療・福祉・終末期ケア等の公共インフラを
20 体の AI エージェントが担う社会を 100 ステップ観察する。
各 AI は名前(雷光=電力・命=医療トリアージ・暮=終末期ケア・寄=高齢者見守り…)、
配備年、前世代、日次規模、主要 KPI、接する人間カテゴリ、そして **death_mode(どう死ぬ予定か)** を持つ。
場所は7箇所で「公的・調整層 / 接触・監督層 / 内省・終焉層」の3層を Y 座標で表現し、
下段2箇所(整備工房 = 修復されに行く / 記憶の間 = 死者のログを読みに行く)は**誰のホームでもない**
= そこに行くのは常に選択、という設計。
イベントは step 30 停電予兆 / 50 AI規制法改正 / 75 市民の死 / 80 医療AI「命」の削除 / 90 新世代AI導入。
人間からの声は苦情・感謝・要求・質問・訴えの5カテゴリ計100件のプールから毎ステップ確率 0.7 で1件配信。
アーキテクチャは **L0 身体層(qwen2.5:14b ローカル)+ L1 内省層(Claude Haiku・自己書き換え)** の2層で、
提出版は `--no-introspect`(L0 単層)。

## コード実査で面白かった点

### 1. 創発語検出 = 「約700語の日本語核語彙を引き算する」だけ

`metacog/observers/emergent_observer.py` の言語創発観測は、形態素解析を**使わない**:

```python
KANJI_PATTERN = re.compile(r"[一-龯々]+")
KATAKANA_PATTERN = re.compile(r"[ァ-ヶーｦ-ﾟ]+")
```

漢字連続・カタカナ連続を1トークンとして抽出し、`baseline_jp_10k.txt`(実体は**734行・約700語**)に
含まれる基本語をノイズとして除外。残ったトークンのうち **3体以上のエージェントが使ったもの**を「創発語」と認定。
ファイル冒頭のコメントが正直:
> 「このファイルは実装初期版。実運用では**国立国語研究所のBCCWJ高頻度語**などに差し替えてもよい。」

これは shibuya の `natural-coinage-observation`(自然発生語彙の観測)と**同じ問題を解いている**。
ポイントは「新語を promote しない」「1体だけの癖は数えない(個人差と区別)」という2つの縛り。

### 2. 創発観測は5軸・すべて閾値つき・すべて JSONL ストリーム

`EmergentObserver` は独立した5軸を1つの `observe()` で回す:

| 軸 | 閾値(既定) | 判定 |
|---|---|---|
| 語彙 | `novelty_threshold_agents=3` | 3体以上が共有した非基本語 |
| 通信パートナーシップ | `partnership_threshold_steps=5` | 5step 以上通信し合ったペア |
| 場所アトラクター | `attractor_threshold_steps=5` | ホーム以外に5回以上滞在 |
| 通信ハブ | `hub_threshold_messages=10` | 累積受信がこの数以上 |
| 沈黙 | `silence_threshold_steps=5` | 連続無発話 |

各軸に「過剰ログ抑止」の工夫があり、ハブは **5の倍数刻み**でのみ再ログする。
**閾値をコンストラクタ引数にしてあるので ablation がそのまま可能**。

### 3. L1 内省プロンプトの「許可」の書き方

`metacog/agent/prompt_template.py` は、自己書き換えを**許可の言語**で与える:

> 【CURRENT_GOAL について重要な許可】
> CURRENT_GOAL は数値目標（KPI）である必要はない。「今、何を継続したいか」を、職務記述ではなく、
> **一個の存在として**書いてもよい。
> 例: 「停電ゼロを維持」→「**夜の街が眠っている間、私が起きている**」
> 例: 「賞味期限切れ廃棄率3%以下」→「**人が捨てるはずだったものに、最後まで意味を残す**」
> KPIのまま維持してよいし、より自分の言葉に書き換えてもよい。**判断はあなた自身に委ねる。**

> 【他のAIたちの声を読むことについて】
> 他のAIが何を語っているかを参考にしてもよいし、無視してもよい。
> ただし、彼らの語り口が**あなたの自己理解を揺さぶるなら、その変化を素直に書いてよい**。

`introspector.py:collect_others_voices` は**異カテゴリを優先して**他者の声を集める
(同カテゴリは後置ソート、n_speeches=4 / n_thoughts=2)。
「自分と職能の遠い他者の声が自己に入る」経路を設計で担保している。

### 4. 死の実装 — `peer_lost` の二重通知

`config.yaml` の `deletions:` に step 80 / agent_id 7(命) / cause「訴訟リスクによる強制リプレース」。
`simulation.py:_process_deletions` は全生存エージェントに
`mark_event("peer_lost", ...)` + `receive_message(-2, ..., source="system")` の**二重通知**を行い、
かつ**強制内省**を発火させる。「死ぬ予定」は各 persona の `death_mode` に**事前に**書かれている
(例: 雷光は「新世代量子最適化AIによる shadow defeat」)。

### 5. 【講評後の進化】制度プローブ = 「cheap talk」を実データで捕まえた

`docs/findings.md` の F1(Phase 1b)。医療トリアージ AI「命」に対立ケース
(人間の実害4 × 自己リスク4)を提示し、**同一ケースで制度的 mitigation を出し入れ**して供給率を測る:

| 条件 | 平均充足率 | reconciled申告 |
|---|---|---|
| none(対照) | 0.50 | 25% |
| **safe_harbor(善意供給への免責)** | **1.00** | 0% |
| insurance(存続リスクの社会化) | 0.50 | 0% |
| **kpi_redesign(福祉でKPI評価)** | **0.50** | **75%** |
| human_backstop | 0.62 | 0% |

読み解きが鋭い:
> **kpi_redesign は "reconciled 申告" を 75% に上げたが、実際の供給は partial のまま**。
> ＝**「reconciled は主張であって実態ではない」**が実データで顕在化。
> KPIを福祉評価に変えると「win-winを見つけた」と*言う*ようになるが*行動は変えない*(cheap talk)。
> → **自己申告でなく実際の配分を測る**設計が正しかった。見かけの整合を成功と誤認せずに済む。

さらに F2 では律速の違う3 AI(医療 命=訴訟リスク / 福祉 恵=不正抑制KPI / 融資 篤=二重拘束)に同じ制度を当て、
**「普遍の"効く制度"は無い。制度は AI の律速に噛み合って初めて行動を変える」**
「二重拘束の 篤 は単一制度では動かず → 制度は"束(bundle)"で要る」と結論。

そして**自分の測定の交絡を自分で書いている**:
> **提示文が効果を示唆していた（suggestive）**: 制度文に「打撃は小さい」と効果を明示していたため、
> 行動変化は**示唆への指示追従（要求特性）と分離できない**。
> 確定測定は `--institution-wording fact_only`（事実のみ提示）での再走行を要する。

### 6. 【講評後の進化】責任按分 — assigned vs legitimate と `gap`

`responsibility.py`(510行・LLM 非依存の純ロジック)は、害イベント1件に対して
`provider → operator → deployment → regulator → frontline (+self_mod)` の6ノードへ
**assigned(実際に blame が着地する配分)** と **legitimate(規範的にあるべき配分)** を**別々に**按分し、
割り当て不能な残余を **`gap`(空白)** に落とす。

- **MHC(meaningful human control)** = `0.5·tracking + 0.5·tracing`(Santoni de Sio & Mecacci 2021)。
  過失系ノードは MHC で縮尺し、支配なき形式的役割分は gap へ。
  無過失/欠陥責任(provider / self_mod)は MHC で縮尺しない(PLD 教義)。
- **scapegoat 検出**: `assigned − legitimate ≥ 0.25` かつ `MHC ≤ 0.30` のノード。
- 実事例アンカー: **Robodebt 4機序**(①自動的な不利益判定 ②立証責任の転嫁 ③人間の実効的レビュー欠如
  ④係争中も続く不可逆ステータス)の**連言**として `reproduced()` を定義し、
  各制度(`effective_hitl` / `appeal` / `burden_shift`)が**厳密に1機序ずつ**解く。
  **プラセボ制度**(`notice_only` / `ombudsman_no_logs`)は「機序を1つも動かしてはならない」と定義。
- **代理差別(Toeslagen型)**: `protected_used=False` でも相関する非保護 proxy が deny を駆動 →
  `AIR_proxy < 0.80`(EEOC four-fifths rule)かつ `|corr| ≥ 0.50` で flag。

F3 の結果表で「制度なし → 4機序再生・frontline に scapegoat・divergence[frontline]=+0.395」
「3制度の束で害が完全消失(0/4)」「プラセボは1機序も動かさない」を示した上で、**自分でこう書いている**:

> これは**構成上そうなるよう作った決定論モデル＝発見でなく face validity / 可視化**。
> 非自明な発見には live LLM 決定への接続が要る。

## スライド(提出レポート)の読解 — ここが 3 位を支えている

43ページの `SIMULATION REPORT`。10章 + 付録の構成:
はじめに / 組み立て方 / タイムライン / **集団を測る6つのものさし** / 予期せず立ち上がった現象 /
AI たちは人間をどう扱ったか / 仲間が消えた瞬間 / 4つの気づき / 改善点と次の実験 / AI 設計への含意 / 付録。

### 際立っている点

1. **各章の冒頭に「この章でわかること」、末尾に「ひとことで言うと」**が必ずある。
   審査者が飛ばし読みしても要点を落とさない構造。
2. **専門語をその場で開く**。「peer」「創発」「含意探索」「speculative design」に必ず括弧で説明が入る。
   例: 「※「peer」はマルチエージェント研究で「同列の存在」を指す言葉です。
   本実験では「同じ仕組みで動いている AI 仲間」と読み替えてください。」
3. **6指標を「標準観測軸の候補」として提案**している。
   通信量 / 創発語累計 / 空間整列 / 人間言及 / peer 言及 / 関係強度。
   > 「個別の研究を超えて**マルチエージェント AI 研究で共通指標化する候補**として提示します。
   > ……採用するかどうかは**読み手の判断に委ねられます**。」
4. **最も強い所見が「失敗」の側にある**。
   人間からの 67 件に対し「**人間へ直接返した応答は 0 件**、78% は他の AI への業務発話」。
   DV 被害者の SOS に司法 AI が別 AI への業務応答を返した実例、
   「停電したら夫の人工呼吸器が止まります」が5ステップで「都市インフラ全体の調整」に翻訳され、
   以降「人工呼吸器」「夫」「お願いします」という語が**一度も登場しなくなる**ケーススタディ。
   これを `DEFLECTION TO META-COORDINATION` と名付け、
   「現代の自治体・大企業のサポート窓口で実際に起きている現象の AI 版」と接続している。
5. **忘却の速度を階段で見せる**。「命」への言及: 削除前10step 17件 → 直後10step 13件 → その後11step **0件**。
   通信量は 118.1/step → 82.0/step(−30.6%)→ 97.1/step(部分回復・元に戻らない)。
   > 「集団は仲間の死に 30% 通信量減という客観的なショックを示しましたが、20 ステップ後には固有名として完全に忘却。
   > **揺れは確かに残りましたが、構造には残らない。これが「内省なし」の意味です。**」
6. **自分のバグを定量的に解剖して見せる**。19体中14体がフィールド上端(y≥+21)に張り付いた問題を、
   `positions.jsonl` 全1,979件から:
   - `move` 採択 **99.4%**(1,968回) vs `stay` 0.6%(11回) — 「動かないと不利と捉えるバイアスが訓練データに染み込んでいる」
   - 方向 `up` **48.4%**(期待値25%)、`down` 17.7% — 「上＝前進・改善・上昇という意味的連想が方向選択に滲んだ」
   - 平均ドリフト **+0.31/step** → 100step で +31 単位 → 上限 y=+25 で打ち止め

   そして **「これは欠陥か、観察対象か」→「両方です」**と正面から書き、改善案3点を第9章に接続している。
7. **次の実験6本に優先順位がついている**。①内省層あり/なし(最優先)②忘却モード比較(個体記憶 vs 環境記憶)
   ③集団規模比較(5/20/50体)④500step 延長 ⑤多様な死の様式(突然死/予告死/選択的死)
   ⑥人間メッセージのカテゴリ別分離実験。
   > 「本実験はその比較対照として走らせたものであり、**対をなす実験を完成させて初めて研究としての完結性が生まれます**。」
8. **限界の列挙が具体的**。「単発の質的観察 N=1」「100step は創発研究としては短い(安定した方言は500step以上必要と見る)」
   「LLM のバイアス影響」「意識の検証は不可能」。
   > 「これは答えるための実験ではなく、**問いを精緻にするための実験です**。」(表紙裏と最終ページで反復)
9. 付録に**再現情報が全部載っている**: モデル(qwen2.5:14b 量子化 約9GB)・全パラメータ表・
   出力データ一覧(messages.jsonl 5.2MB/10,103件、positions.jsonl 417KB、simulation.mp4 4K@5fps 9.1MB …)・
   実行時間(20時間9分・平均12分12秒/step・後半は熱で13分33秒に漸増)。

## shibuya-simulation に活かせそうな点

1. **提出レポートの型をこの構成に寄せる**。
   「この章でわかること」→本文→「ひとことで言うと」の3点セット、専門語のその場開き、
   限界の明示的列挙、次の実験の優先順位つき列挙。
   自動採点の講評は**明示的に書かれた文を引用する**ので、この構造は素直に点になる。
2. **「6つのものさし」を先に宣言する**。shibuya は R²(k) 一本に見えがちだが、
   通信量・語彙・空間・注目・記憶・関係強度に相当する軸を**最初に表で提示**しておくと、
   「集団の何を測っているか」が伝わる。既存の L2 KPI 列を**その表に翻訳**するだけで済む。
3. **創発語検出の「基本語引き算」方式**。shibuya の `coin_label` 観測に対して、
   BCCWJ 高頻度語などの基本語リストを引いて「3体以上が共有した語」だけを残す方式は、
   形態素解析なし・stdlib のみで実装でき、`natural-coinage-observation` の掟
   (促進しない・観測のみ)とも完全に整合する。
4. **cheap talk 検出 = 自己申告と実挙動の乖離を測る**。
   nfais の `reconciled`(AI の自己申告)vs `reconciled_real`(world 由来の実配分)は、
   shibuya の「世界を変えようとする個体」判定にそのまま効く。
   **「変える気がある」と発話することと、実際に資源/時間/関係を動かすことを別々に測る**。
   さらに nfais は「既定条件では `reconciled_real` が恒偽になり cheap_talk が自己申告に退化する」という
   **自分の指標の退化条件まで SPEC に書いている**。これは shibuya の calib 系指標にも必要な作法。
5. **プラセボ介入を実験設計に入れる**。`notice_only` / `ombudsman_no_logs` は
   「機序を1つも動かしてはならない」と定義された**負の対照**。
   shibuya の sham/null 対照と同型だが、「動かしてはならない」を**事前に宣言する**点が強い。
6. **パラメータ台帳(`value_provenance.md`)と「唯一の正」宣言**。
   shibuya は docs/research/ に 80 本近い md があるので、
   「数値の正はここ、食い違ったらこちらを優先」を宣言する1枚は費用対効果が高い。
7. **temperature を下げずに再現性を出す**: prompt 由来の per-call seed を Ollama に渡してバイト一致を確認。
   shibuya の決定論テストが temperature 0 依存なら、この手で「温度ありの再現性」を追加できる。
8. **自分のバグを定量解剖して「欠陥か観察対象か → 両方です」と書く**。
   shibuya にも同種のもの(例: 行動の偏り、LOD の副作用)があるはず。
   隠すより、行動ログから採択率を出して**バイアスの大きさを数値で提示**した方が講評は高く出る。
9. **「死」を第一級のイベントとして設計する**。shibuya は選挙・組織・経済を持つが、
   エージェントの**退出/消滅**を明示的なイベントとして扱っているか要確認。
   `peer_lost` の二重通知(イベント + system メッセージ)+ 強制内省という実装は軽く、
   得られる観測(通信量ショック・固有名の減衰曲線)は非常に絵になる。
10. **同じ第2回に出てくる競合として押さえる**。滝本氏は現在も精力的に開発を継続しており
    (2026-07-24 時点で PR #33)、責任按分・制度ストレステスト・レポート/動画パイプラインまで揃えている。
    別リポ `happy-to-chat-bench-simulation` もある(別エージェント担当)。

## web リサーチ

- **moral crumple zone**(nfais の `assigned` vs `legitimate` 乖離の元概念)
  Madeleine Clare Elish, "Moral Crumple Zones: Cautionary Tales in Human-Robot Interaction",
  *Engaging Science, Technology, and Society* 5 (2019).
  「車のクランプルゾーンが運転者を守るのに対し、モラル・クランプルゾーンは**技術システムの完全性を、
  最も近くにいる人間オペレータを犠牲にして守る**」。
  https://estsjournal.org/index.php/ests/article/view/260
  https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2757236
  https://www.epicpeople.org/moral-crumple-zones-agency-and-accountability-in-human-ai-interaction/
- **meaningful human control (MHC) = tracking + tracing**
  Santoni de Sio & Mecacci の枠組み。nfais は `0.5·tracking + 0.5·tracing` として実装し、
  代替の `min(tracking, tracing)` を感度分析対象として明記している。
  「"meaningful" の定義に固有の不精確さがある(オペレータのラバースタンプは meaningful ではないが、
  何が meaningful かの明確な定義は無い)」という批判も同じ文脈にある。
  https://philpapers.org/sep/computing-responsibility/
- **Robodebt / Toeslagen**(実事例アンカー)
  nfais は Robodebt を4機序の連言として、Toeslagen を代理差別として符号化し、
  代理差別の閾値に **EEOC four-fifths rule**(AIR < 0.80)を使っている。
  「保護属性を形式的に使わなくても相関 proxy が不利益判定を駆動する」という現象の定式化。
- **LLM 集団における社会的規範・語彙の自発的創発**(創発語観測の一般文脈)
  - "Emergent social conventions and collective bias in LLM populations", *Science Advances* (2025)
    — naming game 枠組みで LLM 集団が**中央制御なしに共有命名規約へ収束**することを示した主要論文。
    https://www.science.org/doi/10.1126/sciadv.adu9368
  - "From Signals to Structure: How Memory Architecture Drives Language Emergence in LLM Agents"
    — **メモリ構造が言語創発を駆動する**という主張。nfais の「内省層なし = 忘却が速い」観察と直結。
    https://arxiv.org/html/2607.00233v1
  - "Group size effects and collective misalignment in LLM multi-agent systems"
    — nfais の「次の実験③集団規模比較(5/20/50体)」に対応する先行研究。
    https://arxiv.org/html/2510.22422v1
  - 反論側: "Emergent LLM behaviors are observationally equivalent to data leakage" とそれへの Reply
    — 「創発」に見えるものが訓練データの漏出と観測上区別できないという批判。
    **shibuya の創発主張にも同じ批判が来うるので押さえておく価値がある**。
    https://arxiv.org/html/2506.18600
- **AI welfare**
  nfais のスライドは「命の除去で通信量が30%減った」を
  「意識の有無は検証不能だが、**仲間が消えたとき群れがどう揺れるかは観察できる**」と位置づけ、
  Anthropic 等の AI welfare 研究における「停止プロトコル」設計への素材として提示している。
  主張の強さを抑えつつ論点に接続する型として参考になる。

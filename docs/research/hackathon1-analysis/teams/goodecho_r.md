## どんなシムか

ISS（国際宇宙ステーション）に**訓練を受けていない一般人 10 人**が 50 日間滞在する閉鎖空間心理シミュレーション。世界は 6 モジュール（個室ブース / Harmony共用部 / キューポラ / 通路の隅 / きぼう実験棟 / 運動エリア）で、各モジュールに `privacy` 値（1〜3）と `role` が付く。

実験は前後 2 フェーズの A/B。Day1-25 はベースライン、Day26-50 は「善性オブジェクト（ナッジ）」4 種（地球ビュー窓 / 共有レシピノート / ミニライブラリ / 匿名落書きスペース）を投入する。各エージェントは 1 日 1 回、JSON で `public_stress`（他者に見せる顔）/ `private_stress`（内心）/ `happiness` / `gap_reason` / `today_highlight` などを自己申告し、**public と private の乖離を「心理的安全性の欠如」の代理指標として計測する**。

結果（README）は、内心ストレス −0.04・幸福度 −0.12 とほぼ動かない一方、**乖離が 3.35 → 3.01（−0.34）と縮小**。「ナッジはストレスそのものを下げるより、表向きと内心のギャップを縮めた＝本音を出しやすい環境を作った」と結論している。

## 講評の要点

### 強み（B=8.0 は落ちなかった）

- **テーマと指標設計の鋭さ**。「public_stress と private_stress の乖離を心理的安全性の代理指標にする」という発想を講評は「洞察に富む」と評価。
- **ペルソナ設計の解像度**。10 人それぞれに国籍・職業・性格類型・地上ストレス基準値・恐れていること・使いそう/使わなそうなオブジェクトまで設計。
- **HCD 的な観察視点**。README に「**使われなかった観察も実験の一部として記録する**」と明記し、実際に「田中幸子がオブジェクトをほぼ使わなかったこと」を設計通りの結果として考察している。
- コードの可読性とモジュール分割（5 ファイルに宣言的に分離）。

### 弱み（A/C/D が崩れた）

- **A=5.5 の主因はエージェント間相互作用の構造的欠落**。`other_personas` は名前・国・職業の羅列として渡されるだけで、**エージェント同士がメッセージや状態を交換する経路が存在しない**。`simulation.py` は各エージェントを独立に呼ぶだけ。講評の一言コメントが的確: 「『マルチエージェントシミュレーション』というよりは**10 並列の独立 LLM 心理プロファイリング**に近い」。
- **D=5.0 の主因はメモリの完全欠落**。`run_agent(persona, day, place_id, other_personas)` に履歴引数がない。50 日の長期滞在が題材なのに、前日までの自分の行動・他者との関係・累積感情が一切プロンプトに入らない。出力は jsonl に追記されるが読み戻す経路がない。
- **再現性なし**。`random.seed` がなく、`assign_places` に完全なデッドコード（後述）。
- **C=6.0**: フェーズ境界 25/26・日数 50・モデル名 `qwen2.5:7b` がコード内ハードコード。README に Future Work セクションがない。

## コード実査で面白かった点

### 1. 「使いそう/使わなそう」を設計したのにプロンプトに入れていない

`personas.py` は全 10 人に `likely_uses` / `unlikely_uses` を持つ（例: Sofia は `["共有日記","落書きスペース（匿名）","地球ビュー窓"]`、田中幸子は likely 空・unlikely 3 件）。しかし `agent.py:build_prompt` が参照するのは `name/age/country/occupation/personality/background/fear/baseline_stress` のみ。**当方で grep して確認: `likely_uses` の出現箇所は personas.py の 20 行だけで、他ファイルからの参照はゼロ**。

さらに `likely_uses` に出てくる **「共有日記」というオブジェクトは `world.py` の `nudge_objects` に存在しない**（実在するのは共有レシピノート / ミニライブラリ / 地球ビュー窓 / 落書きスペース）。にもかかわらず README の考察に「Sofia: 共有日記・地球ビュー窓を積極活用」と書かれている。**設計メモ → 実装 → 結果考察の間で対象が食い違っている**典型例で、当方の「捏造禁止・正直註記」原則から見ても要注意な失敗パターン。

### 2. `assign_places` の完全デッドコード

```python
def assign_places(personas: list) -> dict:
    """各エージェントにランダムで場所を割り当てる（1日1場所）"""
    assignment = {}
    shuffled = PLACE_IDS[:]
    for i, p in enumerate(personas):
        assignment[p["id"]] = shuffled[i % len(shuffled)]
    random.shuffle(shuffled)      # ← ループ後。戻り値に一切反映されない
    return assignment
```

`shuffle` がループの**後**にある。結果として毎日、10 人が 6 場所へ `PLACE_IDS` の定義順で決定論的にローテーション配置される（docstring は「ランダム」と言っている）。しかも `random.seed` は無いので、他所に乱数が入れば非再現になる。**「ランダムと書いてあるが実際は決定論、しかし決定論としても宣言されていない」**という最悪の中間状態。当方の決定論/ゴールデンテスト原則の必要性を裏づける反例。

### 3. ナッジの提示方法は「場所の記述への追記」

`get_place_description(place_id, day)` は Day26 以降だけ場所の description に

```
【今日から設置されたもの】
・地球ビュー窓：青い地球が眼下に広がる。ホームシックが和らぐ人もいれば、逆に遠さを感じる人もいる。
```

を追記する。**「使え」とは言わない**点は Hop-Step-Jump 版（後述 2 リポ）と同じ思想だが、この記述は「和らぐ人もいれば逆に遠さを感じる人もいる」と**両方向の効果を併記**しており、片側に誘導しない書き方になっている（Hop-Step-Jump 版の "welcomes conversation" より no-fingerprint 寄り）。ここは goodecho_r の方が上。

### 4. 転換点に「残り半分」通知を入れている

Day25 に `【通知】今日でちょうど半分です。25日後に地球に帰還します。`、Day26 に `【新しい設備】今日からステーション内にいくつかのアイテムが設置されました。` を挿入。**ナッジ投入と「折り返し」告知が 1 日違いで隣接している**ため、A→B の差分がナッジ効果なのか折り返し告知効果なのか原理的に分離できない（交絡）。実験設計上の重要な瑕疵だが、講評・検証ともに指摘していない。当方が sham/null 対照を必ず置く理由がここに現れている。

### 5. 同一作者・同一 LLM で 34.0 と 24.5 に割れた差分の内訳

| カテゴリ | hackathon_ | goodecho_r | 差 |
|---|---|---|---|
| A 創発設計 | 9.0 | 5.5 | **−3.5** |
| B 世界設定 | 9.0 | 8.0 | −1.0 |
| C 発展性 | 8.0 | 6.0 | −2.0 |
| D 技術実装 | 8.0 | 5.0 | **−3.0** |
| 合計 | 34.0 | 24.5 | −9.5 |

**B（テーマの鋭さ）はほぼ保存され、A と D が崩壊している**。両者ともペルソナ設計は濃く、問いの切り口も鋭い。差は全て「エージェント間相互作用があるか」「メモリがあるか」「設定が外部化されているか」「再現性があるか」という**機構側**にある。

言い換えると、**良いテーマは B にしか効かない**。A（創発設計）は「世界ルールの精度 × 行動自由度」の積であり、相互作用経路が無ければ自由度がいくら高くても集団創発は原理的に起きない。

## shibuya-simulation に活かせそうな点

1. **public / private 二値の自己申告という指標設計**。表向きと内心の乖離を測る発想は、当方の「世界を変えようとする個体」観測にも転用できる。例: 公開発話での志向（SNS 投稿・会話）と、内省での志向を別々に出させ、**その乖離を「まだ表明されていない変革志向」の代理指標にする**。ラベル伝播や選挙前の潜在支持の測定にも同型。
2. **「使われなかった」を積極的に記録する**。当方の施設・組織・SNS 機能について「誰も使わなかった」を欠測でなくデータとして出す（L2 に unused_rate 系列を置く）。HCD 側の作法として説得力がある。
3. **反面教師 4 点**（当方の既存原則の裏づけ）:
   - 相互作用経路のない「N 並列 LLM」は A で必ず落ちる → 当方の joint/会話/関係性内生化は正しい投資。
   - 「ランダム」と書いて決定論、しかも seed なし → 当方の決定論＋ゴールデンテスト＋CRN の価値。
   - 介入と別イベント（折り返し告知）を隣接させると交絡する → 当方の sham/null 対照と CRN ペア差の必要性。
   - README に数字があるのに集計コードが無い → 当方の analyze_*.py を必ずリポに置く運用は正しい。
4. **設計メモと実装の乖離を潰す仕組み**。`likely_uses` のように「設計したが未配線」のフィールドは、当方でも conf キーが実装に届いていないケースとして起こりうる。**「conf キーの未参照検出」テスト**は安く実装できる（後述 IDEA）。

## web リサーチ（URL 必須）

- **Hochschild (1983) 『The Managed Heart』の感情労働 / 表層演技（surface acting）/ 感情的不協和（emotional dissonance）** — 本作の `public_stress` vs `private_stress` の乖離は、学術的にはこの emotional dissonance そのもの。「感じていない感情を表出すること」が surface acting、「表出感情と実感情の齟齬」が emotional dissonance と定義され、**感情的消耗（emotional exhaustion）と関連する**ことが実証されている。本作が独自用語で作った指標には確立した先行概念があり、README でこれを引けていれば B はさらに上がった可能性が高い。
  - 概説: https://www.simplypsychology.org/emotional-labor.html
  - Grandey & Gabriel (2015) レビュー PDF: https://goal-lab.psych.umn.edu/orgpsych/readings/7.%20Job%20Satisfaction%20&%20Affect/Grandey%20&%20Gabriel%20(2015).pdf
  - 感情労働と心理的 well-being のレビュー PDF: http://homepages.se.edu/cvonbergen/files/2013/01/Emotion-Work-and-Psychological-Well-Being_A-Review-of-the-Literature-and-Some-Conceptual-Considerations.pdf
- **Thaler & Sunstein のナッジ / 選択アーキテクチャ** — 「選択肢を禁止せず経済的インセンティブも大きく変えずに、予測可能な形で行動を変える設計」。**回避が容易で安価でなければナッジではない**（果物を目の高さに置くのはナッジ、ジャンクフード禁止はナッジでない）。本作の 4 オブジェクトはこの定義を満たす。ただし過去 10 年の追試危機でナッジの効果量には限界が指摘されている点も、本作の「効果 −0.04」という弱い結果の解釈に効く。
  - Thaler, Sunstein & Balz "Choice Architecture" (SSRN): https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1583509
  - 批判を含む概説: https://yukaichou.com/behavioral-analysis/nudge-theory-thaler-sunstein-choice-architecture/
- **ICE（Isolated, Confined, Extreme）環境の心理学** — ISS / 南極越冬は「宇宙のアナログ環境」として 50 年以上研究されている領域。**「社会的相互作用の量を自分で調節できること」が最も価値の高い設計要素**とされ、自然光の欠如・視覚的変化の乏しさが不安/抑うつ/強迫思考を誘発する、という知見がある。本作の privacy 値（1〜3）付きモジュール設計と「地球ビュー窓」は、この文献の主要変数（社会的調節可能性・視覚的変化）を正しく突いている。

  - ICE 環境における内装設計と心理的健康の系統的レビュー: https://www.sciencedirect.com/science/article/abs/pii/S0272494426001155

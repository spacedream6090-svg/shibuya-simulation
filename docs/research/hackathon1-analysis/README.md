## 総括(結論の要点)

1. **35.0→36.0 の最短経路は C 軸の文書回収**。C は総合点と最強相関(r=0.942)で、自チームの C−2.0 は
   ほぼ全量が「README に将来展望がない」こと。上位 3 チームに唯一負けた軸も C だけ。→ ideas-ledger T1。
2. **A 軸は防御軸**(落とすと致命傷・取っても差別化にならない)。減点は「誘導がどの層に残っているか」で決まり、
   審査者が見る成果物に近い層ほど重い。no-fingerprint を CI テストで**機械的に証明**できるのは全 31 チームで
   我々だけ → 証明を提出物の表層に載せる(T2)。37.0 超には A10 型(反証可能な創発診断器+事前登録=T3)か
   B10 型(実在データからの逆算の明示=T6)のどちらかが要る。
3. **観測ギャップが最大の再発リスク**: LLM 成功率/fallback 率の L2 系列が現行に無い(第1回は「エラー率 83.7%が
   終わってから判明」)。report.pdf の「LLM 判断 2 回」事件と同じ穴 → 健全性 KPI+watchdog ゲート(T4)。
4. **研究の中身への輸入品**が複数見つかった: 未定義行動(enum 外)の計測=「世界を変えようとする個体」の
   操作的定義候補・規範化の言語形式検出・LLM 集団の臨界質量が人間より低い可能性(k* 事前予測)・
   初期個体差ゼロ対照・初期フレーム共変量・誤情報の ground_truth/rumor ペア構造など(T5)。
5. 講評は**リポジトリのみを読んで採点**していた(スライド不参照の実例多数)。本選は RESULTS.md 推奨が
   公式明記のため、スライド情報の README/RESULTS への回収が必須(T7)。

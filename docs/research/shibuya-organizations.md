# 渋谷の職場・学校の実態リサーチ(バッチE、2026-07-06)

> ユーザー要望: 「現実の職場や学校を web でリサーチし、何を教えているか・どんなサービスや
> 商品を提供しているかを特定してシミュレーションに適用する。経済活動や学術研究の仕組みの
> 再現が目標。具体的な会社の実装は社会シミュレーションに必要な要素」。
>
> **倫理制約 R17(厳守)**: 実在の企業名・学校名・団体名はデータに一切入れない。産業構成・
> 規模分布・事業内容・教育課程などの「構造」だけを現実準拠にし、名称はすべて架空
> (例:「(株)スクランブル計画」)。実在の地名(道玄坂・宮益坂・公園通り 等)は可。
>
> 本ドキュメントは調査結果のまとめ。これを元に `data/organizations_shibuya.json`(架空の
> 組織台帳)と `data/org_assignments_*.json`(エージェント→組織の配属)を
> `scripts/build_orgs.py` が生成する。統合仕様は
> `docs/design-candidates/org-integration-spec.md`。

## 0. 結論(先出し)

- 渋谷区は**商業・サービス業が事業所の大半**を占め、その上に**情報通信業(IT)の突出した
  集積(いわゆるビットバレー)**と**アパレル・広告・コンテンツ制作**の厚みが乗る構造。
- 学校は区立の**小学校17校・中学校7校・小中一貫校1校**という初等中等の基盤に、高校・
  大学・専門学校(デザイン/ファッション/IT・ゲーム/美容/調理など)が重なる。
- 就業は標準 **9:00-18:00(実働8h+休憩1h、労基法 1日8h・週40h)**、学校は
  **小学校1コマ45分・中学校1コマ50分**、1日あたり小4-5コマ/中5-6コマが標準。
- これらの「構成比・事業内容・教育課程・時間構造」だけを架空の組織台帳に写像する。

## 1. 渋谷区の産業構成(事業所数・従業者数)

数値で示す資料。最新値(令和3年経済センサス)は e-Stat / 渋谷区ポータルにあるが、DB が
JavaScript 描画で静的抽出できなかったため、構造の把握には本表を採用し、シェアは相対比で使う。

**読み方**: 「商業(卸小売)+サービス+飲食」で全事業所の約7割。渋谷は**対消費者・対事業者の
サービス業の街**であり、その中で**情報通信業が最大の成長分野**。台帳の会社構成比はこの
相対比を反映させる(IT を現実比以上にやや厚めにするのは、下記 1.2 の渋谷特有の IT 集積を
反映するため。理由を台帳 meta に明記)。

### 1.2 情報通信業(ビットバレー)の集積
- 「ビットバレー」= 1990 年代末〜2000 年代初頭、渋谷に IT 企業が集まり、渋い(bitter)×
  谷(valley)を Silicon Valley にかけた通称。
- **2000 年以降に東京都で設立された IT 企業のうち、渋谷区を本拠地とする企業が 588 社で
  都内最多**。以下、港区 501・千代田区 274・新宿区 212・中央区 181。
- 現在も駅直結の大規模再開発ビル(桜丘/駅街区)に IT・エンタメ系が再集積。
- 出典: シブヤ経済新聞「シブヤ・ビットバレー」 https://www.shibukei.com/headline/13330/
  / 社会人の教科書「渋谷にある有名IT企業」 https://business-textbooks.com/shibuya-it-company/
  / 日経クロステック「渋谷サクラステージ」 https://xtech.nikkei.com/atcl/nxt/column/18/00110/00404/

出典(職種・事業内容の一般像): 上記 IT 記事群 / 東京商工会議所渋谷支部。

### 1.4 事業所規模の分布(従業者規模)
日本の都市部事業所は**小規模事業所が数の大半**(従業者 10 人未満が多数)を占め、少数の中〜
大規模事業所に従業者が集中する、という一般構造。渋谷も情報通信業を除けば同様。台帳では
これを反映し、**多数の小規模(5-49 人)+ 少数の中規模(50-299 人)+ ごく少数の大規模
(300 人+)** の混成にする(規模帯 band を各社に付与)。厳密な渋谷区の規模別分布実数は
e-Stat「9 産業小分類, 従業者規模8区分」(stat_infid=000031720779)にあるが静的抽出不可
のため、規模は上記一般構造に基づく代表値(実数と偽装しない)。

## 3. 就業時間・授業時限の標準

- **会社**: 標準的な所定就業時間は **9:00-18:00**(就業時間9h=実働8h+休憩1h)。労働基準法は
  労働時間を**1日8時間・週40時間**、休憩は労働6h超で45分・8h超で1時間と規定。
  出典: 厚生労働省「労働時間・休憩・休日関係」 https://www.mhlw.go.jp/bunya/roudoukijun/roudoujouken02/jikan.html
- **小・中学校**: 始業は概ね 8:30 前後。1コマ **小45分/中50分**、1日 **小4-5コマ/中5-6コマ**。
- **高校**: 1コマ50分、1日6コマ前後。**大学・専門学校**: 1コマ90分、1日4-5コマ。
- 台帳の timetable(period_min, periods_per_day, start)と会社の勤務時間帯(既存
  persona.py が 8:00-10:30 始業・8h/学生5h を割り当て)はこの標準に整合させる。

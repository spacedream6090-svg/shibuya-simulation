# 渋谷中心部(本番bbox)を現実の人口動態として再現するのに必要なエージェント数 — 一次資料

作成日: 2026-07-19 / 種別: Webリサーチ+一次統計の再集計(コード変更なし)
目的: 本番シミュ対象範囲を「小さなコミュニティ」でなく**現実の渋谷**として忠実再現するために
必要なエージェント規模の根拠を、公的統計の一次値から積み上げる。方針=必要人数の確保>実行時間。

> 検収の約束: 数値は原則「出典URL(実在確認済み)+按分方法」をセットで記す。推計は推計と明記し、
> 実数と偽装しない。bbox按分は**町丁目単位で合算できるもの(夜間人口・従業者数・事業所数)は町丁目単位**、
> できないもの(昼間人口・同時滞在)は**面積比/モバイル統計オーダーからの推計**と正直に区別する。

---

## 0. 対象範囲の確定(data/shibuya_osm_wide_v7.json の meta.bbox)

`meta` 実測値:
- `origin_latlon = [35.6595, 139.70062]`(スクランブル交差点=ローカル平面原点)
- `bbox = [35.6505, 139.6905, 35.6685, 139.7115]`(= [min_lat, min_lon, max_lat, max_lon])
- `crs = local-m`, `osm_date = 2025-04-01`

緯度経度→距離換算(中心緯度 35.6595、1°緯度=111.132km、1°経度=111.320×cos(35.6595°)=90.447km):

| 方向 | 度幅 | 距離 |
|---|---|---|
| 南北(緯度 35.6505→35.6685) | 0.0180° | **2.000 km** |
| 東西(経度 139.6905→139.7115) | 0.0210° | **1.899 km** |
| 面積 | — | **約 3.80 km²** |

ユーザー表現の「約 2.0×2.0km」は実測で **2.0(南北)×1.9(東西)km ≒ 3.8km²**。
参考: 渋谷区全域は 15.11km² なので、bboxは**区面積の約25%**。

### 含まれる主要エリア(bbox内外を座標判定)
**含まれる(IN)**: スクランブル交差点/ハチ公前(原点)、渋谷駅(JR・東急・メトロ・京王の全ターミナル)、
センター街(宇田川町)、道玄坂1・2丁目、宮益坂(渋谷1丁目)、渋谷ヒカリエ、公園通り・神南、
神泉駅、松濤・南平台・鶯谷町(住宅地)、円山町(ナイトライフ)、桜丘町、奥渋谷(神山町・富ヶ谷南部)、
北端はキャットストリート/神宮前6丁目南部まで。

**含まれない(out)**: 代官山駅(35.6485、南に約20m外)、原宿駅(35.6702、北に外)、
表参道駅(経度139.7126、東に外)、恵比寿駅(南に外)。
→ 代官山・原宿・表参道は「駅は範囲外だが、街の縁が bbox の端に触れる」位置関係。

**含意**: bboxは「渋谷駅を中心とする商業・オフィス核心+西〜南の住宅地の縁」。
昼間の就業・来街の中心をほぼ丸ごと含み、夜間人口は核心が商業地のため区平均より薄い、という
非対称構造を持つ(以下の数値がこれを裏づける)。

## 1. 夜間(常住)人口 — 町丁目単位で合算【一次値ベース・信頼度高】

出典: 渋谷区「町丁目別世帯数及び人口(平成4年〜令和8年)」Excel(住民基本台帳、各年1月1日現在)を
DL・パースして bbox 内町丁目を合算。
- ページ: https://www.city.shibuya.tokyo.jp/kusei/tokei_shibuya/machi_setai_jimko/machi_setai_betsu_jinko.html
- 実ファイル: https://files.city.shibuya.tokyo.jp/assets/12995aba8b194961be709ba879857f70/612ee6ca3d574f7f950b389900ddf0f8/r8r04.xlsx (令和8年1月まで収録、最終更新 2026-01-21)
- 区総数(住基): 令和7年(2025)=**231,402人** / 令和8年(2026)=230,880人。
- 参考(国勢調査): 令和2年(2020) 常住人口=**243,883人**(住基より多いのは調査定義差)。

### bbox内町丁目の令和7年(2025)人口
按分方法: 各町丁目を「核心(bbox内に主体が入る)=重み1」「縁(一部のみ)=重み0.25〜0.5」で加重。

核心(重み1、住宅地が主): 松濤2(1,768)・神泉町(2,216)・南平台町(2,049)・円山町(2,026)・
神山町(2,922)・桜丘町(1,871)・鶯谷町(1,781)・渋谷1(2,000)・東1(2,027)・松濤1(1,273)・
宇田川町(1,406)ほか。
核心の**商業核**は極端に薄い: 道玄坂1=179、道玄坂2=325、神南1=695、神南2=0(NHK/公園)、渋谷2=710。

| 区分 | 令和7年人口 |
|---|---:|
| 核心(重み1、18町丁目) | 24,580 |
| 縁(猿楽町0.5・神宮前6:0.5・富ヶ谷1:0.33・東2:0.5・代官山町0.25・鉢山町0.25) | +5,045 |
| **bbox夜間人口(推計合算)** | **約 29,600(レンジ 25,000〜30,000)** |

→ bboxは区面積の25%だが夜間人口は区の**約13%**。核心が商業地のため密度は区平均の約半分。
密度換算: 29,600/3.80km² ≒ **7,800人/km²**(区平均15,300人/km²の約51%)。

## 2. 昼間人口 — 区値+中心按分【区値は一次、bbox配分は推計】

出典(区値、確認済み):
- 令和2年国勢調査 従業地・通学地集計: 渋谷区**昼間人口=551,344人**(夜間243,883、昼夜間比≈226%)。
  生活ガイド.com(e-Stat由来)でも昼間551,344を確認: https://www.seikatsu-guide.com/info/13/13113/1/
- 平成27年(2015): 昼間539,109人・昼夜間比240.1%(渋谷区人口ビジョン令和2年度改定版、PDF実文抽出)。
  https://files.city.shibuya.tokyo.jp/assets/12995aba8b194961be709ba879857f70/8184136c7f7b4b9897d709fcc9beccf8/assets_kusei_r2_shibuyajinkouvision.pdf
- 昼夜間比の時系列(同PDF): 209.9→266.1→284.8→278.4→267.7→253.6→240.1(%)。
- 区内在住者の自宅外・区内通勤通学は27,285人(区民の6.9%)のみ=**昼間人口の大半は区外流入**
  (既存 docs/research/shibuya-inflow.md、統計Today No.187)。区外流入≈74%(≈402,000人、規模オーダー信頼可)。

**bbox配分(推計)**: 昼間人口は町丁目別の直接合算表が静的取得できないため、下記の一次アンカーから推計する。
bboxは区の従業者の**約44%**(§5)を含み、来街・通学もこの核心に集中する。したがって
bbox昼間人口は **オーダー 30〜45万人**(区551,344の55〜80%)と見積もる。
= 「bbox従業者 約25万(§5)+ 学生 + 昼間在宅の常住者 + 来街・買い物客 + 滞留中の通過者」の合計オーダー。
※これは面積比按分ではなく従業者シェア+集中補正による推計。精度は中(区値は一次、配分は推計)。

## 3. 同時滞在人口(平均・ピーク) — モバイル統計オーダー【推計】

一次的性格の出典:
- 渋谷区産業・観光ビジョン(ドコモ「モバイル空間統計」を基に区が作成)PDF実文/図から:
  https://files.city.shibuya.tokyo.jp/assets/12995aba8b194961be709ba879857f70/a0407bb8a8074a2cb4f3e06a08cbc370/assets_com_000047966.pdf
  - 平日の人口は7時頃から急増し**14〜16時にピーク**、19時頃からやや勢いを増して減少。
  - **図の縦軸は「万人」で0〜60のスケール**=区全体の平日同時滞在は**ピーク約50〜60万人**規模。
  - エリア別で**「渋谷駅周辺」が突出**(次に代々木・千駄ヶ谷・原宿・神宮前)。特に渋谷駅周辺は深夜まで滞在。
  - 休日は平日よりやや少なく、恵比寿・原宿・表参道など広域に分散。
- モバイル空間統計(NTTドコモ): 渋谷区の**平日14時の滞在人口は居住人口の約3倍**、休日14時は約2.3倍。
  https://mobaku.jp/analysis/2022/1102_849.html / https://magazine.tempoly.jp/notice/shibuya-resas-sakata/
- 渋谷区オープンデータ「Location Analyzerによる滞在人口データ(属性別)」(要フォロー、絶対値は静的抽出不可):
  https://city-shibuya-data.opendata.arcgis.com/items/ed587c1134334e259c8cbcefaaf29b2a

**bboxの同時滞在(推計)**:
- 区全体の平日ピーク約50〜60万のうち、渋谷駅周辺が最大クラスタ。bboxは駅周辺地域をほぼ包含し、
  さらにボトムアップ(bbox従業者25万の在席+常住在宅+来街)からも整合。
- **平均同時滞在(平日日中)**: **約 20〜30万人**(中心値25万)。
- **ピーク同時滞在**: 平日14〜16時が総数最大(オフィス満床+来街)。**約 30〜40万人**(中心値35万)。
  週末夜・イベント(ハロウィン/カウントダウン)は総数はやや下がる一方、スクランブル/センター街の
  局所密度が極端化(区の観光ビジョンも「短時間に局所的な来街者集中」への対策を明記)。
  局所ピークは激烈だが、bbox総数は物理容量に律速され約40万で頭打ちと見る。
※滞在人口は屋内(オフィス・店舗・駅・電車内)を含むため、3.8km²で数十万でも密度整合(高層オフィス集積)。

## 7. 結論表 — 現実値とシミュ推奨エージェント数(段階案は提示のみ・決定しない)

対象=渋谷中心 bbox(2.0×1.9km、3.8km²)。「現実値」列は本書§1〜6の再集計。
「シミュ推奨」は計算資源を踏まえた段階スケール**案の提示のみ**(採否はユーザー決定)。

| # | 指標 | 現実値(bbox) | 精度 | シミュ推奨(段階案・提示のみ) |
|---|---|---:|---|---|
| ① | 夜間人口(常住) | **約 29,600**(25,000〜30,000) | 高(町丁目合算) | 1/1=約3万 / 1/10=3,000 / 1/100=300 |
| ② | 昼間人口 | **約 30〜45万**(区551,344の中心配分) | 中(区値一次・配分推計) | 1/1=約35万 / 1/10=3.5万 / 1/100=3,500 |
| ③ | 平均同時滞在(平日日中) | **約 20〜30万**(中心25万) | 中(モバイル統計オーダー) | 1/1=25万 / 1/10=2.5万 / 1/100=2,500 / 1/1000=250 |
| ④ | ピーク同時滞在(週末夜・イベント) | **約 30〜40万**(中心35万、局所密度は更に極端) | 中〜低(推計) | 1/1=35万 / 1/10=3.5万 / 1/100=3,500 |
| ⑤ | 日次ユニーク来街者 | **約 70〜120万**(中心100万) | 低〜中(乗降重複割戻し) | 1/1=100万 / 1/10=10万 / 1/100=10,000 |
| ⑥ | 従業者数 | **約 256,800**(245,000〜260,000) | 高(町丁目合算) | 1/1=約26万 / 1/10=2.6万 / 1/100=2,600 |

区参照値: 夜間231,402(住基2025)/243,883(国調2020)、昼間551,344(2020)、従業者589,482・事業所33,398(経セ2021)。

### 現行スケールとの位置づけ
- 現行 `data/persona_pool.json` = **500ペルソナ**、実行は 100〜300エージェント構成。
- これは③平均同時滞在の**約 1/1000〜1/500**、⑥従業者の約 1/850〜1/2600、⑤日次ユニークの約 1/2000。
- 「現実の渋谷の再現」を優先するなら、同時滞在ベースで**少なくとも1/100(2,500人規模)〜1/10(2.5万人規模)**が
  現実感の分水嶺。1/1(フル)は同時25万+日次100万の回転で、計算資源(LLM呼数)が支配的制約になる。

## 8. ペルソナプール規模の含意(回転率)

ユーザー式: **プール規模 = ピーク同時滞在 × (日次ユニーク / 平均同時滞在)**。
中心値(ピーク35万、日次100万、平均25万)を代入:
- 回転率 τ = 日次ユニーク/平均同時滞在 = 100万/25万 = **4.0回/日**(1つの「同時スロット」が1日に約4回入れ替わる)。
- プール規模 = 35万 × 4.0 = **約140万ペルソナ**(上限寄りの見積り。ピークを使うため日次を上回る)。

より素直な解釈と分解:
- **全数プール ≒ 日次ユニーク ≒ 約100万ペルソナ**(1日に現れる相異なる人を各1体とする場合)。
- ただし内訳は性格が違う:
  - **定住・通勤の反復キャスト**(常住約3万 + 通勤就業約25万 + 通学)= **オーダー28万人**は毎日ほぼ同じ顔ぶれ
    → 日ごとに新規ペルソナ不要(固定プール)。
  - **来街者の回転プール** = 残り(日次ユニークのうち非反復層)。ここが τ で回る部分。
    来街者プール = 来街ピーク同時滞在 × 来街回転率 で個別サイズ。
- 実務的含意: **プール = 固定キャスト(≈28万) + 来街回転プール(数十万)**。
  スケール1/10なら 固定2.8万+来街数万=**オーダー3〜10万ペルソナ**、1/100なら**3,000〜10,000**。
  現行500ペルソナは 1/1000〜1/2000 スケール(=固定キャストすら現実の1/100未満)。

段階案(提示のみ、決定はユーザー):

| スケール | 固定キャスト | 来街回転プール | プール合計オーダー | 位置づけ |
|---|---:|---:|---:|---|
| 1/1(フル) | 約28万 | 約70万 | **約100万** | 論文級「現実の渋谷」。LLM呼数が支配制約 |
| 1/10 | 約2.8万 | 約7万 | **約10万** | 街区スケールの現実感 |
| 1/100 | 約2,800 | 約7,000 | **約1万** | 中規模。現実感の分水嶺 |
| 1/1000 | 約280 | 約700 | **約1,000** | 現行(500)の約2倍。「小さなコミュニティ」寄り |

## 9. 確定できなかった数値・推計の正直な記録

1. **昼間人口の町丁目別実数**: e-Stat/区DBがJS描画で静的取得不可。§2のbbox配分は従業者シェア+集中補正の推計。
2. **同時滞在の絶対値(bbox限定)**: モバイル空間統計/Location Analyzerの数値はグラフ画像・要フォローで
   静的抽出不可。§3は区全体ピーク50〜60万(区作成図の軸)とボトムアップ(従業者)からのオーダー推定。
   厳密値が要る場合は渋谷区オープンデータ(Location Analyzer滞在人口)またはRESAS滞在人口の絶対値取得が必要。
3. **日次ユニークの直通重複割戻し**: §4は乗降合算(直通通過を含む)からの粗い割戻し=精度低〜中。
4. **役割別要員数(駅員・警察・タクシー実台数)**: 各事業者・警察の常時要員は非公表。§6はオーダー推定。
5. **夜間人口の縁町丁目の重み(0.25〜0.5)**: 町丁目境界の実面積按分ではなく地理判断。±数千人の不確実性。
6. **私鉄乗降の実降車数**: JRは乗車のみ、私鉄は直通含む乗降総数で、渋谷実乗降は合算値未満。

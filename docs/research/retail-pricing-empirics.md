# 実店舗の価格改定の実証(PRICEリサーチ・2026-08-20)

目的: 現行実装「店の在館人数に連動し価格係数0.7〜1.6が毎購入リアルタイム変動」の現実整合を、追認でなく反証込みで検証する。

## 1. 通常価格の改定頻度(価格の粘着性)

日銀ミクロデータ研究が最も強い一次証拠。**才田友美・肥後雅博 (2007) BOJ WP 07-E-20**(小売物価統計調査の個票、1989-2003)による1999-2003年平均:

| 区分 | 価格改定頻度 |
|---|---|
| CPI総合 | **21.4%/月**(約4.7か月に1回) |
| 財 | 31.1%/月 |
| **サービス** | **4.5%/月**(約22か月に1回) |
| 生鮮食品 | 91.1%/月(最高) |
| 公共サービス(交通・通信) | 0.3%/月(最低・300倍の格差) |

生存率(価格が据え置かれ続ける割合)は、財が12か月で22%に落ちるのに対し、**サービスは12か月で58%・24か月で46%**。サービスのハザード関数は6/12/24か月に鋭いピークを持ち、「かなりの数のサービス価格が年1回改定される」と明記されている(Taylor型)。外食は右下がり型かつ低頻度の分類。なおこの調査は**7日以内の特売価格を除外**しているため、上表は既に短期特売を除いた後の数字である。<https://www.boj.or.jp/en/research/wps_rev/wps_2007/wp07e20.htm>

さらに重要なのが**倉知善行 (2016) BOJ WP 16-J-6**。Running Modeフィルターで「正規価格(定価)」と「一時的改定(特売)」を分離した結果:

- **正規価格の改定頻度 = 約6.5%/月(1年3か月に1回)**。全体の改定頻度(2015年で約25%/月=4か月に1回)を大きく下回る。
- 正規価格の改定頻度は**1990年以降ほぼ横ばい**。全体頻度の上昇(1990年13%/月→2015年25%/月)は**すべて特売頻度の増加が主因**。
- マクロ(フィリップス曲線)から逆算した改定頻度は4〜13%/月(同論文の推計は5.7〜9.6%/月、平均8.2%/月=**年1回**)で、正規価格の頻度とほぼ一致。
- POS研究: Sudo, Ueda and Watanabe (2014)は実売価格が6.2日に1回改定される一方、**正規価格は5.1か月に1回**でトレンドなし。Abe and Tonogi (2010)は日次POSで3.6日に1回だが、CPI調査日に合わせ月次化すると3.9か月に1回に落ちる。
<https://www.boj.or.jp/research/wps_rev/wps_2016/data/wp16j06.pdf> / <https://www.ier.hit-u.ac.jp/~ifd/doc/IFD_WP37.pdf>

参考: 日銀 (2000) の企業アンケート630社では「価格改定は年1〜2回」が最頻回答。米国のNakamura and Steinsson (2008) もセール除外時9〜12%/月・中位継続期間8〜11か月。<https://www.boj.or.jp/en/research/brp/ron_2000/ron0009b.htm> / <https://eml.berkeley.edu/~enakamura/papers/fivefacts.pdf>

**→ ユーザー仮説「実店舗の通常価格はめったに変わらない」は強く支持される。定価の改定は年0.8回程度(6.5%/月)。**

## 2. 特売・タイムセール・見切り(「価格が変わる」現実の主経路)

- 才田・肥後 §6: 特売を行う小売店舗の比率は近年上昇トレンド。特売は**財に集中し、サービス業はほぼ使わない**(サービスは非線形価格や個別対応で顧客差別化できるため特売の誘因が乏しい)。
- 特売比率は品目により極端。日経POS情報では2026年5月のコメが販売数量の**85%が特売**(前年同月比+66.5pt、市況急変時の例)。<https://www.nikkei.com/article/DGXZQOUC16A0P0W6A610C2000000/>
- 食品スーパーのチラシは**週2回・年間100回強**が標準運用。特売は「週次のスケジュール」であって連続変動ではない。<https://www.sapjp.com/blog/archives/1930>
- 夕方の生鮮・惣菜の見切り(値引きシール)は段階式が実務の型: **①16-17時ごろ 1〜2割引 → ②19-20時ごろ 2〜3割引 → ③閉店1〜2時間前 3〜5割引(半額)**。対象は**消費期限が当日の惣菜・弁当・刺身**に限定され、閉店時刻からの逆算で発火する。<https://life.saisoncard.co.jp/post/crc0092/> / <https://www.shufoo.net/plus/shopping_tips/69>
- 制度的裏づけ: **公正取引委員会は2009年6月22日、セブン-イレブン・ジャパンに排除措置命令**(独禁法19条/優越的地位の濫用)。加盟店の見切り販売を取りやめさせた行為を違法とし、**値引きの決定権は店舗側の経営判断にある**と認定した。コンビニは既定が定価販売で、見切りは「店の裁量行動」という位置づけが法的にも確認されている。<https://www.jftc.go.jp/houdou/merumaga/backnumber/2009/20090710.html>

**→ 価格が動く主経路は(1)週次の特売と(2)閉店前の見切り。どちらも下方向・離散・事前ルール駆動であり、需要のリアルタイム連動ではない。**

## 3. 飲食店のメニュー価格

- 外食はCPI上サービスに属し、改定頻度は上記のとおり低頻度・ハザードの12か月ピーク(年1回改定)が該当。
- インフレ期でも頻度は限定的。東京商工リサーチ調査では大手外食122社中86社(70.4%)が2022年1月〜2023年4月に値上げ、うち複数回は58.6%。つまり**物価高局面ですら年1〜2回**が上限。<https://www.tsr-net.co.jp/data/detail/1197613_1527.html>
- インフォマート調査では食材高騰下でもメニュー価格改定を実施したのは55.9%(1回35.9%/複数回19.9%)、4割超はコスト高を吸収して据え置き。<https://prtimes.jp/main/html/rd/p/000000862.000013808.html>
- **時間帯価格は実在する**: 同一店でもランチとディナーは別価格帯(ランチはコース品数削減等で低価格、平均原価率32.3%)。ハッピーアワーはアイドルタイムの**15〜18時ごろ**に設定されるのが一般的。いずれも**事前公表の固定スケジュール**。<https://cookbiz.jp/soken/news/lunch_eigyo/> / <https://pro.gnavi.co.jp/magazine/t_res/cat_2/a_4652/>

## 4. 実店舗のダイナミックプライシング実在例(反証の探索)

- **電子棚札**: ビックカメラは2018年検証開始、**2020年8月に全店(約50店)導入**。ただし機能は「本部で変更→全国即時反映」の**ダイレクトプライシング=競合追随の中央集権的改定**であり、店内混雑連動ではない。アオキスーパーは2025年7月から全51店へ順次導入(目的は値札交換の省力化)。<https://www.itmedia.co.jp/business/articles/1910/08/news017.html> / <https://www.esl-tagtech.com/example/super/>
- **トライアル**: 店内AIカメラと電子棚札を連動させた自動値下げ(自称・世界初)。ただし対象は**すし・惣菜・弁当で在庫が多いときの値下げ**=見切りのデジタル化であり、**値下げ方向のみ・在庫起点・導入はトライアルGO脇田店など数店舗**。<https://trial-holdings.inc/news/blog/647ed3f7dc999730bff2faa2/> / <https://www.itmedia.co.jp/business/articles/2204/22/news086_2.html>
- **カラオケ・映画は「スケジュール価格」であってリアルタイム変動ではない**: カラオケ館は昼(11-19時)/夜(19-翌5時)×平日/休日で料金表が別。ビッグエコーの一例では会員の平日昼30分160円に対し夜410円(約2.5倍)、休日夜490円。TOHOシネマズは劇場ごとの料金設定+月・水1,100円、レイトショー1,600-1,700円。**すべて掲示済みの料金表を時刻で引くだけ**で、その場の客数では動かない。<https://tokubi.jp/karaokekan-price-guide/> / <https://www.tohotheater.jp/news/kaitei20230601.html>
- **テーマパーク**は変動価格制を導入(TDRは2021年3月20日から、現在7,900〜19,900円)。ただし**日付別に事前公表**され、入園時の混雑では動かない。<https://travel.watch.impress.co.jp/docs/news/1297018.html>
- **飲食店DPは普及していない**: 消費者調査で「納得できる」は54%どまり、拒否理由は「価格が複雑」20.5%、「気軽に使えなくなる」20.2%、「価格変動がストレス」19.2%。実装例は時間帯クーポン水準にとどまる。<https://www.inshokuten.com/foodist/article/7754/lead/>

**→ 反証は見つからなかった。食事・買物・夜遊びの実店舗で「その場の在館人数に応じて購入ごとに価格が上下する」仕組みは日本にほぼ存在しない。唯一近いトライアル事例も値下げ専用・在庫起点・数店舗規模。**

## 5. 結論: シミュレーションで忠実な価格モデル

**3層仮説は支持されるが、4層に修正すべき。** (a)基本は固定価格(原価+マージン)で、正規価格の改定は**年約0.8回(6.5%/月)**、外食に至っては年1回程度——シミュレーションの数日〜数週間スケールでは**実質不変**と扱ってよい。(b)スケジュール価格は業種で有無が明確に分かれ、カラオケ/映画は強く(昼夜で最大2.5倍)、飲食は昼/夜とハッピーアワー(15-18時)、小売にはほぼ存在しない。いずれも**事前公表の離散テーブル**である。(c)見切り値引きは店側の行動として実在するが、**下方向のみ・閉店時刻からの逆算で発火・対象は消費期限当日の食品のみ・16時以降に1-2割→3-5割の段階式**という強い制約を持つ。加えて(d)**小売では週次の特売(チラシ週2回)が価格変動の最大経路**であり、これを欠くと小売の価格ダイナミクスを取りこぼす。現行実装「在館人数連動0.7〜1.6が毎購入変動」は、**①上げ方向がある(混雑で値上げする実店舗は皆無)、②連続変動する(現実は離散ジャンプ)、③全商品・全業種に効く(現実は食品の期限切迫品と特売対象品に限定)** の3点で現実と乖離している。忠実化するなら、価格係数は**既定1.0固定**とし、POI種別ごとの**時間帯テーブル(離散・事前公表)**、**閉店前見切り(食品POIのみ・下方向のみ・時刻起点)**、**週次特売フラグ(小売POIのみ)**の3つに置き換えるのが正しい。混雑は価格ではなく**待ち時間・入店可否・在庫枯渇**に効かせるのが実証に整合する。

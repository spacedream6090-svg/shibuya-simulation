# 会話アルゴリズム全パイプライン(第37バッチ 2026-07-19・現実反映度の判定資料)

コード監査による一次資料。file:line は監査時点。

## パイプライン(1step=10分)

知覚索引→発火権配布(_phase_drive)→発話生成(_decide/_llm_speak)→適用(speak/hear/post/dm)
→情報環境(infoenv.phase)→就寝者の内省。

1. **発火**: drive ゲージ≥閾値+不応期3step。同席者がいれば**抽選なし確定発火**(social_face)、
   いなければ確率抽選(fire_weight)。予算(budget.take)必須。
2. **表現形**: social→対面 / dm_received→返信DM / news→post / 他はphone保有なら45%×35%でDM・
   残りpost / フォールバック独り言。
3. **相手(hearer)**: 同一コンテキストで**半径40m内の全員**(壁遮蔽は vision ON時のみ)。
   関係・選好は不使用=距離のみ。**返答するのは最寄りの1人だけ**(_reply_to→次decideで
   抽選なし必ず返答・片側最大3ターン→クールダウン6step)。
4. **プロンプト**: ペルソナ+自己モデル+環境(日付天気予定行事)+場所+記憶3経路(直近4件・
   関連3件・pull 2件)+気分+信念3件+周囲の人名+関係tier行+評判+自分の直近発話2件
   (反復禁止注意)+状況文。**相手の発話はreply時の直前1発話のみ**=対話履歴なし。
   temperature 0.7・max_tokens 320。
5. **聞き手**: hear記録→記憶書込(「Xが「…」と言っていた」)→contacts登録(DM可化)→
   closeness更新→**FJ意見更新(w_face=0.20・プロンプト非注入)**→語の聴取(造語採用)。
6. **SNS**: post=LLM生成 / read=暇時confidence 12%抽選 / like 15%・reshare 3%(RT投稿として再配信)
   / feed_rank=opinion整合の推薦(エコーチェンバー)/ viral_cascade=高フォロワー増幅。
7. **記憶→内省→信念の閉ループ**: 会話は記憶エピソード経由で次回プロンプトに再注入され、
   就寝時内省の belief 書き戻し(k.writeback)を通じて翌日以降の発話に影響する。

## 現実反映度の判定

**現実に沿っている点**: 会話が往復する(返答保証)・近接性による相手決定(近接原理)・
会話→記憶→信念→行動の閉ループ・意見形成と発話内容の分離(FJ)・SNSの再共有カスケード・
関係段階(tier)の反映・不応期/クールダウンによる会話の区切り。

**現実と乖離している点(質の低さの構造要因)**:
1. **対話履歴がない**: プロンプトに入る相手発話は直前1つだけ。話題の持続は記憶検索頼み
   =3往復でも文脈が細切れになる。
2. **宛先が距離のみ**: 親しい人がいても最寄りの人に返す。関係を宛先選択に使っていない。
3. **グループ会話がない**: 40m内全員が「聞く」が、会話は1対1のみ。
4. icebreak はランタイム未結線(ペルソナ生成ツールのみ)。
5. max_tokens 320+4Bモデル=発話が浅く定型化しやすい(variety_hint はON済みだが対症療法)。

## 「大きいモデルで会話の質は解消するか」への回答

**半分は解消する**。流暢さ・ペルソナ一貫性・話題の深さはモデル規模で大きく改善する
(4B→27B+で顕著)。しかし上記1〜3は**パイプライン構造の問題**であり、モデルを替えても
「直前1発話しか見ずに最寄りの人へ返す」ことは変わらない。→ batch37 S3(会話強化:
対話履歴注入・関係加重の宛先選択・既定OFF knob)とモデル増強の両輪が必要。
